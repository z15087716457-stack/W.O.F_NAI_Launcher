# V4／V4.5 及更早模型

先从 studio_context 确认完整模型 ID 和工作流。这是 V4 系列入口；不要把 V5 的提示词或接口规则移植到这里。

沿当前原生字段编辑主／负面提示词、角色、尺寸、种子、采样与参考设置。角色位置、启用项、提示词与积木原文用 scope=draft 的实际结构；不把翻译文本或生效预设回写成原始草稿。当前服务不支持的参数不得根据旧聊天补齐。

构图与标签建议可先通过 tag_query／wiki_query 核对词义，并用 image_read 看用户原图。具体图生图、Vibe 与精准参考支持以 reference_manage 的当前状态为准；请求费用和资格以 generation_prepare 为准，不假定某尺寸或方案免费。

需要当前版本的详细创作规则时，读取用户明确提供的工作区资料或通过其可用网络工具核对官方文档。无法核实的模型限制应说明；本包不会默认导入开发者的私人创作手册。

操作语义见 [studio.md](studio.md) 和 [generation.md](generation.md)。
