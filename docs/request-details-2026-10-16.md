## 行为与接线

- 鼠标位于某条请求记录时，该行末尾显示“详情 ›”；离开即隐藏，按钮位预留，耗时与 token 数不被覆盖。窄窗口或大字号时表格可横向查看。
- `SettingsRequestLog.id` 投影原 `ModelRequestRecord.id`，`SettingsActions.onRequestDetails` 经 `SettingsModelActions` 打开已有 `ModelRequestDetailsDialog`。无原始记录 ID 的摘要不放空入口；按 ID 观察记录，新的请求插入列表也不会串行。
- 详情保留“概览／请求／响应”：实际地址、方法、请求头与请求体，逐次 HTTP 尝试的状态码、响应头／正文及错误，可选中并复制当前页的完整格式化 JSON。复用现有捕获和脱敏链路，没有重发请求或第二份日志。
- 正文仍只保存在本轮应用内存，历史最多 100 条，表格最多展示 50 条；记录已清空／淘汰显示缺失，复制停用。授权、Cookie 和已知凭据沿用原脱敏，未改变配置导出或磁盘日志。
- 新按钮文案同步五语言，台湾正体及 l10n 按现行入口生成。无依赖、数据库结构或 Riverpod／Freezed 生成输入变化。
