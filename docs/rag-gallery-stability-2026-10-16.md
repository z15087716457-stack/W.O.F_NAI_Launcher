# F31 · 图库 RAG 结果回退与环境状态

**交付状态：已随 [r11 本机累计更新](cumulative-preview-r11-2026-10-16.md) 安装；下文保留实现阶段的验证与边界。**

2026-10-16，按用户“语义命中一闪后只剩两张、环境几秒后又回来”的反馈调查并本地修复。用户确认两张是普通精确命中；现有图库每次最多附加 60 张语义结果，因此 62 → 2 与语义结果被撤掉吻合。

## 已确认原因与实际环境

1. `LocalGalleryNotifier` 监听 RAG 可用性／完成状态，每次变化都会重新载入时间线，先写入普通结果，再发语义请求；短暂错误、暂停和恢复会把已经成功显示的语义命中撤掉。隔离测试先复现两条结果退回一条普通命中，见 `reproduction.log`。
2. 环境检测原为页面离开即释放的 provider，回到设置重新导入依赖；空的检测中状态被映射为 `runtimeReady=false` 和空 Python 路径，标题又显示“先安装环境”。这是已确认的界面误报，不代表文件被卸载。
3. 工作进程串行执行推理／建库步骤，交互请求优先；单次建库步骤或首次模型加载会增加等待。原 60 秒状态请求超时会把所有来源置为错误，进一步触发上述结果回退。真实子进程退出的底层原因没有在本次复现，不能据此认定显卡／其他工具冲突。

现有运行包的 Python 3.12 托管环境只读导入检查：退出 0，8.51 秒，依赖版本及 CUDA 均通过，stderr 为零；未加载权重。现场进程清单显示登记 Studio 及其 RAG 宿主／Python 子进程仍在。用户的环境、路径联接、模型和索引未重装、迁移或清理，正在进行的建库未被操作。

## 当前实现

- 状态故障或 GPU 暂停不重新覆盖已有结果；可用性恢复／建库完成时重新查询，同一筛选、搜索词、通道和参考图保留原结果直到新请求成功。换查询、切通道、清除索引或关闭 RAG 沿用普通刷新；成功返回空语义命中时会正确回到普通结果。删除保护、范围过滤和旧请求取消保持。
- 图库失败继续作为失败向调用端传播，不伪装成成功空列表；资源让出同样与空命中区分。模型结果仍按现有融合规则处理，本批未改综合搜索权重或结果上限。
- 成功的环境 probe 使用 keepAlive 跨页面复用；失败结果可在再次进入页面时重测，显式检测／安装／解释器变化仍失效重查。待测时保留已选路径，已连接工作进程可作为当前可用事实；明确检测失败仍显示失败。检测中标题、徽标和按钮不再提示未安装。
- 心跳在活动检索期间超时不破坏来源状态；图库检索使用明确三分钟上限，可随时取消。重连替换旧事件订阅并取消旧刷新定时器，旧进程晚到事件不能污染新连接。
- Python 使用独立协议输出流，第三方库及推理线程普通 print 转 stderr，避免破坏严格 JSON 流导致误断开。Dart 日志记录超时操作、断开原因和进程退出码；stderr 只识别 CUDA 内存不足／系统内存限制等有限类别，不落原文、查询、路径或模型输出。
