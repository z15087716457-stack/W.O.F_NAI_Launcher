# 侧栏更新入口

按用户确认的 HTML 样板完成源码接入，已随 [2.3.3 安装与发布](release-2.3.3-2026-11-11.md)交付。下文保留源码完成时的专项验证。

## 行为

- 更新入口位于折叠按钮上方，收起为蓝色圆形图标，展开显示状态与版本／进度副标题。下载用进度环，就绪用重启图标，失败用错误色。未知新版、检查中、检查失败及已是最新不占用入口。
- `nav_contract.dart` 用 `NavUpdateData` 替换原布尔字段，接线在 `nav_wiring.dart`，界面仍只依赖契约。`nav_update.dart` 共用图标与本地化标签；收起、停靠展开及临时展开都能打开现有 `UpdateCheckDialog`，临时展开先收起。
- 入口不会自动下载、安装或退出。共用详情保留真实版本说明、校验、取消、重试、手动下载和 Mac 访达替换流程；下载中提供“后台下载”，关闭详情不取消下载。
- 去掉桌面设置红点与无窗口装饰时的旧横幅，更新通知集中在新入口。设置手动检查和移动端现有提示不变。
- 安装等待生图、探索、放大／批量操作以及所有已创建 Agent 会话结束。Agent 的运行、启动、排队、压缩和待发送均纳入；不初始化关闭的 Agent。检查按详情订阅释放，重开详情重新采样，安装点击再次核对。
- 七项新增文案同步简中、繁中、英、日、韩；台湾正体由登记流程生成。

## 验证

- 登记 Flutter 3.47.7／Dart 3.13.5。相关 180 项测试全部通过，0 跳过；全仓 `flutter analyze --no-pub` 为 0 问题。
- 覆盖六种可操作状态、两种导航模式、五种语言和深浅色；另查 320×360 窗口、手动替换平台、键盘激活、进度变化不移动页面、临时／停靠导航、后台下载重开及明确安装点击。
- 安装检查覆盖冷态 Agent 不初始化、已保留的后台会话各忙碌状态、重新打开详情，以及已结束后台任务不阻止安装。现有真实更新 provider 与详情回归使用合成服务，无真实下载、安装、生图或模型调用。
- 原主导航 PNG 不改。仅在新入口区域及被移除的旧设置红点 8×8 区域排除旧像素，其余旧界面逐像素比较仍通过。
- 首轮测试夹具分别漏用了生成状态构造字段和更新资产校验摘要；另补齐四种语言的占位符元数据。均已修正，最终同组 180 项重新运行通过，没有放宽失败断言。
