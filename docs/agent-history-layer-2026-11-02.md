## 原因与改动

Agent 对话历史原来手动插入根 OverlayEntry，大图使用页面内已有的 UiModal／OverlayPortal。根条目画在页面浮层之后，因此即使大图已经打开，历史仍覆盖在图片上并接收点击。

历史栏改用所属页面的 OverlayPortal，位置计算、宽度、内容、样式与导航均保持。大图打开时按原弹窗机制绘制在历史上方；关闭后，历史栏仍保留位置和搜索条件。历史随所属页面卸载，不再手动管理根条目的插入、重绘和释放。切换会话时在框架允许的帧尾关闭 Portal，保持原先的关闭行为。

生产改动仅 `lib/presentation/ui/agent/agent_panel.dart`，测试补在已有 `agent_history_test.dart`；没有新浮层管理器、路由系统或强制关闭历史来遮掩层级问题，也未改共享 UiModal 或图片查看器。
