# 统一界面缩放 · 2026-11-14

用户确认将「设置与对话框字号」「创作区文字字号」合并为一个整体缩放，并修正预览重复放大。本轮只修改有效源码；桌面仍为2.3.4+103，未构建、安装、启动Studio或提交Git。

## 行为与实现

- 设置只保留「界面缩放」：80%–150%、10%一档、默认100%。导航、Agent、提示词编辑器、设置、菜单与对话框随同一个倍率调整文字、图标及控件尺寸；资源子窗口创建时继承、已打开时同步。图片文件、生成参数及输出分辨率不改写。
- `AppUiScale`读取唯一`uiScaleProvider`，纯UI组件`UiScale`包住完整Navigator／Overlay。逻辑视口按倍率换算，绘制和命中测试共用Transform；内部文字使用原始字号和`TextScaler.noScaling`。保留系统DPR，避免原生坐标二次乘倍率。
- 预览标题／正文／说明使用15／13／11逻辑像素，随整体界面缩放一次。130%时标题为19.5px，150%时为22.5px；去掉原来显式字号和继承TextScaler重复相乘的路径。
- 移除旧字号provider、工作区字号Host和Scope；设置作用域只保留减少动态效果的`SettingsMotionScope`，不再控制字号。
- 菜单先把全局锚点转换到Overlay局部坐标；可见范围、悬浮预览及原生标题栏矩形使用变换后的边界。原生区域按界面倍率上报客户区逻辑坐标，系统DPI仍由既有原生路径处理。
- 设置可用逻辑宽度小于700时，目录收成带悬停名称的图标栏，搜索移到内容顶部；语言选项使用下拉框。快捷键表格横向滚动，模型／Agent页签沿用`UiScrollableRow`，长操作组与更新按钮可换行。资源小窗在极窄逻辑视口里把筛选放到第二行，详情保留主要操作。

主要入口：`lib/presentation/ui/kit/ui_scale.dart`、`lib/presentation/widgets/common/app_ui_scale.dart`、`lib/presentation/providers/ui_scale_provider.dart`、`lib/core/settings/ui_scale_preference.dart`。设置契约、备份、Agent设置工具、资源窗口协议／控制器及坐标调用方同步接线。

## 旧值与备份

新键为`ui_scale`。读取优先级：有效新值；旧`settings_font_scale`的非100%值；旧`workspace_font_scale`的非100%值。如果任一现行旧键存在但没有有效非100%值，使用100%，不复活更早废弃的`font_scale`；只有两个现行旧键都不存在时才回退到有效`font_scale`。

读取不改写用户设置；保存及恢复默认只写新键。明确保存100%后，旧值不会再次生效。新备份和Agent设置枚举只输出新键；导入旧备份／旧更新参数时统一归并为新键。历史设置卡仍能展示旧键，恢复时保留既有快照冲突保护。
