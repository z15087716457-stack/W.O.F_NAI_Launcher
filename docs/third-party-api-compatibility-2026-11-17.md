# 第三方 API 连接修复 · 2026-11-17

源码已完成，尚未安装；本机桌面仍为 2.4.1+117。使用用户提供的临时凭据完成只读账户诊断，未保存到真实账号配置，未调用生图、放大或氛围编码接口。

## 原因与实测

两个站点的根地址 `/user/subscription` 都返回 HTTP 200 的 New API 网页。旧客户端将网页直接转换为订阅 Map，导致登录失败；密钥本身能够访问各自的模型列表。

| 站点 | 已验证的账户 API 基础地址 | 账户响应 |
|---|---|---|
| 存在站 | `https://api.cunzaijiang.cn/v1` | 有效凭据通过；不提供 Anlas 余额，`trainingStepsLeft: null` |
| HamuBox | `https://api.hamubox.com/v1/novelai` | 有效凭据通过；余额是站内兼容显示单位，Opus 是虚拟兼容状态 |

两站使用无效测试密钥均返回 401。修复后的真实 Dart 客户端已分别完成前缀识别、账户验证和余额刷新；HamuBox 一次完整识别超过 5 秒，证实旧总时限也会使有效连接失败。

HamuBox 前缀、单次一张、ZIP／MessagePack 及 multipart 契约依据其[客户端接入](https://api.hamubox.com/docs/novelai/clients/)和[官方协议兼容](https://api.hamubox.com/docs/novelai/native/)。使用正确报价请求进行非生成验证，832×1216、23 步、V5 Curated、单张样本返回站内显示单位 10、预估 0.01 USD、免费张数 0；这只是该参数组合当时的报价。存在站的同名报价路径返回 404。

## 已完成修改

- 登录按输入地址、同站 `/v1`、同站 `/v1/novelai` 检查账户接口。仅网页／不兼容响应或 404／405继续识别；401、403、限流和网络故障直接保留。显式自定义路径不猜测，不通过提交生成探路。
- 验证结果同时携带订阅数据和确认的地址，手动登录、账号切换及自动恢复均采用确认地址；新增账号保存确认地址，独立配置的图片服务保留。
- 第三方登录总时限为 30 秒，官网保持 5 秒，取消与旧请求不能覆盖新会话的校验保留。
- New API 连接 JSON 可直接粘贴到 Token 框，拆分 URL 与 key 后验证；无效导入显示字段错误，错误信息不包含密钥。
- 登录与刷新共用账户响应检查，网页不再当作登录成功；无兼容接口时提示检查 API 基础路径。
- 缺少余额显示未知；第三方订阅标记独立计费，虚拟 Opus 不再触发官网免费逻辑。五语言说明同步。
