## 复查修正

- **卡片打开中**：外圈原来用 `BoxShadow(spreadRadius: 2)`，Flutter 会把 30% 块色铺在半透明底色下面，底色比 HTML 深（同场景平均色差浅色 46 / 深色 32）。改为只画在药丸外面的 `PromptPillShadowPainter`，与 CSS `box-shadow` 一致；色差降到 11 / 6。
- **拖动中**：阴影原来是 `colorScheme.shadow` 18% 并铺在药丸下面。改为 HTML 的 `--shadow`（浅色黑 14%、深色黑 45%），只画在外面，模糊按 Chromium 的 CSS 换算；浅色色差 35 → 2。
- **翻译药丸图标槽**：原来固定 12px 方框，药丸比 HTML 宽 2px。改为和 HTML 一样随「译」字宽度，宽差归零。
- **翻译忙态**：上一轮把 `TranslationIcon` 的旋转动画整个删了，`busy` 参数什么也不做，提示词翻译按钮、标签百科自动翻译、标签补全翻译开关、大图提示词翻译等处翻译时看不出在忙。原型没有设计忙态，所以保留原型图形，只在忙时让同一图形透明度 1 ↔ 0.35 呼吸（700ms）；系统减少动态效果或 TickerMode 关闭时不动。药丸里的「译」不传 `busy`，不受影响。
- 原子编辑器里提取虚线画家后遗留的一段中文说明移回 `DashedRoundedBorderPainter`。
