## 已修复的问题

1. **NAI 云端放大调用了旧接口。** 原代码向主 API 域发送旧版 `scale=4/width/height`，实际返回 404。按当前官网改为图像域 `/ai/upscale`，发送 `model=nai-diffusion-5-curated`、`declared_blur_sigma=0`，固定 2 倍；源图面积上限 3,145,728 像素。费用按源图面积为 1 / 2 / 3 / 4 Anlas，Opus 同样收费。界面倍数、禁用条件和费用同步修正。HTTP 200 的 JSON / HTML 不再被误注册成图片。
2. **大图增强的上传体积过大。** 源图重采样后使用低压缩 PNG，再转 base64 JSON 上传。本轮同像素 RGBA 图片以压缩 PNG + 官网 `image` / `request` multipart 协议成功完成 2 倍增强；仅给已成功的 JSON 增加空白也发生断线，支持上传体积影响稳定性的判断，不能据此推断固定服务端大小限制。生产代码采用二进制源图与遮罩，并提高重采样 PNG 压缩；像素、透明度和提示词不变。文生图保持原请求协议。流式与非流式共用包装流程。
3. **生成变体可能沿用当前草稿。** 旧路径把提示词导入排进微任务，立即生成时仍可读到旧稿。现在等待共享元数据导入完成，恢复所选图片的正负提示词、角色、坐标与参考参数，再生成；费用投影也使用所选底图的图生图模式。回归曾在修复前复现旧提示词，修复后检查了实际生成投影。
4. **网络异常被显示成 Unknown error / 整页 HTML。** 保留 Socket / TLS 等底层网络原因，流式错误使用公共映射，HTTP 504 等保留状态码而不把网关 HTML 塞进界面。未增加自动重试；断线不保证没有扣费。
5. **此前待交付的桥接图标对齐。** 水平双环下移 1px，对齐“负面”文字的视觉中心，固定槽、命中区域和浮层锚点保持原行为。
