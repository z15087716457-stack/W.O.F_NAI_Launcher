# F20 · 关于页系统信息自动换行

用户截图中的长 Windows 版本挤压 OS 标签。原因是系统信息行把弹性宽度留给标签，右侧值没有宽度约束。本次改成标签占自身宽度、预留 12px 间距，值在剩余宽度内右对齐自动换行；双方顶端对齐，卡片随内容增高。

仅修改 `SettingsAboutPage` 的系统卡片，不裁剪、缩小或省略信息，不修改后端版本数据或其他设置。短信息场景的原 27 张基准截图无需改动，沿用此前获准区域比较后均通过。

登记 SDK 下，设置页／界面边界组合 **247 项通过**；新增专项覆盖五语言、1600／900 窗口及 1.5 倍字号共 15 个场景，以截图中的 Windows 版本及长无空格标识检查完整换行、标签高度、两列边界和下一行不重叠。15 张真实字体组件实绘与中文原尺寸卡片裁片已检查。范围分析无诊断，格式检查通过。

证据在 `.dart_tool/about-system-wrap-20261016/`，含原文件／哈希、最终测试与分析日志、实绘及保护核对。原 27 张 PNG、已有 DEVELOPMENT 修改、安装收据和 r9 AOT 的 30 项保护哈希保持。
