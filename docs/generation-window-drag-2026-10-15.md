# F12 · 主生图页顶部拖窗范围

2026-10-15。用户要求顶部拖窗范围向下接近截图红线，避免必须贴着最上边拖动。已本地修复，随 F07–F11 继续积攒，未构建 Release 或安装；桌面仍为 r7。

## 原因与实现

主画布已有 36px 高的窗口拖动层，但浮动工具条的横向滚动容器强制铺满整行，连两侧空白也被拦截，因此出图后实际主要剩顶部约 10px 可以拖窗。

- 仅将主画布空白拖动层下沿从 36px 延至 44px；不增高窗口按钮或移动工具条、图片与历史栏。
- 工具条居中保持原位，滚动容器按工具条实际宽度收缩，让两侧空白可命中拖动层；窄窗口放不下时仍保留横向滚动。共用底部窄工具条也沿用按实际宽度命中的容器，不改显示布局。
- 窗口拖动层仍在工具条下方；工具按钮、菜单、原生窗口按钮优先处理自己的事件。44px 以下继续交给画布，定位模式及非桌面窗口场景沿用原有条件。
