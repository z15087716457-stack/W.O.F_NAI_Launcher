# Agent 系统图片输入增量（2026-10-14）

本轮是源码增量，尚未装入 2.0 Preview r2 运行包。原生插件继续锁定 0.8.24，无真实模型或 NAI 生成请求。

- 文件选择、剪贴板和外部拖放共用有界读取与逐项导入。文件载荷优先，附件保存原字节 / SHA-256；BMP 原件保留，预览和视觉上传使用独立 PNG 副本。截图 / 复制像素没有原文件编码和元数据保证。
- Ctrl+V、PasteTextIntent 和右键粘贴走同一路径，富剪贴板失败仍可粘贴文本。导入中暂缓所属会话发送；切换后附件归原会话，新会话可独立粘贴。损坏项不阻断后续图片，控制器关闭后不再接纳迟到结果。
- 单图最多 64 MiB / 6400 万像素，文件 / 流读取有超时。OLE 回调快速返回；URL / HTML 单独拖入不下载图片。
- 只对确认的 NAI 图片解析元数据：Software / Source、模型标识与 stealth 特征经现有解析器确认。普通图片不保存自动元数据、不显示元数据入口。默认模型上下文只含文件路径 / 尺寸和少量 NAI 参数；完整提示词按需调用 `image_read(path, metadata_only=true)`，无需视觉模型。
- Windows 的 DIB / DIBV5 继续由原生插件提供 PNG。仅 CF_BITMAP 时，使用只读 GDI 读取原位图，包装 BMP 像素；所有本机锁 / 内存 / DC 及时释放，优先保留已有文件或 PNG 载荷。
