# MCP 自动连接与显示名称

2026-11-01，源码已完成并随本机 **2.2.4+77** 安装；本批未提交 Git 或发布，未自动启动应用。[本机交付核验](local-2.2.4-build77-2026-11-01.md)。

## 结果

- 已选择模型且启用外部 MCP 时，进入 Agent／MCP 设置页会初始化原 Pi 会话，未发送的新聊天也可连接；聊天切换复用同一生命周期。连接在 Pi 内后台握手，状态查询沿用其等待机制，页面显示原有「连接中／已连接／失败」状态，已有连接只查询、不强制重连。
- 服务器编辑框新增「显示名称（可选）」，支持中文；原名称标为「工具标识」。例如界面可写「EXA免费联网搜索」，内部仍是 `exa`；列表显示新名称，状态匹配、连接、OAuth 和工具命名仍用内部标识。
- 显示名保存在既有 MCP 元数据，旧记录默认为空并显示原名；不传入 Pi 连接配置，也不进入运行配置签名。设置页与 `agent_manage` 共用原保存入口，未指定显示名的配置更新保留原值。完整配置编辑仍沿用原凭据保存和下轮生效流程。

## 实现

扩展现有 `loadHistory`／聊天初始化，合并重复的恢复逻辑；MCP 设置页仅在已有控制器或启用服务器时接入原状态查询。保留未配置 MCP 时的惰性启动，不新增连接池、轮询或重试循环。Pi 宿主、工具声明、Skill 和生成链路未改。
