# Agent 会话前置指令

2026-11-01，源码已完成并随本机 **2.2.4+77** 安装；本批未提交 Git 或发布，未自动启动应用。[本机交付核验](local-2.2.4-build77-2026-11-01.md)。

## 行为

- 「指令」页在全局指令下增加「本会话前置指令」，沿用卡片与现有多行文字弹窗；小字说明作用范围和位置，其他入口不变。
- 每个聊天独立保存，新聊天默认空，不复制上一聊天的内容；首次发送前显式保存也会保留该聊天及当前输入草稿。
- 保存后用于后续消息，清空即取消；改名、活动时间更新、切换、重启和删除恢复保留该值。
- 顺序：全局前缀（若有）→ 本会话前置指令 → 基础提示词 → 原全局指令、项目 AGENTS.md 与工作区规则。全局前缀仍作用于所有聊天，仅某一聊天需要的内容填写在新增卡片中。

## 实现边界

`AgentChat.systemPromptPrefix` 存在原 `ui/chats/<id>.json`，旧字段缺省为空。复用 `copyWith` 合并已有聊天更新，不另建配置文件或会话系统；写入处校验编辑起点，并将旧值存到既有 `prompt-history`。

`effectiveSystemPrompt` 接收当前聊天的前缀，原 Pi `setSystemPrompt` 负责运行态刷新；启动、恢复、全局／工作区提示词更新以及新旧最终提示词预览均沿用这一拼接点。Pi 宿主、内置 Skill、工具声明和生成链路未修改；图生图暂停调查按用户决定继续搁置。
