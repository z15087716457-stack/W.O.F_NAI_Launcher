## 缩略图根因与修复

棋盘背景按 8 px 方块绘制，最后一格会超过缩略图的非整数尺寸。`Stack(clipBehavior: Clip.hardEdge)` 仅在布局溢出时裁切，不能拦住 CustomPainter 的绘制越界，因此产生截图中的右侧棋盘条，并污染选中边框。

增加明确的 ClipRect，并限制棋盘画笔绘制区域。图层托盘继续是 94 px 宽、80 px 缩略图长边、3 px 选中边框；未新增工具或图标。
