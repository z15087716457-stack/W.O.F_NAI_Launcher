## 已实现并注册

- snapshot：保存、分页列出、读取配置摘要、明确载入完整配置。当前 draft_version 来自 studio_context(scope=draft)；载入前写完整备份，IO 后重复检查草稿、生成占用、取消和生命周期。切工作区从不自动载入。
- 快照包含 ImageParams 的普通参数和普通 JSON 刻意排除的源图/遮罩/局部框、额外噪声种子、增强状态、Vibe 原图/缩略图/编码及模型、精准参考与标准化标记、参数角色；保留主/负面/角色积木文档、翻译与抽取状态、角色 UI 元数据/坐标模式、质量与 UC 自定义预设、格式转换开关。
- 保存配置携带实际引用的积木定义。后来修改/删除的积木以独立 UUID 的隐藏依赖副本恢复，不覆盖全局库的新内容；重复恢复复用同源同内容依赖。最终应用前再次同步校验实际依赖内容。
- wiki_query：本地百科原文、来源与正文分页，诚实报告缺词和源语言。tag_query：本地统一索引/已同步标签，返回别名、类别、计数、缓存中文名称和简短释义语言，不请求付费翻译。
- Node 只启用 Dart 实际提供的域工具；路由来自实际 schema 定义。设置页展示当前实际工具，并验证 Dart 与 Node 的目录/地图一致。加上三个基础 Studio 工具、ask_user 与 Pi 四个基础工具，E1 当时注册 11 个工具；E2 新增两个积木工具，当前为 13 个。
