## 实现

- 编辑器与 Agent `tag_related` 继续共用 `CooccurrenceCompletionSource`，完整邻接评分后再截取。Jaccard 乘 `log10(1+C/post_count)`，C 为活动词库最大词频，按不可变词库版本缓存；不用估算总帖子数。最高频词仍有正权重，多输入支持来源、类别、排除与别名逻辑保持。工具返回 `algorithm: jaccard_frequency`，分数是关联强度，不是概率。
- Ctrl+左键、完整单标签框选与相关标签侧栏自动采用新排序，无额外 UI 或模式。多标签／部分短语框选仍走既有搜索流程。共现提供搭配，发型同类词等语义扩展仍属于语义检索；`long_hair` 的前排仍可能出现身体／表情词。
- 仅手动 tags 的视觉 ANN 召回允许首轮已有至少 **800** 个候选时返回，目标上限仍为 1000。不足则沿用扩取与原回退；实体、后台推荐及其他集合仍严格取数。没有修改模型、向量格式、重排规则或自动重建索引。
- `session_history(action=outline)` 在截取 200 字之前清理 Studio 完整合法的附件清单信封，并忽略非文本内容块。仅接受既有完整标记、末尾布尔状态与有效 JSON/path 行；损坏或引用的相似文字保留。完整 read/search/read_turn、分页、脱敏及原始会话不变。
