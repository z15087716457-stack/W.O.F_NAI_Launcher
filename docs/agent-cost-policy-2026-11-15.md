# Agent 费用确认策略

仅有效源码完成，未构建／安装；桌面仍为 **2.3.4+103**。没有改写真实用户设置、草稿或自定义系统提示词，没有调用 NAI／模型生成接口。

## 行为

| 权限 | 总报价为 0 | 付费、开关关闭 | 付费、开关开启 |
|---|---|---|---|
| 完全权限 | 直接执行，无费用卡 | 显示费用卡 | 直接执行，无费用卡 |
| 自动／询问 | 保留费用卡 | 保留费用卡 | 保留费用卡 |
| 只读 | 由权限层阻止执行 | 由权限层阻止执行 | 由权限层阻止执行 |

「设置 → NAI Agent → 常规」新增 **付费也无需确认**，默认关闭，仅完全权限生效。沿用现有开关、即时保存、恢复默认和搜索跳转；旧设置缺少此字段时仍为关闭。全局存储字段是 `skipPaidConfirmation`，未加入模型自管理可写字段。

判定使用含参考图、编码等额外费用的总报价，不按生成单价或模型自报值判断。策略在运行时读取当前 Agent 偏好，冷态判断不启动 Agent。生图、变体／增强、画风探索和云端图像工具共用同一规则。

免确认只省去费用卡：保留报价有效期、余额、草稿／账号／参考图／价格复核、备份、原生准入、取消与防重入。启动失败后的重试会重新读取免确认设置。报价及结果用 `full_access_policy` 区分自动授权与 `user_button`，模型传入的授权字段不生效；用户亲自点击提示词组生成仍按原有直接授权执行。

五语言设置与权限提示、内置中英文默认提示词、工具声明和指南已同步；默认提示词版本为 `2026-11-15.1`，已保存的自定义正文保持。
