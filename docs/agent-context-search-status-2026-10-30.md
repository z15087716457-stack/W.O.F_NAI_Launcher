# studio_context 极简检索状态

状态：源码完成并验证，尚未构建或安装；桌面仍为 2.2.2+66。本轮不改变此前资源小窗和服务商输入优化的待交付状态。

按用户最终选择，只扩展 `studio_context` 的返回值。`summary` 和 `draft` 都从同一个生产 `readSummary` 回调读取 `search`，每次读取当前内存快照。结构示例（不是实机状态）：

```json
"search": {
  "gallery": "ready",
  "tags": "ready",
  "wiki": "partial",

```

## 状态含义

| 值 | 含义 |
|---|---|
| `ready` | 已知有向量、索引完整，没有已知错误或资源暂停 |
| `partial` | 已有可检索向量，索引尚不完整或仍在检查/建立 |
| `not_indexed` | 已确认该来源没有向量 |
| `disabled` | 全局检索或该来源已关闭 |
| `busy` | GPU 被占用、资源暂停/忙碌，或正在首次建库且还没有向量 |
| `error` | 该来源有已知故障 |
| `unknown` | 设置/控制器尚未读取，索引状态未知，或正在初始化/重连 |

先用 `ref.exists` 检查设置和控制器是否已存在，再读取已有值。读取上下文不会创建控制器、启动后台加载、扫描、建库或进行检索；没有数量、进度、路径或错误详情。已关闭的来源优先报告关闭，资源忙碌单独标记；实际搜索仍走原有的执行检查。

工具清单、工具声明、系统提示词、MCP 服务摘要和内置 Skill 均未修改。状态只在模型读取上下文时返回，不主动推送、强制搜索或改变 Pi 的按需发现方式。
