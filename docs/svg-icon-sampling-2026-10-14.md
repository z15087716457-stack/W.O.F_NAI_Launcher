# 共用小图标轻微平滑（2026-10-14）

用户指出左上角 NAI / 闪电以及其他图标有毛刺感。对照 13px、四档设备密度与整数 / 半像素位置的组件实绘，区分上一批蒙版 / 虚线几何错误与本批低密度显示下的边缘采样差异。提供原矢量、原尺寸缓存、2 倍与 3 倍采样对照后，用户明确选择“轻微平滑：减少毛刺，沿用原尺寸与线宽”。

## 实现

共用 `UiSvgIcon` 接管 `UiGlyph`、`GenNaiIcon`、图像工具 `ToolsIcon` 间接入口、旧 `UiuxPrototypeIcon`，以及探索预览 / 价格与旧模型胶囊中的小 SVG。当图标尺寸不超过 24px、设备密度低于 1.5 时，沿用当前固定 `flutter_svg` / `vector_graphics` 实现，使用局部 2 倍缓存采样；只改 SVG 子树的采样密度，周围文本 / 控件的 MediaQuery 密度保持。密度 1.5 及以上和更大的图形继续直接矢量绘制，探索页 230px 品牌图未进入小图标策略。

NAI 先前的 SVG 是从 512px PNG 描出的折线。改用本地官方归档 `logo_alt.271425c8.svg` 的原曲线，保留完整路径及填充规则，由控件沿用当前反色配色。原 33×40 素材增加透明水平边距，成为 `viewBox="-3.5 0 40 40"` 方形槽，保证已有 13px / 14px 模型按钮图标位不缩窄。原 PNG 及官方归档保留。

没有改变其他图标路径、线宽、用户字体、按钮尺寸 / 间距、菜单或操作。上一批变体、重绘 / 移除背景虚线、调色板圆点几何修正继续保留；本批是用户选定的呈现采样变化。缓存采样利用现有库的共享与释放流程，不引入依赖、全页模糊或全页离屏纹理；该策略增加小图标缓存面积，真实 Windows GPU 性能随最后构建验收，不将部件测试写成运行窗口性能结论。
