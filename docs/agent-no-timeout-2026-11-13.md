# Agent 移除额外请求计时器

2026-11-13，按用户反馈调整：非流式上游或缓冲转发在完整结果返回前可能没有任何增量，不适合由 Studio 的 120 秒无进展计时器中断。仅更新源码，桌面仍为 2.3.3+100；未安装、启动 Studio、提交 Git或调用真实模型／NAI。

## 最终行为

- 删除 `tool/nai_agent/lib/model.mjs` 中的额外 AbortController、计时器、每次增量续期和专用超时错误分支。直接传递原有取消信号，保留上游错误脱敏、请求许可释放及已收到的部分正文。
- Agent 模型映射不再传入服务商通用 `timeoutSeconds`；旧配置即使仍带该字段，宿主也不会据此设置额外时限。不修改用户保存的服务商设置，以及其他功能使用它的行为。
- 手动停止仍返回 `aborted`，可继续发送下一条。模型正常结束却没有正文／工具调用，或流结束却没有最终结果时，仍报明确空回错误。建议补全和一 Token 缓存保温的空返回例外保持。
- 删除控制器专用超时映射、四份手工 ARB 的句子及元数据，再按既有流程生成繁体和本地化 Dart；空回、图片预算等提示继续保留。

移除的是 Studio 自己增加的等待计时器，没有改 Pi／底层 SDK 的既有 HTTP 连接策略，也没有改服务端、代理或系统的超时策略。Studio 仍使用已有的流式传输协议；此次验证的是上游缓冲、长时间无增量后才返回的情况，不宣称新增非流式 JSON 协议解析能力。
