# 本地画廊大图尺寸修复

主画廊打开详情时，索引和当前记录可能暂时没有宽高，而详情的生成参数异步读取。旧回退逻辑（66f1ea53e）在胶片条微缩图就绪时把它的尺寸写入大图条目，覆盖详情已经拿到的原图尺寸。1216×832 的原图缩略为 80×55，这个宽高同时影响详情面板和主图区的适应缩放，文件字节与生成参数未变化。

已有原图宽高沿用索引快照；缺失时只在查看器读取原文件，先读文件头，必要时补读原文件。内存图片仍直接读编码尺寸，资源小窗复用同一文件读取方法。微缩图回填只更新缩略图。无需清缓存、改图或重建图库。

隔离 PNG 与真实微缩图的回归改前出现 80×55，改后在微缩图就绪且原图完成渲染后，尺寸栏保持 1216×832、主图区保持适应尺寸，原种子仍可读。大图、生成历史、资源小窗、缩略图与分辨率共 222 项测试通过。修复仅在源码，尚未安装桌面或公开发布。
