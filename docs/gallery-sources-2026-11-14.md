## 实现

- 浏览来源统一使用 `gallery_source_paths_v2`；旧配置首次读取延续保存目录及额外来源的覆盖范围，父子目录只保留父目录作为扫描／监听范围。读取不落盘，首次修改时迁移；显式空列表代表没有浏览来源。
- 图片保存位置独立；变更前固定旧分类路径基准 `gallery_category_base_path_v1`，既有相对分类与 `.gallery_categories.json` 仍使用原目录。变更保存位置不自动添加新来源，也不迁移旧图或重建分类 ID。
- 来源移除只退出浏览和监听；旧分类记录在配置中保留，再添加时沿用原 ID。设置页和旧来源卡共用同一规则，原保存目录同样提供移除按钮。
- 文件事件同步按分类 ID 保留记录，路径映射允许既有同路径节点共存；修复被普通节点覆盖的未分类记录时复用已有 ID。完整扫描、文件事件与重新加载都保留专用入口。
- 移除来源时实际刷新图库服务的内存文件列表，不只失效页面 Provider；保留数据库记录、收藏及磁盘文件。未收录目录的新保存图片也不会经即时添加入口重新混入图库。
