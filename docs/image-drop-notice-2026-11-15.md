# 图片拖入轻浮条

状态：按用户确认的「轻浮条」方案完成源码，未构建／安装；桌面仍为 **2.3.4+103**。

## 当前行为

- 全局拖入时，接收区内缩10px，使用1px淡蓝边框与4%高亮；底部显示「松开以导入图片／下一步选择图片用途」。移出或拖放结束后清除。
- 松开后沿用同一浮条，图片图标换为现有小进度圈，文案切为「正在准备图片／读取完成后选择用途」；撤掉蓝色高亮与旧版全屏黑色遮罩，保留处理中阻止底层点击的行为。读完或失败后收起，目标选择弹窗仍逐张显示。
- 浮条最大326px宽、距底26px；窄接收区收紧边距，长文案自然换行。复用 `UiCard`、`UiGlyph`、`UiSpinner`、`UiColors` 与 `UiText`；没有新增色板、图标资源或依赖。
- 五语言文案同步，台湾正体由既有流程生成。前次[拖放读取时序修正](external-drop-freeze-2026-11-15.md)保持：回调内启动全部读取、处理期间拒绝重入、导入逐张执行。

实现入口：`lib/presentation/ui/kit/ui_image_drop_overlay.dart`；`GlobalDropHandler` 仅把已有拖入／处理状态交给该纯界面组件，移除两套旧覆盖层。
