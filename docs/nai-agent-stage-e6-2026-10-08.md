- `block_query(kind=tree)` 返回 `library_version`。`block_manage` 接目录和收藏树创建／改名／移动／完整同级重排，空目录删除、收藏子树删除及明确添加／移除成员。收藏加入同时标记原生收藏，移出不清收藏旗标，删收藏树保留积木本体。完整备份后在实际 Hive 写入前检查最新整个库和取消；原生父级、循环引用、完整排序校验复用。集合成员与收藏旗标在一次 Hive 批量写入中提交。
- `wiki_query(include_examples=true)` 只为一个词条获取官方示例元数据；默认仍读取离线正文。返回源链接、描述、可用状态、静态缩略图／预览 URL 及 `wiki:*` 图像 ID，可分页。`image_read` 按 ID 读取官方 720px 静态预览，复用现有缓存和图片上传管线。普通帖子链接不被替换为示例；缺失图片保留文字和来源，网络失败不影响本地正文。只在模型明确调用后获取像素，不批量下载；不带 NovelAI 凭据。缓存下载本身沿用原生行为，停止会放弃等待，不承诺中断其内部网络传输。
- `explore_manage` 接原生探索列表、分页详情、当前配方建 Run、改名／完成、候选收藏与文件夹管理；候选实际像素通过 `explore:*` ID 调用 `image_read`。执行沿用原生运行器和当前 Studio 参数／配方，创建快照只记录当时配置，不伪称运行器始终使用旧快照。只读查询不初始化恢复运行器，也不更改选中的 Run 或画布。
- 探索 `prepare` 报告基础轮、续跑、失败重试或已有家族深度轮的总请求量／费用／余额；`run(quote_id)` 等待已有真实授权卡片，备份后重新校验版本和费用并进入原生运行器。每张请求前检查参数、配方、库、账号、端点和余额。运行器保留原有抽取与深度轮 guard；Agent Stop／pause／cancel 只控制本会话同步取得的原生 session，旧会话不能中断后来的手动任务；探索未结束时也核对每张主生成的 run ID 和 notifier 身份，手动接管主生成后不误停该任务。部分结果保留，返回本次新图，最多 100 条，余下按详情分页。失败不会自动重放或续跑。
