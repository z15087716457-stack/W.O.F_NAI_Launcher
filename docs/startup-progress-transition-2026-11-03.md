# 启动进度平滑过渡

日期：2026-11-03。配合 2.2.5 发布，解决启动优化后进度从 0% 瞬间到 100%、原有背景去噪来不及展现的问题。

## 实现

- 在现有 `SplashScreen` 使用一个 450ms、`easeOutCubic` 的 `TweenAnimationBuilder`，进度条、百分比、STEP 和背景共用同一显示值。真实预热状态、任务、错误和账号验证仍走原来的 provider。
- `AppBootstrap` 等真实加载、原账号验证条件与显示进度都完成后切页；没有额外的固定片头、定时假进度、服务或 provider。系统关闭动画时使用零时长过渡。
- 完成通知根据实际呈现的 100% 发出，兼容进度先到 100%、稍后才标记完成的顺序；不会因为这时没有新的动画结束事件而停留在载入页。
- Logo、文字、布局、像素进度条、背景和原有页面切换保持。生产改动仅两个现有载入页文件，版本更新为 `2.2.5+80`。

## 验证

本轮 110 项不同回归通过：载入／登录、启动服务与版本共 55 项；版本／Portable 更新和回退 45 项，其中 5 项版本重复；Agent 指令导航和会话前置指令 15 项。新增四项动画回归覆盖中间帧同步、完成前不切页、关闭动画与先到 100% 的完成顺序。

使用真实字体实绘明暗、窄窗及各语言原有入口，检查了过渡中间帧；没有替换原视觉基准或扩大排除区域。材料在 `.dart_tool/release-2.2.5/`，实绘在 `.dart_tool/brand-entry-captures/`。

首轮动画测试恰好在 450ms 边界检查完成通知，下一帧前回调尚未到达；保留原日志，终点检查留出一帧余量。全仓分析另发现旧 Agent 导航测试遗漏新增的 `chatPrefix` 枚举：该项为原位编辑，已由独立测试覆盖；导航测试改为直接列出四个导航目标与预期锚点，15 项调用链回归通过，没有因此修改产品逻辑。

发布准备另通过全仓 `flutter analyze --no-pub`、LFS fsck、四个 SQLite 资源头检查、变更文本凭据模式扫描及完整更新说明／清单夹具。相对已安装 +79，2,119 个生产输入中仅两个载入页文件与版本变化；Pi 1.5.0 等累计功能的专项证据按相同源码复用，不冒称本轮重跑。未请求真实模型／NovelAI，未启动或操作用户应用。
