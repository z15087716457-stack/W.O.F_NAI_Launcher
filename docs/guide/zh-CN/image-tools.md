# 图像工具

## 风格迁移与精准参考

- **风格迁移（Vibe）**：参考一张或多张图的风格和氛围。可以调强度和信息提取量；编码一次后可以重复使用，不再额外花 Anlas。
- **精准参考**：参考角色或画风，可以调保真度，每张计费。
- 同时设置时，精准参考优先，风格迁移不会发送（界面会提示）。

左侧导航的“Vibe 库”和“精准参考库”分别管理两类参考图，可以搜索、分组、导入导出 Vibe 整包。

## 导演工具

<img src="../../images/readme/zh/tools-director.webp" alt="导演工具" width="100%">

NovelAI 的七种导演工具：背景移除、杂线清理、线稿提取、草图化、上色、表情修复，以及本机运行的像素对齐。Opus 订阅在 1MP 以内大部分免费（背景移除始终计费）。处理结果可以复制、保存、加入输入队列或直接作为图生图。

## 局部重绘与编辑

<img src="../../images/readme/zh/tools-inpaint.webp" alt="局部重绘编辑器" width="100%">

全屏编辑器，工具齐全：画笔、橡皮、填充、魔棒（可选智能对象模式，首次使用下载约 133 MB 模型）、选区、套索、仿制图章、模糊、图层、画布尺寸、色相饱和度。

画完蒙版后可以“应用”，或者直接“应用并生成”。生成结果在画布上按住即可对比原图。

## 放大

<img src="../../images/readme/zh/tools-upscale.webp" alt="放大" width="100%">

| 方式 | 说明 | 要求 |
| --- | --- | --- |
| NovelAI 放大 | 云端 2 倍放大，按图片大小计费 | 登录 |
| 本地 · Real-ESRGAN | 内置引擎和模型（动漫画质、动漫快速、通用摄影），1–4 倍，保留透明度，不花 Anlas | 支持 Vulkan 的显卡 |
| 本地 · RTX | NVIDIA RTX Video 快速放大，需下载约 64 MB 组件 | NVIDIA RTX 显卡 |
| 本地 · SeedVR2 | 高质量放大，3B / 7B / 7B Sharp 多种型号（权重 3.4–8.2 GB），有色彩校正、显存策略等高级设置 | NVIDIA 显卡（INT8 版需 Turing 或更新） |

本地放大的组件和模型都在“设置 → 本地放大”里按需下载。也可以在生成页“增强”里选择本地方案，让每张图生成后自动在本机放大。
