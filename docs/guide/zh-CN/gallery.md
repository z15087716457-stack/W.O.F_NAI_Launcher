# 画廊

## 本地画廊

<img src="../../images/readme/zh/gallery.webp" alt="本地画廊" width="100%">

入口：左侧导航的“本地画廊”（`Ctrl+2`）。

**浏览**

- 左边是资料库、收藏集和文件夹，中间是连续的图片时间线，右边是详情；
- 可以按天、按月分组或不分组，拖右侧时间轴快速定位，`Ctrl+G` 跳到指定日期；
- 三种排版：火车流（等高行、不裁切）、网格、瀑布流；缩略图大小和清晰度可调。

**查找**

- 按文件名或提示词搜索，角色提示词也能搜；
- 筛选：仅 NAI 图、模型版本、日期范围、标签；
- 开启 [本地语义检索](rag.md) 后可以按画面内容找图，或选一张图找相似。

**整理**

- 支持多个图库文件夹（“设置 → 图库源管理”）；新图默认存进主图库的“未分类文件夹”；
- 文件夹就是分类，可以新建、移动、复制；
- 收藏：红心 + 收藏集，收藏集可以无限嵌套；
- 多选后可以批量移动、打包、编辑元数据、加入收藏集；
- 删除的图先进“删除池”，可以恢复，下次启动时才真正删除。

**复用**

- 详情面板显示完整的生成参数，可以“复用参数”、复制提示词或种子；
- 一键用作图生图、风格迁移、精准参考，或存入参考图库；右键“放入画布”；
- 拖到生图页时会弹出窗口让你选择导入哪些内容（种子默认不勾选）。

<img src="../../images/readme/zh/viewer.webp" alt="大图查看" width="100%">

常用按键：单击选中，双击 / 空格 / 回车看大图，方向键切换，`Delete` 删除，`Ctrl+A` 全选，`Esc` 退出多选。

## 在线画廊

<img src="../../images/readme/zh/online.webp" alt="在线画廊" width="100%">

入口：左侧导航的“在线画廊”（`Ctrl+3`）。

- **来源**：Danbooru、Safebooru、Gelbooru、AI TAG；
- **浏览**：标签搜索（同样支持标签扩展）、日 / 周 / 月排行榜、热门；
- **收藏**：本地收藏（无需站点账号，离线可看）和站点收藏；AI TAG 可以收藏作者并查看他的作品；
- **黑名单**：屏蔽不想看到的标签；
- **复用**：作品带生成参数时可以直接复用；多图作品逐张切换；
- **批量下载**；
- 标签和提示词悬停显示翻译按钮，点了才翻译。

Danbooru 登录、Gelbooru API 凭据都只保存在本地。
