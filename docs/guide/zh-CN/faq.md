# 常见问题

### 运行时 Windows 提示“已保护你的电脑”

安装包和程序暂未做代码签名。点“更多信息 → 仍要运行”即可。如果想确认文件没被篡改，对照 Release 页面附带的 SHA-256 校验值。

### 安装版和便携版有什么区别

功能完全一样。安装版装到 `%LOCALAPPDATA%\Programs\W.O.F NAI Studio`，有开始菜单和卸载入口；便携版解压到哪里都能运行。两者都支持应用内更新。

### 我的数据存在哪里，怎么备份

- 设置、图库数据库、积木库：程序目录下的 `user-data/`
- NAI Agent：程序目录下的 `agent-data/`
- 图片：你设置的图库文件夹

把这三处复制走就是完整备份。升级和卸载都不会删除 `user-data/` 和 `agent-data/`。

### 从旧版（1.x）升级

直接安装新版即可。旧版放在 AppData 里的数据，会在首次启动时完整备份、校验后迁移到 `user-data/`。旧的安装版也能通过应用内更新升级。

### 一次生成到底花多少 Anlas

生成按钮上实时显示本次总消耗（张数 × 每张价格，含参考图编码等）。可以在设置里打开“Anlas 高消耗警告”，超过设定值时先确认。NAI Agent 和外部桥接生成图片时也都要你在价格卡上确认。

### 哪些功能会联网

- NovelAI 接口（生成、账号、放大、导演工具）
- 你自己配置的大模型服务（翻译、反推、NAI Agent）
- 在线画廊来源（Danbooru、Safebooru、Gelbooru、AI TAG）
- 检查更新（本仓库的 GitHub Releases）
- 你主动点击下载的可选组件（语义检索模型和环境、放大模型、魔棒模型）

语义检索、本地放大、图库整理都在本机完成。Danbooru 在线关联标签只发送相关标签，不发送完整提示词，可以在“设置 → 词库与缓存”关闭。

### 我的账号和密钥安全吗

NovelAI Token、密码和各家 API 密钥都保存在 Windows 系统安全存储中，只在本机使用。MCP 配置保存在加密存储中。

### 需要什么显卡

生成在 NovelAI 云端完成，对显卡没有要求。只有可选的本地功能需要：本地放大需要支持 Vulkan 的显卡；RTX 放大需要 NVIDIA RTX 显卡；SeedVR2 需要 NVIDIA 显卡；语义检索有 NVIDIA 显卡更快，没有也能用 CPU。

### 界面语言怎么切换

“设置 → 外观”里可以选简体中文、繁體中文、English、日本語、한국어，以及浅色、深色或跟随系统。

### 遇到问题怎么反馈

请到本仓库的 [Issues](https://github.com/z15087716457-stack/W.O.F_NAI_Launcher/issues) 提交，附上版本号、操作步骤和截图。不要在截图里露出你的 Token 或密钥。
