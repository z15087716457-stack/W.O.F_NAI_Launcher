# 标签扩展与标签百科

软件随附完整的离线标签库、标签共现数据和 Danbooru Wiki，不联网也能查标签。

## 标签扩展

<img src="../../images/readme/zh/tag-expansion.webp" alt="标签扩展" width="100%">

在提示词框里：

- **Ctrl+单击**一个标签：打开本地标签搜索，可以输入中文或英文找标签和别名，按 `Tab` 补全，点击插入；
- **Ctrl+拖选**一段：查看“关联标签”，也就是哪些标签常和它一起出现；
- 弹层里还有“标签小百科”，直接看这个标签的解释。

普通打字时不会弹出自动补全，不打扰写作。同样的标签搜索也用在本地画廊搜索、在线画廊搜索、黑名单和积木库里。

**数据来源**：

- 离线合并的 Danbooru / e621 标签与别名库；
- 离线共现数据（哪些标签常一起出现）；
- 中文语义补充资料（约 5.4 万条标签的同义词和简短释义）；
- 可选的 Danbooru 在线关联标签：只发送相关标签，不发送完整提示词，可在“设置 → 词库与缓存”关闭。

开启 [本地语义检索](rag.md) 后，标签推荐还会结合你光标附近的提示词内容，推荐更贴合语境的标签。

## 标签百科

<img src="../../images/readme/zh/wiki.webp" alt="标签百科" width="100%">

入口：左侧导航的“标签百科”。

- 按官方分组目录浏览，或搜索标签和别名；可以筛选“有释义 / 暂无释义”，按热度或名称排序；
- 正文可以切换译文、原文、对照显示（需要配置“百科翻译”模型；自动翻译默认关闭）；
- “常一起出现”列出关联标签：点击查看，`Shift+点击`添加到积木；
- 加书签、建书签集；
- “添加到积木”会预填好标签，打开积木保存窗口；
- 示例图片在需要时才加载。

快捷键：`/` 搜索 · `↑↓` 切换 · `Enter` 添加到积木 · `B` 收藏 · `Alt+←/→` 前进后退。

## 更新数据

“设置 → 词库与缓存”里可以检查并更新标签和 Wiki 数据，查看各级缓存并清理。更新只在你点击时进行，不会自动下载。你自己的译文在刷新时会保留。
