# 画风遗传（画风探索）

画风探索帮你回答一个问题：**哪几位画师混在一起最好看？** 先用随机画师池批量抽候选，你挑出喜欢的，程序再让它们“杂交、变异”出下一代。你只负责挑，画风会一代代朝你想要的方向靠拢。

<img src="../../images/readme/zh/explore-main.webp" alt="画风探索" width="100%">

入口：左侧导航的“画风探索”。探索页和生图页共用同一份提示词和参数。

## 准备：放一个随机积木

在提示词里插入一个随机模式的积木，比如一个装了几十位画师的画师池（怎么做见 [积木](blocks.md)）。例如：

```
1girl, solo, silver hair, starry sky, night, {画师池·示范}, very aesthetic, masterpiece
```

画师池设成随机，每次抽 2–3 个，带随机权重。

## 第一步：抽候选

点左下角“抽 N 张候选”。每一张都会重新抽画师，所以每张画风都不一样。数量旁边会显示预计消耗的 Anlas，余额不够时按钮变红。

候选出来以后：

- 单击查看，右侧检查器会写出这张图**抽到了哪些画师**、种子和完整提示词；
- 点红心收藏；按 `1`–`9` 快速归到不同分组；
- 网格太挤可以切换卡片大小；双击看大图。

## 第二步：开始进化

挑几张喜欢的（多选），点“开始进化”：

1. 每张候选抽到的画师串就是一个**父本**；
2. 子代由父本**交叉**（两个父本各取一部分）、**变异**（调权重、偶尔去掉一位）和**注入新画师**得到；
3. 勾选喜欢的子代，**培育下一代**。

<img src="../../images/readme/zh/explore-evolution.webp" alt="进化线" width="100%">

几个规则：

- 每个父本至少会分到一张子代，所以父本越多，一轮需要的张数越多；
- 只能从最新一代建下一代，旧的代可以看、不能从中间岔出去；
- 如果提示“产不出足够不同的子代”，说明基因池太小了，给画师池多加几位画师；
- 提示词里可以有多个积木都设为“遗传目标”（顺序或随机积木都可以），它们抽到的结果会合并成一个父本串。

> 想再手动加一个父本？在开始进化的对话框里点“再加一段自定义画师串”，例如 `0.8::artist:sample_alpha::, artist:sample_beta`。

## 第三步：两两比较（可选）

拿不定主意时点“两两比较排序”：每次并排看两张父本的图，选更接近你想要的那张。偏好越高的父本，培育下一代时越常被选中。结果随时保存，可以中途关掉。

<img src="../../images/readme/zh/explore-compare.webp" alt="两两比较" width="100%">

## 第四步：收获

找到满意的画风后，点“存为块”：

- **只要抽到的画师**：存成一个画师积木；多选几张时会合并去重；
- **完整正向提示词**：只有一张候选时可用。

存好的积木回到生图页就能直接用。

## 常见问题

- **按钮灰着不能进化**：提示词里没有启用中的顺序或随机积木，或者没有开启遗传。
- **删除探索会删我的图吗**：不会。删除只删探索任务里的候选副本，本地画廊里的原图不受影响。
- **第一代都不好看**：正常。多挑几代再下结论，变异常常带来意外。
- **探索会改我生图页的草稿吗**：进化轮在独立的数据里运行，不会改你当前积木的锁定状态和抽取结果。

算法思路参考 [monineko/PromptCard-Studio](https://github.com/monineko/PromptCard-Studio)（GPL-3.0），本项目为独立的 Dart 实现。
