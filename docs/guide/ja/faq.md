# よくある質問

### 実行時に Windows が「Windows によって PC が保護されました」と表示します

インストーラーとプログラムにはまだコード署名がありません。「詳細情報 → 実行」をクリックしてください。改ざんされていないことを確かめたい場合は、Release ページの SHA-256 チェックサムと照合してください。

### インストーラー版とポータブル版の違いは何ですか

機能はまったく同じです。インストーラー版は `%LOCALAPPDATA%\Programs\W.O.F NAI Studio` にインストールし、スタートメニューとアンインストールの入口を作成します。ポータブル版は好きな場所に展開して実行できます。どちらもアプリ内更新に対応しています。

### データの保存先とバックアップ方法を教えてください

- 設定、ギャラリーデータベース、ブロックライブラリ：プログラムフォルダーの `user-data/` です。
- NAI Agent：プログラムフォルダーの `agent-data/` です。
- 画像：自分で設定した画像フォルダーです。

この 3 か所をコピーすれば完全なバックアップになります。アップグレードやアンインストールでも `user-data/` と `agent-data/` は削除されません。

### 旧版（1.x）からのアップグレード方法

そのまま新版をインストールしてください。旧版の AppData 内のデータは、初回起動時に完全なバックアップと検証を行ってから `user-data/` に移行します。旧インストーラー版からもアプリ内更新でアップグレードできます。

### 1 回の生成で Anlas はいくらかかりますか

生成ボタンに今回の合計消費量をリアルタイムで表示します（枚数 × 1 枚あたりの価格、参照画像のエンコードなどを含みます）。設定の「Anlas コストが高いという警告」を有効にすると、設定値を超える前に確認します。NAI Agent や外部ブリッジからの画像生成でも、価格カードで本人の確認が必要です。

### どの機能が通信しますか

- NovelAI API（生成、アカウント、拡大、ディレクターツール）です。
- 自分で設定した大規模言語モデルサービス（翻訳、プロンプト逆推定、NAI Agent）です。
- オンラインギャラリーのソース（Danbooru、Safebooru、Gelbooru、AI TAG）です。
- 更新確認（本リポジトリの GitHub Releases）です。
- 自分でダウンロードを選んだオプションコンポーネント（セマンティック検索のモデルと環境、拡大モデル、マジックワンドのモデル）です。

セマンティック検索、ローカル拡大、ギャラリー整理はすべて PC 上で行います。Danbooru のオンライン関連タグには関連するタグだけを送り、プロンプト全体は送りません。「設定 → 辞書とキャッシュ」でオフにできます。

### アカウントとキーは安全ですか

NovelAI Token、パスワード、各サービスの API キーは Windows のシステムセキュアストレージに保存し、この PC 上でのみ使用します。MCP 設定は暗号化ストレージに保存します。

### どのような GPU が必要ですか

生成は NovelAI のクラウドで行うため、GPU の要件はありません。オプションのローカル機能だけが GPU を使います。ローカル拡大には Vulkan 対応 GPU、RTX 拡大には NVIDIA RTX GPU、SeedVR2 には NVIDIA GPU が必要です。セマンティック検索は NVIDIA GPU があると高速ですが、なくても CPU で使えます。

### 表示言語を切り替えるには

「設定 → 外観」で简体中文、繁體中文、English、日本語、한국어を選べます。ライト・ダーク・システムに合わせる設定もあります。

### 問題を報告するには

本リポジトリの [Issues](https://github.com/z15087716457-stack/W.O.F_NAI_Launcher/issues) に、バージョン、操作手順、画面画像を添えて報告してください。Token やキーが画像に写らないようにしてください。
