# ギャラリー

## ローカルギャラリー

<img src="../../images/readme/en/gallery.webp" alt="ローカルギャラリー" width="100%">

入口は左ナビゲーションの「ローカルギャラリー」（`Ctrl+2`）です。

**閲覧**

- 左側にライブラリ、コレクション、フォルダー、中央に連続した画像タイムライン、右側に詳細があります。
- 日別・月別・グループなしを選べます。右側のタイムラインをドラッグしてすばやく移動し、`Ctrl+G` で指定日へ移動できます。
- 同じ高さの行に並べるクロップなしの表示、グリッド、ウォーターフォールの 3 方式があります。サムネイルのサイズと画質も調整できます。

**検索**

- ファイル名やプロンプトで検索できます。キャラクターのプロンプトも対象です。
- NAI 画像のみ、モデルのバージョン、日付範囲、タグで絞り込めます。
- [ローカルのセマンティック検索](rag.md)を有効にすると、画像の内容から探したり、選んだ画像に似た画像を探したりできます。

**整理**

- 複数の画像フォルダーに対応しています（「設定 → ギャラリーソース」）。新しい画像は既定でメインライブラリの「未分類フォルダー」に保存します。
- フォルダーが分類となり、作成・移動・コピーができます。
- お気に入りはハートとコレクションで管理します。コレクションは階層数の制限なく入れ子にできます。
- 複数選択で一括移動、アーカイブ作成、メタデータ編集、コレクションへの追加ができます。
- 削除した画像はいったん「ゴミ箱」に入り、復元できます。実際に削除するのは次回起動時です。

**再利用**

- 詳細パネルに完全な生成パラメータが表示され、「パラメータを再利用」したり、プロンプトやシードをコピーしたりできます。
- ワンクリックで画像から画像生成、Vibe 転送、精密参照に使うか、参照ライブラリへ保存できます。右クリックの「キャンバスに配置」も使えます。
- 画像生成ページへドラッグすると、読み込む内容を選ぶウィンドウが開きます（シードは初期状態では選択されません）。

<img src="../../images/readme/en/viewer.webp" alt="大きな画像の表示" width="100%">

主な操作：クリックで選択、ダブルクリック / スペース / Enter で大きく表示、矢印キーで切り替え、`Delete` で削除、`Ctrl+A` ですべて選択、`Esc` で複数選択を終了します。

## オンラインギャラリー

<img src="../../images/readme/en/online.webp" alt="オンラインギャラリー" width="100%">

入口は左ナビゲーションの「オンラインギャラリー」（`Ctrl+3`）です。

- **ソース**：Danbooru、Safebooru、Gelbooru、AI TAG に対応しています。
- **閲覧**：タグ検索（タグ拡張にも対応）、日 / 週 / 月のランキング、人気作品を使えます。
- **お気に入り**：ローカルのお気に入り（サイトのアカウント不要、オフライン閲覧可）とサイトのお気に入りを使えます。AI TAG では作者をお気に入りにして作品を見られます。
- **ブラックリスト**：見たくないタグを非表示にします。
- **再利用**：生成パラメータ付きの作品は直接再利用できます。複数画像の作品は 1 枚ずつ切り替えられます。
- **一括ダウンロード**ができます。
- タグやプロンプトにマウスを重ねると翻訳ボタンが表示され、クリックしたときだけ翻訳します。

Danbooru のログイン情報や Gelbooru の API 認証情報は、ローカルにだけ保存します。
