# 画像ツール

## Vibe Transfer と精密参照

- **Vibe Transfer（Vibe）**：1 枚または複数の画像の画風や雰囲気を参照します。強さと情報抽出量を調整できます。一度エンコードすれば再利用でき、追加の Anlas はかかりません。
- **精密参照**：キャラクターや画風を参照し、忠実度を調整できます。画像ごとに課金されます。
- 両方を設定した場合は精密参照が優先され、Vibe Transfer は送信されません（画面にも表示します）。

左ナビゲーションの「Vibe ライブラリ」と「精密参照ライブラリ」でそれぞれの参照画像を管理します。検索、グループ分け、Vibe パッケージ全体の読み込み・書き出しができます。

## ディレクターツール

<img src="../../images/readme/en/tools-director.webp" alt="ディレクターツール" width="100%">

NovelAI の 7 種類のディレクターツールを使えます。背景除去、不要な線の除去、線画抽出、スケッチ化、着色、表情修正と、ローカルで動作するピクセル整列です。Opus サブスクリプションでは 1MP 以下の処理は大部分が無料です（背景除去は常に課金されます）。結果はコピー、保存、入力キューへの追加、画像から画像生成への直接利用ができます。

## インペイントと編集

<img src="../../images/readme/en/tools-inpaint.webp" alt="インペイントエディター" width="100%">

全画面エディターに、ブラシ、消しゴム、塗りつぶし、マジックワンド（スマートオブジェクトモードも選択可、初回に約 133 MB のモデルをダウンロード）、選択範囲、投げ縄、クローンスタンプ、ぼかし、レイヤー、キャンバスサイズ、色相・彩度を備えています。

マスクを描いたら「適用」、またはそのまま「適用して生成」を選べます。生成結果をキャンバス上で押し続けると、原画像と比較できます。

## アップスケール

<img src="../../images/readme/en/tools-upscale.webp" alt="アップスケール" width="100%">

| 方式 | 説明 | 必要条件 |
| --- | --- | --- |
| NovelAI の拡大 | クラウドで 2 倍に拡大し、画像サイズに応じて課金されます | ログイン |
| ローカル · Real-ESRGAN | エンジンとモデルを内蔵（アニメ高画質、アニメ高速、汎用写真）し、1–4 倍に拡大します。透明度を保持し、Anlas は使いません | Vulkan 対応 GPU |
| ローカル · RTX | NVIDIA RTX Video で高速に拡大します。約 64 MB のコンポーネントのダウンロードが必要です | NVIDIA RTX GPU |
| ローカル · SeedVR2 | 高画質の拡大です。3B / 7B / 7B Sharp などのモデル（重み 3.4–8.2 GB）があり、色補正や VRAM 方針などの詳細設定を使えます | NVIDIA GPU（INT8 版は Turing 以降） |

ローカル拡大のコンポーネントとモデルは、「設定 → ローカル拡大」で必要に応じてダウンロードします。画像生成ページの「エンハンス」でローカル方式を選ぶと、生成後に各画像を自動で PC 上で拡大できます。
