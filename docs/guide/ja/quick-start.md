# クイックスタート

## 1. インストール

[Releases](https://github.com/z15087716457-stack/W.O.F_NAI_Launcher/releases/latest) からダウンロードします。

- **インストーラー版** `WOF_NAI_Studio_Windows_<バージョン>_Setup.exe`：ダブルクリックしてインストールします。既定の保存先は `%LOCALAPPDATA%\Programs\W.O.F NAI Studio` で、管理者権限は不要です。
- **ポータブル版** `WOF_NAI_Studio_Windows_<バージョン>_Portable.zip`：好きなフォルダーに展開し、中の `nai_launcher.exe` を実行します。

対応 OS：Windows 10 または 11（64 ビット）。

> インストーラーにはまだ署名がありません。Windows が「Windows によって PC が保護されました」と表示したら、「詳細情報 → 実行」をクリックしてください。改ざんが心配な場合は、Release ページに添付された SHA-256 チェックサムと照合できます。

## 2. ログイン

- **API Token（推奨）**：NovelAI サイトのアカウント設定で、`pst-` で始まる Persistent Token を作成して貼り付けます。
- **アカウントとパスワード**：公式サイトと同じものを使います。
- **ゲストモード**：ログインページでログインをスキップし、ギャラリー、ブロック、タグ百科などのローカル機能を試せます。画像生成にはログインが必要です。

Token とパスワードは Windows のシステムセキュアストレージに保存し、この PC 上でのみ使用します。

## 3. 初めての生成

<img src="../../images/readme/en/hero.webp" alt="画像生成ページ" width="100%">

1. 左上でモデルを選びます（V4.5 または V5 を推奨）。
2. プロンプト欄に英語のタグを書きます。例：
   ```
   1girl, solo, silver hair, starry sky, glowing flowers, night, cinematic lighting, very aesthetic, masterpiece
   ```
3. 下でサイズ、枚数、ステップ数を設定します。生成ボタンに今回の Anlas 消費量がリアルタイムで表示されます。
4. `Ctrl+Enter` を押すか、生成をクリックします。生成中は `Esc` でキャンセルできます。

結果は中央のキャンバスに表示され、右側には履歴が並びます。操作方法は[無限キャンバス](canvas.md)を参照してください。

## 4. すぐに使えるヒント

- **重みの調整**：プロンプトの一部を選択し、`Alt` を押しながらホイールを回します。
- **ブロックの保存**：プロンプトの一部を選び、右クリックして「ブロックとして保存」を選びます。次からはライブラリでクリックするだけで挿入できます。詳しくは[ブロック](blocks.md)を参照してください。
- **画像のドラッグ**：ウィンドウに画像をドラッグすると、画像から画像生成、バイブストランスファー、精密参照、またはプロンプトとパラメータだけの読み込みを選べます。
- **ショートカット**：`F1` ですべてのショートカットを確認できます。`Ctrl+1/2/3` で画像生成・ローカルギャラリー・オンラインギャラリーを切り替え、`Ctrl+,` で設定を開きます。
- **Anlas の誤消費を防ぐ**：設定で「Anlas コストが高いという警告」をオンにすると、1 回の推定消費が設定値を超える前に確認します。

## 5. データの場所

| 場所 | 内容 |
| --- | --- |
| プログラムフォルダー内の `user-data/` | 設定、ギャラリーデータベース、キャッシュ、ブロックライブラリなど |
| プログラムフォルダー内の `agent-data/` | NAI Agent のワークスペース、チャット履歴、スキル |
| 自分で設定した画像フォルダー | 生成した画像そのもの |

バックアップには `user-data/`、`agent-data/`、画像フォルダーをまとめてコピーします。アップグレードやアンインストールでも、この 2 つのデータフォルダーは削除されません。
