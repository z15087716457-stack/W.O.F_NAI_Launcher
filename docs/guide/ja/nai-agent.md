# NAI Agent

NAI Agent は Studio 内蔵の AI アシスタントです。チャットでやりたいことを伝えると、Studio のツールを使ってプロンプトの修正、タグや百科の検索、ブロックやギャラリーの整理、参照画像の設定、生成の準備などを行います。操作のたびに、何を変更したかを示す**カード**が会話に表示され、ほとんどの変更はワンクリックで元に戻せます。

<img src="../../images/readme/en/gen-agent.webp" alt="画像生成ページの NAI Agent" width="100%">

## 準備

1. 「設定 → モデルと API」で大規模言語モデルのプロバイダーを追加し、モデルを選びます（OpenAI 互換 API、Responses、Anthropic、Gemini、Ollama に対応）。
2. 画像生成ページまたは画風探索ページの上部にある「NAI Agent」ボタンをクリックすると、右側にサイドバーが開きます。
3. サイドバー下部で使うモデルを選び、チャットを始めます。

Agent はご自身のモデルサービスを使います。会話の料金は、そのサービスの価格に従います。

## 頼めること

たとえば、次のように頼めます。

- 「今のプロンプトを雨の夜の街角の雰囲気にして、キャラクターの説明は残してください」
- 「`wet hair` の百科を調べて、もっとよく使う書き方があるか教えてください」
- 「ブロックライブラリの絵師ブロックをすべて『画風』フォルダーへ移してください」
- 「この画像を Vibe 転送の参照にしてください」（画像を直接貼り付けたり、ドラッグしたりできます）
- 「先週作った夜景の画像をギャラリーからすべて探して、新しいフォルダーへ移してください」
- 「今の設定で 4 枚生成する準備をして、見積もりを出してください」
- 「雨の夜のカフェを舞台に、8 つの場面からなる短い物語を考えてください」「同じキャラクターに夏服を 6 着用意してください。1 着ずつ試したいです」

使える Studio ツールには、現在の下書きを読み取り、画像を表示、プロンプトを書き換え、プロンプトセット、下書きスナップショット、百科を検索、タグを検索、ブロックを検索、ブロックを整理、設定を読み取り / 設定を変更、画風探索、生成の準備、画像を生成、生成をキャンセル、ギャラリーを検索、ギャラリーを整理、セマンティック検索、参照画像を設定、参照画像ライブラリ、画像ツール、バリエーション / エンハンスがあります。ワークスペース内のファイルの読み書き、コマンド実行、必要に応じたユーザーへの質問もできます。

## 会話に表示されるカード

Agent が黙って変更することはありません。会話には、次のようなカードが表示されます。

### 進行状況：思考とステップ

<img src="../../images/readme/en/agent-card-thinking.webp" alt="思考とステップ" width="460">

モデルの思考過程は既定で折りたたまれ、「思考済み」とだけ表示されます。ツールの呼び出しは順番にステップとして並びます（例：現在の下書きを読み取り → 百科を検索 → プロンプトを書き換え）。展開するとパラメータと結果を確認できます。

### タグの検索結果

<img src="../../images/readme/en/agent-card-tags.webp" alt="タグの検索結果" width="460">

「タグを検索」や「セマンティック検索」の結果は、そのステップのすぐ下に表示されます。正式なタグ名、中国語名、投稿数が並び、マウスを重ねると Wiki の概要を確認できます。

### プロンプトとパラメータの変更

<img src="../../images/readme/en/agent-card-diff.webp" alt="プロンプトとパラメータの変更" width="460">

プロンプト欄を変更するたびに差分カードが表示され、追加は緑、削除は赤で示されます。ステップ数、サンプラー、サイズなどのパラメータの変更は別のカードにまとまり、変更前の値 → 変更後の値が並びます。一度に複数の箇所を変更した場合は、一番上に「今回の変更 · N か所」と表示され、**すべて元に戻す**ことも、個別のカードで「元に戻す」を選ぶこともできます。その後に手動で下書きを編集した場合は、新しい変更を上書きしないよう、元に戻す機能がロックされます。

### プロンプトセット：物語・試着・絵コンテ

<img src="../../images/readme/en/agent-card-promptset.webp" alt="プロンプトセットカード" width="460">

複数のプロンプトをまとめて書くように頼むと（物語の数場面、衣装一式、戦闘のいくつかのカット、表情のセットなど）、会話にプロンプトセットカードが表示されます。カードの名前（絵コンテカード、試着カード、戦闘シーンカードなど）や各項目のタイトル、アイコン、説明は、Agent が決めます。

- **切り替え**：左右の矢印、下部の小さなアイコン、またはカードを選択した状態でキーボードの ← → キーを使います。右上のグリッドボタンでは、全項目をまとめて確認できます。
- **プロンプト**：既定では折りたたまれています。展開すると、各項目で共通の設定（画風、キャラクターの外見、ネガティブプロンプト）は灰色、その項目だけの部分は強調表示されます。離れた箇所の共通部分は「…」で省略されます。「すべて表示」をクリックすると、原文全体を確認できます。
- **キャンバスに読み込む**：この項目のメインプロンプト、キャラクター、ネガティブプロンプトだけを下書きに書き込みます。パラメータ、シード、サイズ、参照画像は変わりません。読み込み後はカードで元に戻せます。Agent がキャラクターの位置を決めている場合（たとえば左右に 1 人ずつ）は、プロンプトを展開すると小さな配置ボードが表示され、読み込み時に位置も書き込まれます。位置のないプロンプトセットではこのボードは表示されません。
- **生成**：クリックすると現在の項目を読み込んで **1 枚**を生成します。会話の末尾で再確認する必要はありません。開始前の単価・残高・現在の状態の確認は引き続き行います。気に入らなければ、もう一度クリックして生成し直せます。生成した画像はその項目の下に残り、小さなアイコンに緑の点が付きます。
- **⋯ メニュー**：「ブロックとして保存」（各項目が 1 エントリーになり、あとで順番またはランダムに設定できます）、「この項目のプロンプトをコピー」または「すべてコピー」、「この項目の修正を Agent に頼む」を選べます。
- **修正**：Agent に「5 番目のシーンを昼間にしてください」と頼むと、同じカードが直接更新されます。カードには「v2 · 1件変更」と表示され、修正した項目には黄色の点が付きます。再起動後も、カードと生成した画像は残ります。

### キャラクターの位置

<img src="../../images/readme/en/agent-card-position.webp" alt="キャラクターの位置" width="460">

キャラクターの配置を調整すると、小さなプレビューに各キャラクターの位置が示され、誰が左で誰が右かをひと目で確認できます。

### アプリの設定

<img src="../../images/readme/en/agent-card-settings.webp" alt="設定の変更" width="460">

設定の変更（ダークテーマへの切り替えやビジュアルチャンネルの有効化など）を頼むと、各項目の変更前の値 → 変更後の値が表示されます。カード全体を元に戻すことも、「設定を開く」をクリックして該当する設定項目へ移動することもできます。

### ギャラリーの整理

<img src="../../images/readme/en/agent-card-gallery.webp" alt="ギャラリーの操作" width="460">

お気に入り登録、移動、コピー、削除、コレクションへの追加を行うと、対象の画像のサムネイルと枚数が表示されます。削除した画像はいったん回収エリアに入り、ほとんどの操作は元に戻せます。

### あなたに質問

<img src="../../images/readme/en/agent-card-ask.webp" alt="あなたに質問" width="460">

判断に迷うことがあれば、Agent はいったん止まって質問します。いくつかの選択肢から選ぶほか、自分で回答を入力することもできます。

### 許可が必要なとき

<img src="../../images/readme/en/agent-approval.webp" alt="確認カード" width="460">

「確認」モードでは、変更、削除、移動、コマンド実行の前にこのカードが表示されます。実行予定の具体的なパラメータを確認し、「今回のみ許可」「このセッションで同一の呼び出しを許可」「拒否」を選べます。

### Anlas を使う前に：価格カード

<img src="../../images/readme/en/agent-card-gate.webp" alt="価格確認カード" width="460">

Agent が画像生成、バリエーション / エンハンス、クラウド画像ツールの利用を行おうとすると、先にこの価格カードが表示されます。モデルとサイズ、リクエスト回数、単価、参照画像のエンコード料金、合計、現在の残高を確認できます。価格は Studio が計算し、モデルは変更できません。**「確認して生成」をクリックするまでは、実際に Anlas を消費しません**。どの権限でも同じです。見積もりには有効期限があるため、設定が変わった場合や期限が切れた場合は、Agent に準備をやり直してもらってください。

プロンプトセットカードはユーザーが直接操作する入口です。カードの「生成」を自分でクリックすると、その項目の 1 枚を許可したことになり、追加の価格確認カードは表示されません。上記の確認は、モデル自身が生成ツールを呼び出す場合には引き続き必要です。

### 出力とまとめ

<img src="../../images/readme/en/agent-card-images.webp" alt="今回の出力" width="460">

生成した画像は会話に表示され（「出力」ページにも入ります）、今回消費した Anlas も添えられます。各実行の最後には、所要時間、Anlas、変更箇所数、ツールの呼び出し回数、使用トークン数をまとめた行が表示されます。

## 権限の段階

サイドバー下部で権限を選べます。

| 段階 | 動作 |
| --- | --- |
| **閲覧のみ** | 読み取りと相談だけを行い、変更や生成はしません |
| **確認** | 変更、コマンド、未知のツールは先に確認します |
| **自動** | ワークスペース内の通常の変更は直接実行します。支払いには確認が必要です |
| **フルアクセス** | 確認せずにすべての操作を実行しますが、Anlas の消費には確認が必要です（切り替え前にリスクを表示します） |

生成中は Agent の停止ボタン、またはメイン画面の停止ボタンを押すと、待機中の生成を中断できます。

## スキル（Skill）

スキルは Agent 向けの「操作マニュアル」で、必要なときだけ読み込みます。

- **nai-studio**（Studio の各ツールの使い方とルール）と **nai-prompt**（V4 / V4.5 / V5 のプロンプトの書き方）が内蔵されています。
- 自分のスキルも作れます。`agent-data/skills/`（全体用）または各ワークスペースの `skills/` フォルダーに置きます。同名の場合はワークスペース、全体用、内蔵の順に優先します。
- スキルごとにオン・オフを切り替えたり、「手動のみ」に設定して入力欄から `/skill:名前` で呼び出したりできます。

入力欄の `@` でファイルや画像を参照し、`/` でスキルを呼び出します。

## MCP と CodeMode

- **MCP**：「設定 → NAI Agent」で外部 MCP サーバーを追加し、Agent に外部ツールを使わせられます。stdio と Streamable HTTP、OAuth ログインに対応しています。設定は暗号化ストレージに保存します。
- **CodeMode**：Agent は既定で安全なスクリプトサンドボックスを使い、必要に応じてツールを見つけて呼び出します。複数の操作を一度に行い、会話の往復を減らします。

<img src="../../images/readme/en/settings-agent.webp" alt="Agent の設定" width="100%">

## ワークスペースとデータ

- ワークスペースごとにチャット、出力、ルールがあり、作成・名前変更・削除ができます（削除後は回収エリアから元に戻せます）。
- データはプログラムフォルダーの `agent-data/` に保存します。
- 「指示」ページに全体の指示やワークスペースのルールを書くと、それ以降のリクエストに反映されます。
- 1 回の実行でのモデルリクエストは既定で最大 32 回です。設定で 1–200 回に変更できます。
- 送信済みのメッセージは「編集」して再送信できます（それ以降の会話は置き換えられます）。最後の返信には「回答を再生成」を使えます。

## ヒント

- まず「確認」で動作を把握し、それから「自動」の利用を検討してください。
- 外部の Pi 拡張や MCP サーバーはローカルコードを実行できます。信頼できる提供元のものだけをインストールしてください。
- 外部の AI ツールやスクリプトも「ローカルブリッジ」（付属の `studio-bridge.exe`）経由で Studio を操作できます。画像生成には同じく見積もり確認が必要です。
