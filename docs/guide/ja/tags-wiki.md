# タグ拡張とタグ百科

完全なオフラインのタグライブラリ、タグ共起データ、Danbooru Wiki が付属しているため、通信せずにタグを調べられます。

## タグ拡張

<img src="../../images/readme/en/tag-expansion.webp" alt="タグ拡張" width="100%">

プロンプト欄で、次の操作ができます。

- タグを **Ctrl+クリック**：ローカルのタグ検索を開きます。中国語や英語でタグと別名を探し、`Tab` で補完、クリックで挿入できます。
- 範囲を **Ctrl+ドラッグ選択**：「関連タグ」、つまりよく一緒に使われるタグを確認できます。
- ポップアップ内の「タグ百科」で、そのタグの説明もすぐに読めます。

通常の入力中に自動補完は表示されないため、作業の邪魔をしません。同じタグ検索を、ローカルギャラリー検索、オンラインギャラリー検索、ブラックリスト、ブロックライブラリでも使えます。

**データの出典**：

- オフラインで統合した Danbooru / e621 のタグ・別名ライブラリです。
- オフラインの共起データ（どのタグが一緒に使われやすいか）です。
- 中国語の意味補足資料（約 5.4 万タグの類義語と短い説明）です。
- オプションの Danbooru オンライン関連タグです。関連タグだけを送り、プロンプト全体は送りません。「設定 → 辞書とキャッシュ」でオフにできます。

[ローカルのセマンティック検索](rag.md)を有効にすると、カーソル付近のプロンプトも考慮し、文脈に合ったタグを提案します。

## タグ百科

<img src="../../images/readme/en/wiki.webp" alt="タグ百科" width="100%">

入口は左ナビゲーションの「タグ百科」です。

- 公式のグループ一覧から閲覧したり、タグや別名を検索したりできます。「説明あり / 説明なし」で絞り込み、人気順・名前順に並べ替えられます。
- 本文は訳文・原文・対訳表示を切り替えられます（「百科翻訳」モデルの設定が必要です。自動翻訳は初期状態ではオフです）。タグ名や本文の翻訳時には、文中で一致したタグとローカルの説明を用語集としてモデルに送り、同じ名前の絵師・作品・一般の単語を区別しやすくします。詳しくは[翻訳ブロック・一致したタグの用語集](translation.md#誤訳を防ぐしくみ一致したタグの用語集)をご覧ください。
- 「よく一緒に使われるタグ」に関連タグが並びます。クリックで確認し、`Shift+クリック`でブロックに追加します。
- ブックマークの追加やブックマーク集の作成ができます。
- 「ブロックに追加」を押すと、タグを入力済みの状態でブロック保存画面を開きます。
- 例の画像は必要なときだけ読み込みます。

ショートカット：`/` で検索 · `↑↓` で切り替え · `Enter` でブロックに追加 · `B` でお気に入り · `Alt+←/→` で前後に移動します。

## データの更新

「設定 → 辞書とキャッシュ」でタグと Wiki の更新確認・更新、各階層のキャッシュ確認・削除ができます。更新はクリックしたときだけ行い、自動ダウンロードはしません。自分で作成した訳文は更新時も保持されます。
