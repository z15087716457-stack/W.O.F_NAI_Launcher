# NAI Agent

NAI Agent 是 Studio 內建的 AI 助手。你透過聊天告訴它要做什麼，它會呼叫 Studio 的工具完成：修改提示詞、查詢標籤和百科、整理積木和圖庫、設定參考圖、準備生成……每做一件事，對話裡都會出現一張對應的**卡片**，告訴你它改了什麼，而且大多可以一鍵復原。

<img src="../../images/readme/zh/gen-agent.webp" alt="生圖頁裡的 NAI Agent" width="100%">

## 準備

1. 在「設定 → 模型與介面」新增大型語言模型服務商（支援 OpenAI 相容 API、Responses、Anthropic、Gemini 和 Ollama），選好模型；
2. 在生圖頁或畫風探索頁頂端點選「NAI Agent」按鈕，右側就會展開側欄；
3. 在側欄底部選擇要使用的模型，開始聊天。

Agent 使用你自己的模型服務，對話費用依該服務的價格計算。

## 能讓它做什麼

幾個範例：

- 「把目前的提示詞改成雨夜街頭的氛圍，保留角色描述」
- 「查一下 `wet hair` 的百科，有沒有更常用的寫法」
- 「把積木庫裡所有畫師積木移到『畫風』資料夾」
- 「把這張圖設為風格遷移參考」（可以直接貼上或拖入圖片）
- 「找出圖庫裡上週畫的所有夜景圖，移到新資料夾」
- 「依目前設定準備生成 4 張，先報價」

可使用的 Studio 工具包括：讀取當前草稿、檢視圖片、改寫提示詞、草稿快照、查百科、查標籤、查積木、整理積木、讀取設定 / 修改設定、畫風探索、準備生成、生成圖片、取消生成、查圖庫、整理圖庫、語義搜尋、設定參考圖、參考圖庫、影像工具、變體 / 增強。此外也能在工作區讀寫檔案、執行命令，必要時向你提問。

## 對話裡的卡片

Agent 不會偷偷修改內容。以下是你會在對話裡看到的幾種卡片。

### 過程：思考和步驟

<img src="../../images/readme/zh/agent-card-thinking.webp" alt="思考與步驟" width="460">

模型的思考過程預設收合，只顯示「已思考」；它呼叫的每個工具會依序列成步驟（例如 讀取當前草稿 → 查百科 → 改寫提示詞），點開就能查看參數和結果。

### 查到的標籤

<img src="../../images/readme/zh/agent-card-tags.webp" alt="查標籤結果" width="460">

查標籤或語義搜尋的結果會直接顯示在該步驟下方：標準標籤名稱、中文名稱、作品數，將游標停在標籤上就能查看 Wiki 簡介。

### 提示詞和參數改動

<img src="../../images/readme/zh/agent-card-diff.webp" alt="提示詞與參數改動" width="460">

每修改一欄提示詞，就會出現一張差異卡，綠色代表新增、紅色代表刪除；步數、取樣器、尺寸這類參數改動會另列一張卡，顯示舊值 → 新值。一次修改多處時，最上方會顯示「本次改動 · N 處」，可以**全部復原**，也可以只對其中一張按「復原」。如果你之後又手動修改了草稿，復原功能會被鎖定，避免覆蓋你的新修改。

### 角色位置

<img src="../../images/readme/zh/agent-card-position.webp" alt="角色位置" width="460">

調整角色位置時，會顯示一個迷你畫面，標出每個角色的位置，一眼就能看出誰在左邊、誰在右邊。

### 應用程式設定

<img src="../../images/readme/zh/agent-card-settings.webp" alt="設定改動" width="460">

請它修改設定（例如切換為深色主題、開啟視覺通道）時，會列出每一項的舊值 → 新值，可以整張復原，也可以點選「去設定」，跳到對應的設定項目。

### 整理圖庫

<img src="../../images/readme/zh/agent-card-gallery.webp" alt="圖庫操作" width="460">

收藏、移動、複製、刪除或加入收藏集後，會顯示受影響圖片的縮圖和張數。刪除會先送到回收區，大多數操作都能復原。

### 向你提問

<img src="../../images/readme/zh/agent-card-ask.webp" alt="向你提問" width="460">

遇到不確定的地方，它會停下來詢問你，提供幾個選項，也可以自行填寫答案。

### 需要你允許

<img src="../../images/readme/zh/agent-approval.webp" alt="確認卡片" width="460">

在「詢問」等級下，修改、刪除、移動或執行命令前會顯示這張卡，列出它準備執行的具體參數，讓你選擇「允許一次」、「本會話允許相同呼叫」或「拒絕」。

### 花費 Anlas 前：價格卡

<img src="../../images/readme/zh/agent-card-gate.webp" alt="價格確認卡" width="460">

Agent 想生成圖片、製作變體 / 增強或使用雲端影像工具時，會先顯示這張價格卡：模型和尺寸、請求次數、單價、參考圖編碼費、合計和目前餘額。價格由 Studio 計算，模型無法修改。**只有你點選「確認並生成」後，才會真正花費 Anlas**，任何權限等級都一樣。報價有有效期限，設定變更或報價過期後，需要請 Agent 重新準備。

### 產物和小結

<img src="../../images/readme/zh/agent-card-images.webp" alt="本輪產物" width="460">

生成的圖片會出現在對話裡（也會進入「產物」頁），並附上本輪花費的 Anlas。每輪結束後會有一行小結：耗時、Anlas、改動處數、工具呼叫次數，以及使用的 token 數。

## 權限等級

在側欄底部可以選擇權限等級：

| 等級 | 行為 |
| --- | --- |
| **只讀** | 只讀取和討論，不修改、不生成 |
| **詢問** | 修改、命令和未知工具會先詢問 |
| **自動** | 直接執行工作區內的一般修改；花費仍須確認 |
| **完全權限** | 不再詢問，直接執行所有操作；花費 Anlas 仍須確認（切換前會提示風險） |

生成途中點選 Agent 的停止，或按主介面的停止，都能中斷等待中的生成。

## 技能（Skill）

技能是供 Agent 閱讀的「操作手冊」，需要時才會讀取：

- 內建 **nai-studio**（Studio 各工具的用法和規則）和 **nai-prompt**（V4 / V4.5 / V5 提示詞寫法）；
- 也可以撰寫自己的技能：放在 `agent-data/skills/`（全域）或工作區的 `skills/` 資料夾。同名時優先使用工作區版本，其次是全域，最後是內建；
- 每個技能都能開關，或設為「僅手動呼叫」，在輸入框以 `/skill:名稱` 呼叫。

在輸入框用 `@` 引用檔案或圖片，`/` 呼叫技能。

## MCP 與 CodeMode

- **MCP**：在「設定 → NAI Agent」新增外部 MCP 伺服器（支援 stdio 和 Streamable HTTP，以及 OAuth 登入），讓 Agent 使用更多外部工具。設定儲存在加密儲存區。
- **CodeMode**：Agent 預設透過安全的指令碼沙箱，依需要尋找並呼叫工具，一次完成多步操作，減少來回對話。

<img src="../../images/readme/zh/settings-agent.webp" alt="Agent 設定" width="100%">

## 工作區與資料

- 每個工作區有自己的聊天、產物和規則，可以新增、重新命名、刪除（刪除後可以從回收區復原）；
- 資料都在程式目錄下的 `agent-data/`；
- 「指令」頁可以撰寫全域指令和工作區規則，影響之後的請求；
- 每次執行預設最多 32 個模型請求，可在設定裡調整（1–200）；
- 已送出的訊息可以「編輯」後重新傳送（之後的對話會被取代），最後一則回覆可以「重新回答」。

## 小技巧

- 先使用「詢問」熟悉它會做什麼，再考慮「自動」。
- 外部 Pi 擴充功能和 MCP 伺服器能執行本機程式碼，請只安裝可信來源。
- 外部 AI 工具或指令碼也能透過「本機橋接」（隨附 `studio-bridge.exe`）控制 Studio，同樣要報價確認後才能生圖。
