# NAI Agent

NAI Agent 是 Studio 內建的 AI 助手。你透過聊天告訴它要做什麼，它會呼叫 Studio 的工具完成：修改提示詞、查詢標籤和百科、整理積木和圖庫、設定參考圖、準備生成……

<img src="../../images/readme/zh/gen-agent.webp" alt="生圖頁裡的 NAI Agent" width="100%">

## 準備

1. 在「設定 → 模型與介面」新增大型語言模型服務商（支援 OpenAI 相容 API、Responses、Anthropic、Gemini 和 Ollama），選好模型；
2. 在生圖頁或畫風探索頁頂端點選「NAI Agent」按鈕，右側就會展開側欄；
3. 在側欄底部選擇要使用的模型，開始聊天。

Agent 使用你自己的模型服務，對話費用依該服務的價格計算。

## 能讓它做什麼

幾個範例：

- 「把目前的提示詞改成雨夜街頭的氛圍，保留角色描述」
- 「查一下 `wet hair` 的百科，有沒有更常用的寫法」
- 「把積木庫裡所有畫師積木移到『畫風』資料夾」
- 「把這張圖設為風格遷移參考」（可以直接貼上或拖入圖片）
- 「找出圖庫裡上週畫的所有夜景圖，移到新資料夾」
- 「依目前設定準備生成 4 張，先報價」

可使用的 Studio 工具包括：讀取目前草稿、查看圖片、改寫提示詞、草稿快照、查百科、查標籤、查積木、整理積木、讀取 / 修改設定、畫風探索、準備生成、生成圖片、取消生成、查圖庫、整理圖庫、語義搜尋、設定參考圖、參考圖庫、影像工具、變體 / 增強。此外也能在工作區讀寫檔案、執行命令，必要時向你提問。

## 權限與確認

在側欄底部可以選擇權限等級：

| 等級 | 行為 |
| --- | --- |
| **只讀** | 只讀取和討論，不修改、不生成 |
| **詢問** | 修改、命令和未知工具會先詢問 |
| **自動** | 直接執行工作區內的一般修改；花費仍須確認 |
| **完全權限** | 不再詢問，直接執行所有操作；花 Anlas 仍須確認（切換前會提示風險） |

需要確認時會跳出卡片，可以選擇「允許一次」、「本會話允許相同呼叫」或「拒絕」。刪除、移動等操作和執行命令都屬於需要確認的操作。

<img src="../../images/readme/zh/agent-approval.webp" alt="確認卡片" width="50%">

### 生成圖片一定要你確認

Agent 想生成圖片時，會先「準備生成」，在 Studio 顯示價格卡：每次請求多少 Anlas、預估總價、目前餘額。**只有你在價格卡上確認後，才會真正生成**，任何權限等級都一樣。報價有效期限為 5 分鐘。生成途中點選停止，或按主介面的停止，都能中斷。

## 技能（Skill）

技能是供 Agent 閱讀的「操作手冊」，需要時才會讀取：

- 內建 **nai-studio**（Studio 各工具的用法和規則）和 **nai-prompt**（V4 / V4.5 / V5 提示詞寫法）；
- 也可以撰寫自己的技能：放在 `agent-data/skills/`（全域）或工作區的 `skills/` 資料夾。同名時優先使用工作區版本，其次是全域，最後是內建；
- 每個技能都能開關，或設為「僅手動呼叫」，在輸入框以 `/skill:名稱` 呼叫。

在輸入框用 `@` 引用檔案或圖片，`/` 呼叫技能。

## MCP 與 CodeMode

- **MCP**：在「設定 → NAI Agent」新增外部 MCP 伺服器（支援 stdio 和 Streamable HTTP，以及 OAuth 登入），讓 Agent 使用更多外部工具。設定儲存在加密儲存區。
- **CodeMode**：Agent 預設透過安全的指令碼沙箱，依需要尋找並呼叫工具，一次完成多步操作，減少來回對話。

<img src="../../images/readme/zh/settings-agent.webp" alt="Agent 設定" width="100%">

## 工作區與資料

- 每個工作區有自己的聊天、產出和規則，可以新增、重新命名、刪除（刪除後可以從回收區復原）；
- 資料都在程式目錄下的 `agent-data/`；
- 「指令」頁可以撰寫全域指令和工作區規則，影響之後的請求；
- 每次執行預設最多 32 個模型請求，可在設定裡調整（1–200）。

## 小技巧

- 先使用「詢問」熟悉它會做什麼，再考慮「自動」。
- 外部 Pi 擴充功能和 MCP 伺服器能執行本機程式碼，請只安裝可信來源。
- 外部 AI 工具或指令碼也能透過「本機橋接」（隨附 `studio-bridge.exe`）控制 Studio，同樣要報價確認後才能生圖。
