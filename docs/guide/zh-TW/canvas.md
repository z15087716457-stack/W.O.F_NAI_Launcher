# 無限畫布與視覺通道

## 無限畫布

生圖頁中間是一張可以無限拖曳的畫布，每次生成的結果會分批鋪開。

| 操作 | 方式 |
| --- | --- |
| 平移 | 滾輪上下，`Shift+滾輪`左右；或以中鍵 / `Shift+左鍵`拖曳 |
| 縮放 | `Ctrl+滾輪` |
| 導覽 | `W A S D` |
| 總覽全部 | `Ctrl+0` |
| 看原圖 | 對局部重繪等有原圖的結果，按住滑鼠、空白鍵或 Enter，顯示原圖和本次重繪範圍（圖上會標示 OLD） |

- 點選生成後會先放置預留區塊並移至最新一組，生成中的預覽和最終結果都會出現在同一位置；
- 可以對喜歡的圖片選擇「固定圖片」，即使清空歷史紀錄也會保留在畫布上；
- 透明背景圖片可以選擇襯底樣式（棋盤格、純色等），只影響顯示，不會寫入圖片；
- 「畫布顯示」裡可以開關放大填滿、減少動態效果、鎖定畫布相機。

## 視覺通道

<img src="../../images/readme/zh/channel.webp" alt="視覺通道" width="100%">

視覺通道是畫布兩側隨捲動移動的裝飾，**只繪製在圖片之外，不遮擋圖片**。

開啟方式：畫布左下角齒輪 →「畫布顯示」→「視覺通道」。

- **主題**：像素電路、星圖、植物標本、迴廊、深海、青海波、機芯、地層、地鐵、樂譜、月相，共 11 種；
- **模式**：關閉、固定一個、每次隨機（隨機時至少保留兩個主題，可以「換一組」）；
- **濃淡**：淡、標準、濃；
- **時間刻度**：顯示批次時間、日期分隔和右側刻度條；
- **空閒微動**：未生成時，裝飾會輕微動起來，生成時自動暫停。
