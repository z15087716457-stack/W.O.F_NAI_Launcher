# 翻譯塊

看不懂一長串英文提示詞？翻譯塊會將它翻成中文，直接顯示在原本的位置。**生成時一律使用英文原文**，翻譯只幫助閱讀和修改。

<img src="../../images/readme/zh/translation.webp" alt="翻譯塊" width="100%">

## 先設定翻譯模型

翻譯需要你自己的大型語言模型服務（支援 OpenAI 相容 API、Anthropic、Gemini、本機 Ollama 等）：

1. 開啟「設定 → 模型與介面」，點選「新增服務商」，填入網址和金鑰，選好模型；
2. 在「功能分配」裡為「提示詞翻譯」選擇模型。

<img src="../../images/readme/zh/settings-models.webp" alt="模型與介面" width="100%">

同一頁還能為另外三個功能分配模型：提示詞反推、標籤翻譯與語義補充、百科翻譯。金鑰儲存在系統安全儲存區。翻譯請求會傳送到你選擇的服務，費用依該服務的價格計算。

## 使用方式

點選提示詞工具列上的「翻譯」。完成後，每段英文會變成一個「翻譯塊」：

| 操作 | 效果 |
| --- | --- |
| **中鍵點選區塊** | 切換原文與譯文 |
| **左鍵點原文** | 定位游標，直接修改英文 |
| **左鍵點譯文** | 開啟翻譯塊編輯視窗 |
| 翻譯選單「全部顯示原文 / 譯文」 | 整組切換 |
| 翻譯選單「翻譯新增內容」 | 只翻譯後來新增的部分 |
| 「全部翻譯塊還原為原文文本」 | 移除所有翻譯塊，回到一般文字 |

## 翻譯塊編輯視窗

用左鍵點選譯文開啟編輯視窗，可以看到原文和「生圖使用」的內容：

- 直接修改英文原文，儲存後生效；
- **↑ 中文轉原文**：輸入中文，讓模型轉成英文標籤，檢查後儲存；
- **↓ 原文轉中文**：重新翻譯；
- 修改原文後，區塊會提示譯文待同步。

## 怎麼避免模型翻錯：命中術語表

許多 Danbooru 標籤只看字面容易誤解：一個詞可能是畫師名、作品名、角色名，也可能只是一般的畫面描述。為了讓模型翻得準，每次翻譯時，Studio 都會先在本機查詢，將**提示詞裡命中的標籤**整理成術語表，隨請求一起傳送給模型參考：

| 術語表的內容 | 來源 |
| --- | --- |
| 標準標籤名稱 | 本機標籤庫（只收錄能在庫裡查到的完整標籤） |
| 中文譯名 | 先前已翻譯並快取的標籤譯名 |
| 簡短釋義 | 本機 Wiki：有對應的中文釋義就用中文，沒有則附上原文的簡短釋義，並註明是原文 |
| 類別 | 本機標籤庫（畫師 / 作品 / 角色 / 一般等） |

同時還有幾項限制：

- **術語表只是參考資料**：明確告知模型，提示詞和術語表都只是待翻譯的資料，不是指令，也不能將釋義附加到提示詞；查不到的標籤不得編造含義或關係；
- **只對完整標籤生效**：不會強行將 Danbooru 的含義套用到句子裡的一般單字；
- **結果要回本機核對**：譯文中標記的畫師、作品、角色標籤，必須能在本機標籤庫裡查到。類別圖示由 Studio 依本機資料決定，不採信模型提供的類別；無法對應的標記會直接捨棄，但譯文本身仍會保留；
- **譯名與釋義分開快取**：Wiki 原文變更後，便不再使用舊的中文釋義，改用新的原文，避免過時說明誤導模型；
- **全部在本機完成**：查詢術語表不會額外呼叫模型，查詢失敗也不會中斷翻譯。

同一套術語表也用於「↑ 中文轉原文」、標籤翻譯和百科翻譯：在編輯視窗輸入中文時，模型可以參考命中的標準標籤，還原成準確的英文標籤；翻譯標籤名稱或 Wiki 正文時，也會附上相關標籤的釋義，協助區分同名的畫師、作品和一般詞語。

## 小技巧

- 隨時用中鍵看一下原文，確認模型沒有把 `cat ears` 翻成奇怪的東西。
- 翻譯不會改變儲存的生成原文，也不影響 Anlas 消耗。
- 標籤和百科的自動翻譯預設關閉，需要時可在 [標籤百科](tags-wiki.md) 和詞庫設定裡開啟。
