# 翻譯塊

看不懂一長串英文提示詞？翻譯塊會將它翻成中文，直接顯示在原本的位置。**生成時一律使用英文原文**，翻譯只幫助閱讀和修改。

<img src="../../images/readme/zh/translation.webp" alt="翻譯塊" width="100%">

## 先設定翻譯模型

翻譯需要你自己的大型語言模型服務（支援 OpenAI 相容 API、Anthropic、Gemini、本機 Ollama 等）：

1. 開啟「設定 → 模型與介面」，點選「新增服務商」，填入網址和金鑰，選好模型；
2. 在「功能分配」裡為「提示詞翻譯」選擇模型。

<img src="../../images/readme/zh/settings-models.webp" alt="模型與介面" width="100%">

同一頁還能為另外三個功能分配模型：提示詞反推、標籤翻譯與語義補充、百科翻譯。金鑰儲存在系統安全儲存區。翻譯請求會傳送到你選擇的服務，費用依該服務的價格計算。

## 使用方式

點選提示詞工具列上的「翻譯」。完成後，每段英文會變成一個「翻譯塊」：

| 操作 | 效果 |
| --- | --- |
| **中鍵點選區塊** | 切換原文與譯文 |
| **左鍵點原文** | 定位游標，直接修改英文 |
| **左鍵點譯文** | 開啟翻譯塊編輯視窗 |
| 翻譯選單「全部顯示原文 / 譯文」 | 整組切換 |
| 翻譯選單「翻譯新增內容」 | 只翻譯後來新增的部分 |
| 「全部翻譯塊還原為原文文本」 | 移除所有翻譯塊，回到一般文字 |

## 翻譯塊編輯視窗

用左鍵點選譯文開啟編輯視窗，可以看到原文和「生圖使用」的內容：

- 直接修改英文原文，儲存後生效；
- **↑ 中文轉原文**：輸入中文，讓模型轉成英文標籤，檢查後儲存；
- **↓ 原文轉中文**：重新翻譯；
- 修改原文後，區塊會提示譯文待同步。

## 小技巧

- 隨時用中鍵看一下原文，確認模型沒有把 `cat ears` 翻成奇怪的東西。
- 翻譯不會改變儲存的生成原文，也不影響 Anlas 消耗。
- 標籤和百科的自動翻譯預設關閉，需要時可在 [標籤百科](tags-wiki.md) 和詞庫設定裡開啟。
