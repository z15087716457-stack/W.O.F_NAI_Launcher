# 常見問題

### 執行時 Windows 顯示「Windows 已保護您的電腦」

安裝檔和程式尚未進行程式碼簽章。點選「其他資訊 → 仍要執行」即可。如果想確認檔案沒有遭到竄改，可比對 Release 頁面附上的 SHA-256 校驗值。

### 安裝版和可攜版有什麼不同

功能完全相同。安裝版安裝到 `%LOCALAPPDATA%\Programs\W.O.F NAI Studio`，附開始功能表和解除安裝入口；可攜版解壓縮到哪裡都能執行。兩者都支援應用程式內更新。

### 我的資料存在哪裡，如何備份

- 設定、圖庫資料庫、積木庫：程式目錄下的 `user-data/`
- NAI Agent：程式目錄下的 `agent-data/`
- 圖片：你設定的圖庫資料夾

複製這三處就是完整備份。升級和解除安裝都不會刪除 `user-data/` 和 `agent-data/`。

### 從舊版（1.x）升級

直接安裝新版即可。舊版放在 AppData 的資料，會在首次啟動時完整備份、驗證，再移轉到 `user-data/`。舊安裝版也能透過應用程式內更新升級。

### 一次生成到底花多少 Anlas

生成按鈕會即時顯示本次總消耗（張數 × 每張價格，包含參考圖編碼等）。可在設定裡開啟「Anlas 高消耗警告」，超過設定值時先確認。NAI Agent 和外部橋接生成圖片時，也都要你在價格卡上確認。

### 哪些功能會連網

- NovelAI API（生成、帳號、放大、導演工具）
- 你自己設定的大型語言模型服務（翻譯、反推、NAI Agent）
- 線上畫廊來源（Danbooru、Safebooru、Gelbooru、AI TAG）
- 檢查更新（本儲存庫的 GitHub Releases）
- 你主動點選下載的選用元件（語義檢索模型與環境、放大模型、魔術棒模型）

語義檢索、本機放大、圖庫整理都在本機完成。Danbooru 線上關聯標籤只傳送相關標籤，不傳送完整提示詞，可以在「設定 → 詞庫與快取」關閉。

### 我的帳號和金鑰安全嗎

NovelAI Token、密碼和各家的 API 金鑰都儲存在 Windows 系統安全儲存區，只在本機使用。MCP 設定儲存在加密儲存區。

### 需要什麼顯示卡

生成在 NovelAI 雲端完成，對顯示卡沒有要求。只有選用的本機功能需要：本機放大須使用支援 Vulkan 的顯示卡；RTX 放大須使用 NVIDIA RTX 顯示卡；SeedVR2 須使用 NVIDIA 顯示卡；語義檢索使用 NVIDIA 顯示卡較快，沒有也能使用 CPU。

### 如何切換介面語言

在「設定 → 外觀」裡可以選擇簡體中文、繁體中文、English、日本語、한국어，以及淺色、深色或跟隨系統。

### 遇到問題如何回報

請到本儲存庫的 [Issues](https://github.com/z15087716457-stack/W.O.F_NAI_Launcher/issues) 提交，附上版本號、操作步驟和截圖。截圖中請勿露出 Token 或金鑰。
