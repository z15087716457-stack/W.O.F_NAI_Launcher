# 標籤擴展與標籤百科

軟體隨附完整的離線標籤庫、標籤共現資料和 Danbooru Wiki，不連網也能查詢標籤。

## 標籤擴展

<img src="../../images/readme/zh/tag-expansion.webp" alt="標籤擴展" width="100%">

在提示詞框裡：

- **Ctrl+點選**標籤：開啟本機標籤搜尋，可以輸入中文或英文查詢標籤和別名，按 `Tab` 補齊，點選插入；
- **Ctrl+拖曳選取**一段文字：查看「關聯標籤」，也就是哪些標籤經常與它一起出現；
- 彈出面板裡還有「標籤小百科」，直接查看標籤的說明。

一般輸入時不會跳出自動完成，不打擾寫作。同樣的標籤搜尋也用於本地畫廊搜尋、線上畫廊搜尋、黑名單和積木庫。

**資料來源**：

- 離線合併的 Danbooru / e621 標籤與別名庫；
- 離線共現資料（哪些標籤經常一起出現）；
- 中文語義補充資料（約 5.4 萬個標籤的同義詞和簡短釋義）；
- 選用的 Danbooru 線上關聯標籤：只傳送相關標籤，不傳送完整提示詞，可在「設定 → 詞庫與快取」關閉。

啟用 [本機語義檢索](rag.md) 後，標籤推薦還會結合游標附近的提示詞內容，推薦更符合語境的標籤。

## 標籤百科

<img src="../../images/readme/zh/wiki.webp" alt="標籤百科" width="100%">

入口：左側導覽的「標籤百科」。

- 依官方分組目錄瀏覽，或搜尋標籤和別名；可以篩選「有釋義 / 暫無釋義」，依熱門程度或名稱排序；
- 正文可以切換譯文、原文、對照顯示（須先設定「百科翻譯」模型；自動翻譯預設關閉）。翻譯標籤名稱和正文時，會將文中命中的標籤及其本機釋義作為術語表，一起傳送給模型，協助區分同名的畫師、作品和一般詞語，詳見 [翻譯塊 · 命中術語表](translation.md#怎麼避免模型翻錯命中術語表)；
- 「常一起出現」列出關聯標籤：點選查看，`Shift+點選`新增到積木；
- 加入書籤、建立書籤集；
- 「新增到積木」會預先填好標籤，開啟積木儲存視窗；
- 範例圖片在需要時才載入。

快速鍵：`/` 搜尋 · `↑↓` 切換 · `Enter` 新增到積木 · `B` 收藏 · `Alt+←/→` 上一頁／下一頁。

## 更新資料

「設定 → 詞庫與快取」裡可以檢查並更新標籤和 Wiki 資料，查看各層快取並清除。更新只在你點選時執行，不會自動下載。重新整理時會保留你自己的譯文。
