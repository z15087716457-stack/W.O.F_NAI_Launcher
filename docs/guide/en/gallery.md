# Gallery

## Local Gallery

<img src="../../images/readme/en/gallery.webp" alt="Local Gallery" width="100%">

Open “Local Gallery” in the left navigation (`Ctrl+2`).

**Browse**

- Libraries, collections and folders are on the left, a continuous image timeline is in the middle, and details are on the right.
- Group by day or month, or leave ungrouped. Drag the timeline on the right to jump quickly, or use `Ctrl+G` to go to a date.
- Three layouts: justified rows (equal-height rows without cropping), grid and masonry. Thumbnail size and quality are adjustable.

**Find**

- Search by filename or prompt, including character prompts.
- Filter by NAI images only, model version, date range or tags.
- Enable [local semantic search](rag.md) to find images by visual content or find similar images from a selected image.

**Organize**

- Multiple gallery folders are supported (“Settings → Gallery Sources”). New images go to “Uncategorized” in the main gallery by default.
- Folders serve as categories; create, move and copy them.
- Favorites: hearts + collections, with unlimited collection nesting.
- Select multiple images to move, package, edit metadata or add to collections in batches.
- Deleted images go to “Trash” first and can be restored. They are permanently deleted on the next launch.

**Reuse**

- The details panel shows full generation settings. Choose “Reuse parameters,” or copy the prompt or seed.
- Use an image for image-to-image, Vibe Transfer or Precise Reference in one click, or save it to a reference library. Right-click for “Place on canvas.”
- Dragging to the generation page opens a dialog to choose what to import (seed is unchecked by default).

<img src="../../images/readme/en/viewer.webp" alt="Large image viewer" width="100%">

Common controls: click to select, double-click / Space / Enter to view large, arrow keys to switch, `Delete` to delete, `Ctrl+A` to select all, `Esc` to leave multi-select.

## Online Gallery

<img src="../../images/readme/en/online.webp" alt="Online Gallery" width="100%">

Open “Online Gallery” in the left navigation (`Ctrl+3`).

- **Sources**: Danbooru, Safebooru, Gelbooru and AI TAG.
- **Browse**: Tag search (also supports tag expansion), daily / weekly / monthly rankings and popular posts.
- **Favorites**: Local favorites (no site account needed, viewable offline) and site favorites. On AI TAG, favorite artists and view their work.
- **Blacklist**: Hide tags you do not want to see.
- **Reuse**: Reuse generation settings directly when included in a post; switch between individual images in multi-image posts.
- **Batch downloads**.
- Hover over tags and prompts to reveal a translate button. Translation runs only when clicked.

Danbooru login and Gelbooru API credentials are stored only locally.
