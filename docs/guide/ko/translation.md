# 번역 블록

긴 영어 프롬프트가 이해하기 어렵다면 번역 블록으로 중국어로 번역해 원래 위치에 표시할 수 있습니다. **생성에는 항상 영어 원문을 사용합니다**. 번역은 읽기와 수정을 돕는 용도입니다.

<img src="../../images/readme/en/translation.webp" alt="번역 블록" width="100%">

## 먼저 번역 모델 설정하기

번역에는 본인의 대규모 언어 모델 서비스가 필요합니다(OpenAI 호환 API, Anthropic, Gemini, 로컬 Ollama 등을 지원합니다).

1. “설정 → 모델과 API”를 열고 “공급자 추가”를 클릭하여 주소와 키를 입력하고 모델을 선택합니다.
2. “기능별 모델”에서 “프롬프트 번역”에 모델을 할당합니다.

<img src="../../images/readme/en/settings-models.webp" alt="모델과 API" width="100%">

같은 페이지에서 프롬프트 역추론, 태그 번역 및 의미 보충, 위키 번역의 세 기능에도 모델을 할당할 수 있습니다. 키는 시스템 보안 저장소에 저장합니다. 번역 요청은 선택한 서비스로 전송하며 해당 서비스의 요금이 적용됩니다.

## 사용 방법

프롬프트 도구 모음에서 “번역”을 클릭합니다. 번역이 끝나면 영어의 각 부분이 “번역 블록”으로 바뀝니다.

| 조작 | 결과 |
| --- | --- |
| **블록 가운데 버튼 클릭** | 원문과 번역문을 전환합니다 |
| **원문 왼쪽 클릭** | 커서를 놓고 영어를 직접 수정합니다 |
| **번역문 왼쪽 클릭** | 번역 블록 편집기를 엽니다 |
| 번역 메뉴의 “모두 원문 보기 / 모두 번역문 보기” | 그룹 전체를 전환합니다 |
| 번역 메뉴의 “새 내용 번역” | 나중에 추가한 부분만 번역합니다 |
| “모든 번역 블록을 원문 텍스트로 복원” | 모든 번역 블록을 없애고 일반 텍스트로 돌아갑니다 |

## 번역 블록 편집기

번역문을 왼쪽 클릭하면 편집기가 열리며 원문과 “이미지 생성용” 내용을 확인할 수 있습니다.

- 영어 원문을 직접 수정하고 저장하면 적용됩니다.
- **↑ 번역문을 원문으로**: 중국어를 작성해 모델이 영어 태그로 바꾸게 하고 확인한 뒤 저장합니다.
- **↓ 원문을 번역문으로**: 다시 번역합니다.
- 원문을 바꾸면 블록에 번역문 동기화가 필요하다고 표시됩니다.

## 오역을 줄이는 방법: 일치 태그 용어집

많은 Danbooru 태그는 글자 그대로만 보면 오해하기 쉽습니다. 어떤 단어는 작가명·작품명·캐릭터명일 수도 있고, 단순한 이미지 묘사일 수도 있습니다. 모델이 정확하게 번역하도록 Studio는 번역할 때마다 먼저 로컬에서 검색하고, **프롬프트에서 일치한 태그**를 용어집으로 정리해 요청과 함께 참고 자료로 보냅니다.

| 용어집 내용 | 출처 |
| --- | --- |
| 표준 태그 이름 | 로컬 태그 라이브러리(라이브러리에서 찾을 수 있는 완전한 태그만 포함) |
| 중국어 번역명 | 이전에 번역하여 캐시한 태그 이름 |
| 짧은 뜻풀이 | 로컬 Wiki: 해당 중국어 뜻풀이가 있으면 사용하고, 없으면 원문의 짧은 설명을 원문임을 표시하여 첨부 |
| 분류 | 로컬 태그 라이브러리(작가 / 작품 / 캐릭터 / 일반 등) |

다음과 같은 제한도 적용합니다.

- **용어집은 참고 자료일 뿐**: 프롬프트와 용어집은 번역할 데이터이지 지시가 아니라고 모델에 명확히 알립니다. 뜻풀이를 프롬프트에 덧붙일 수 없으며, 찾을 수 없는 태그의 의미나 관계를 지어내서도 안 됩니다.
- **완전한 태그에만 적용**: 문장 속 일반 단어에 Danbooru의 의미를 억지로 적용하지 않습니다.
- **결과를 로컬에서 대조**: 번역문에 작가·작품·캐릭터로 표시된 태그는 로컬 태그 라이브러리에 있어야 합니다. 분류 아이콘은 Studio가 로컬 데이터로 정하며 모델이 제시한 분류는 믿지 않습니다. 일치하지 않는 표시는 버리되 번역문 자체는 유지합니다.
- **번역명과 뜻풀이를 별도로 캐시**: Wiki 원문이 바뀌면 오래된 중국어 뜻풀이 대신 새 원문을 사용해 낡은 설명이 모델을 오도하지 않도록 합니다.
- **조회는 모두 로컬에서 처리**: 용어집 검색으로 모델을 추가 호출하지 않으며, 검색에 실패해도 번역은 계속합니다.

같은 용어집을 “↑ 번역문을 원문으로”, 태그 번역, 위키 번역에도 사용합니다. 편집기에 중국어를 쓰면 모델이 일치한 표준 태그를 참고해 정확한 영어 태그로 되돌릴 수 있습니다. 태그 이름이나 Wiki 본문을 번역할 때도 관련 태그의 뜻풀이를 첨부해 이름이 같은 작가·작품·일반 단어를 구분하도록 돕습니다.

## 팁

- 가운데 버튼으로 언제든 원문을 확인하여 모델이 `cat ears`를 이상하게 번역하지 않았는지 확인합니다.
- 번역은 저장되는 생성 원문을 바꾸지 않으며 Anlas 소비에도 영향을 주지 않습니다.
- 태그와 백과 자동 번역은 기본적으로 꺼져 있습니다. 필요할 때 [태그 백과](tags-wiki.md)와 사전 설정에서 켭니다.
