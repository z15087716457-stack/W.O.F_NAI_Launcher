# 빠른 시작

## 1. 설치

[Releases](https://github.com/z15087716457-stack/W.O.F_NAI_Launcher/releases/latest)에서 다운로드합니다.

- **설치형** `WOF_NAI_Studio_Windows_<버전>_Setup.exe`: 두 번 클릭해 설치합니다. 기본 경로는 `%LOCALAPPDATA%\Programs\W.O.F NAI Studio`이며 관리자 권한이 필요하지 않습니다.
- **포터블** `WOF_NAI_Studio_Windows_<버전>_Portable.zip`: 원하는 폴더에 압축을 풀고 안에 있는 `nai_launcher.exe`를 실행합니다.

시스템 요구 사항: Windows 10 또는 11(64비트)입니다.

> 설치 파일에는 아직 서명이 없습니다. Windows에서 “Windows의 PC 보호”가 표시되면 “추가 정보 → 실행”을 클릭합니다. 변조 여부가 걱정된다면 Release 페이지의 SHA-256 체크섬과 비교할 수 있습니다.

## 2. 로그인

- **API Token(권장)**: NovelAI 사이트의 계정 설정에서 `pst-`로 시작하는 Persistent Token을 만들어 붙여 넣습니다.
- **계정과 비밀번호**: 공식 사이트와 같은 정보를 사용합니다.
- **게스트 모드**: 로그인 페이지에서 로그인을 건너뛰고 갤러리, 블록, 태그 백과 같은 로컬 기능을 먼저 사용할 수 있습니다. 이미지 생성에는 로그인이 필요합니다.

Token과 비밀번호는 Windows 시스템 보안 저장소에 저장하며 이 PC에서만 사용합니다.

## 3. 첫 이미지 생성

<img src="../../images/readme/en/hero.webp" alt="이미지 생성 페이지" width="100%">

1. 왼쪽 위에서 모델을 선택합니다(V4.5 또는 V5 권장).
2. 프롬프트 입력란에 영어 태그를 작성합니다. 예를 들면 다음과 같습니다.
   ```
   1girl, solo, silver hair, starry sky, glowing flowers, night, cinematic lighting, very aesthetic, masterpiece
   ```
3. 아래에서 크기, 장수, 스텝 수를 설정합니다. 생성 버튼에는 이번에 사용할 Anlas가 실시간으로 표시됩니다.
4. `Ctrl+Enter`를 누르거나 생성을 클릭합니다. 생성 중에는 `Esc`로 취소합니다.

결과는 가운데 캔버스에 나타나며 오른쪽에는 기록이 표시됩니다. 조작 방법은 [무한 캔버스](canvas.md)를 참고합니다.

## 4. 바로 쓸 수 있는 팁

- **가중치 조정**: 프롬프트 일부를 선택하고 `Alt`를 누른 채 휠을 돌립니다.
- **블록 저장**: 프롬프트 일부를 선택한 뒤 우클릭하여 “블록으로 저장”을 선택합니다. 이후에는 블록 라이브러리에서 한 번 클릭해 다시 넣습니다. 자세한 내용은 [블록](blocks.md)을 참고합니다.
- **이미지 끌어오기**: 이미지를 창 안으로 끌어오면 이미지 투 이미지, Vibe 트랜스퍼, 정밀 참조, 또는 프롬프트와 파라미터만 읽기를 선택할 수 있습니다.
- **단축키**: `F1`로 전체 단축키를 확인합니다. `Ctrl+1/2/3`으로 이미지 생성·로컬 갤러리·온라인 갤러리를 전환하고 `Ctrl+,`로 설정을 엽니다.
- **Anlas 오소비 방지**: 설정에서 “높은 Anlas 비용 경고”를 켜면 한 번의 예상 소비량이 설정값을 넘을 때 먼저 확인합니다.

## 5. 데이터 위치

| 위치 | 내용 |
| --- | --- |
| 프로그램 폴더의 `user-data/` | 설정, 갤러리 데이터베이스, 캐시, 블록 라이브러리 등 |
| 프로그램 폴더의 `agent-data/` | NAI Agent 작업 공간, 채팅 기록, 스킬 |
| 직접 설정한 이미지 폴더 | 생성한 이미지 파일 |

백업할 때는 `user-data/`, `agent-data/`, 이미지 폴더를 함께 복사합니다. 업그레이드하거나 제거해도 이 두 데이터 폴더는 삭제하지 않습니다.
