# 태그 확장과 태그 백과

완전한 오프라인 태그 라이브러리, 태그 동시 출현 데이터, Danbooru Wiki가 포함되어 있어 인터넷 없이도 태그를 찾을 수 있습니다.

## 태그 확장

<img src="../../images/readme/en/tag-expansion.webp" alt="태그 확장" width="100%">

프롬프트 입력란에서 다음과 같이 사용합니다.

- 태그를 **Ctrl+클릭**: 로컬 태그 검색을 엽니다. 중국어나 영어로 태그와 별칭을 찾고 `Tab`으로 완성하거나 클릭해 삽입합니다.
- 범위를 **Ctrl+드래그 선택**: “관련 태그”, 즉 자주 함께 쓰는 태그를 확인합니다.
- 팝업의 “태그 미니 백과”에서 해당 태그의 설명을 바로 확인합니다.

일반 입력 중에는 자동 완성을 띄우지 않아 작성을 방해하지 않습니다. 같은 태그 검색을 로컬 갤러리 검색, 온라인 갤러리 검색, 블랙리스트, 블록 라이브러리에서도 사용합니다.

**데이터 출처**:

- 오프라인으로 합친 Danbooru / e621 태그·별칭 라이브러리입니다.
- 오프라인 동시 출현 데이터(어떤 태그가 자주 함께 쓰이는지)입니다.
- 중국어 의미 보충 자료(약 5만 4천 태그의 동의어와 짧은 뜻풀이)입니다.
- 선택 기능인 Danbooru 온라인 관련 태그입니다. 관련 태그만 보내고 전체 프롬프트는 보내지 않습니다. “설정 → 사전과 캐시”에서 끌 수 있습니다.

[로컬 시맨틱 검색](rag.md)을 켜면 커서 주변의 프롬프트도 고려하여 문맥에 더 맞는 태그를 추천합니다.

## 태그 백과

<img src="../../images/readme/en/wiki.webp" alt="태그 백과" width="100%">

왼쪽 탐색 메뉴의 “태그 백과”로 들어갑니다.

- 공식 그룹 목록으로 탐색하거나 태그와 별칭을 검색합니다. “설명 있음 / 아직 설명 없음”으로 필터링하고 인기도나 이름으로 정렬합니다.
- 본문은 번역문·원문·대조 표시로 전환할 수 있습니다(“위키 번역” 모델 설정이 필요하며 자동 번역은 기본적으로 꺼져 있습니다).
- “함께 자주 쓰는 태그”에 관련 태그가 표시됩니다. 클릭해 확인하고 `Shift+클릭`으로 블록에 추가합니다.
- 북마크를 추가하고 북마크 모음을 만듭니다.
- “블록에 추가”를 클릭하면 태그가 미리 입력된 블록 저장 창을 엽니다.
- 예시 이미지는 필요할 때만 불러옵니다.

단축키: `/` 검색 · `↑↓` 전환 · `Enter` 블록에 추가 · `B` 즐겨찾기 · `Alt+←/→` 앞뒤로 이동입니다.

## 데이터 업데이트

“설정 → 사전과 캐시”에서 태그와 Wiki 업데이트를 확인하고 적용하며 각 단계의 캐시를 확인하고 지울 수 있습니다. 업데이트는 직접 클릭할 때만 진행하며 자동 다운로드하지 않습니다. 직접 작성한 번역문은 새로고침해도 유지됩니다.
