# 무한 캔버스와 비주얼 채널

## 무한 캔버스

이미지 생성 페이지 가운데에는 끝없이 끌어 이동할 수 있는 캔버스가 있으며 생성 결과가 배치별로 놓입니다.

| 조작 | 방법 |
| --- | --- |
| 이동 | 휠로 위아래, `Shift+휠`로 좌우 이동하거나 가운데 버튼 / `Shift+왼쪽 버튼`으로 끕니다 |
| 확대·축소 | `Ctrl+휠` |
| 탐색 | `W A S D` |
| 전체 보기 | `Ctrl+0` |
| 원본 보기 | 인페인트처럼 원본이 있는 결과에서 마우스 버튼, 스페이스 또는 Enter를 누르고 있으면 원본과 이번 수정 범위를 표시합니다(이미지에 OLD 표시) |

- 생성을 클릭하면 먼저 자리 표시자를 놓고 최신 그룹으로 이동합니다. 생성 중 미리보기와 최종 결과가 모두 같은 자리에 나타납니다.
- 마음에 드는 이미지를 캔버스에 “이미지 고정”하면 기록을 지워도 남습니다.
- 투명 배경 이미지의 바탕 모양(체커보드·단색 등)을 선택할 수 있습니다. 표시용일 뿐 이미지에 저장하지 않습니다.
- “캔버스 표시”에서 확대해 채우기, 동작 줄이기, 캔버스 카메라 잠금을 켜고 끌 수 있습니다.

## 비주얼 채널

<img src="../../images/readme/en/channel.webp" alt="비주얼 채널" width="100%">

비주얼 채널은 캔버스 양쪽에서 스크롤에 따라 움직이는 장식입니다. **이미지 바깥에만 그리므로 이미지를 가리지 않습니다.**

캔버스 왼쪽 아래 톱니바퀴 → “캔버스 표시” → “비주얼 채널”로 엽니다.

- **테마**: 회로, 성도, 식물 표본, 회랑, 심해, 청해파, 무브먼트, 지층, 지하철, 악보, 달의 위상으로 총 11가지입니다.
- **모드**: 끄기, 고정, 매번 무작위가 있습니다. 무작위는 테마를 최소 두 개 유지해야 하며 “다시 섞기”로 바꿀 수 있습니다.
- **농도**: 연하게·보통·진하게 중에서 선택합니다.
- **시간 눈금**: 배치 시간, 날짜 구분선, 오른쪽 눈금 막대를 표시합니다.
- **대기 중 움직임**: 생성 중이 아닐 때 장식이 조금씩 움직이며 생성할 때는 자동으로 일시 정지합니다.
