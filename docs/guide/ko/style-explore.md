# 화풍 유전(화풍 탐색)

화풍 탐색은 **어떤 작가를 섞어야 가장 좋을까**라는 질문을 돕는 기능입니다. 먼저 무작위 작가 풀로 후보를 일괄 생성하고 마음에 드는 것을 고르면 프로그램이 “교차·변이”로 다음 세대를 만듭니다. 고르기만 하면 세대를 거듭하며 원하는 화풍에 가까워집니다.

<img src="../../images/readme/en/explore-main.webp" alt="화풍 탐색" width="100%">

왼쪽 탐색 메뉴의 “화풍 탐색”으로 들어갑니다. 탐색 페이지와 이미지 생성 페이지는 같은 프롬프트와 파라미터를 공유합니다.

## 준비: 무작위 블록 넣기

프롬프트에 무작위 모드 블록을 넣습니다. 수십 명의 작가를 담은 작가 풀 등을 사용합니다(만드는 방법은 [블록](blocks.md) 참고). 예를 들면 다음과 같습니다.

```
1girl, solo, silver hair, starry sky, night, {画师池·示范}, very aesthetic, masterpiece
```

작가 풀을 무작위로 설정하고 매번 2–3명을 무작위 가중치로 뽑도록 합니다.

## 1단계: 후보 뽑기

왼쪽 아래의 “후보 N장 뽑기”를 클릭합니다. 이미지마다 작가를 다시 뽑으므로 화풍이 달라집니다. 장수 옆에 예상 Anlas 소비량이 표시되며 잔액이 부족하면 버튼이 빨간색으로 바뀝니다.

후보가 나오면 다음과 같이 사용합니다.

- 클릭해 확인하면 오른쪽 검사기에 **뽑힌 작가**, 시드, 전체 프롬프트가 표시됩니다.
- 하트를 클릭해 즐겨찾기에 추가하고 `1`–`9`로 서로 다른 그룹에 빠르게 분류합니다.
- 그리드가 비좁으면 카드 크기를 바꾸고 두 번 클릭해 크게 봅니다.

## 2단계: 진화 시작

마음에 드는 후보 몇 장을 다중 선택한 뒤 “진화 시작”을 클릭합니다.

1. 후보마다 뽑힌 작가 문자열 하나가 **부모**가 됩니다.
2. 부모의 **교차**(두 부모에서 일부씩 가져오기), **변이**(가중치 조정, 가끔 작가 한 명 제거), **새 작가 주입**으로 자손을 만듭니다.
3. 마음에 드는 자손을 선택해 **다음 세대를 키웁니다**.

<img src="../../images/readme/en/explore-evolution.webp" alt="진화 라인" width="100%">

규칙은 다음과 같습니다.

- 부모마다 자손이 최소 한 장씩 배정되므로 부모가 많을수록 한 라운드에 필요한 장수가 늘어납니다.
- 최신 세대에서만 다음 세대를 만들 수 있습니다. 이전 세대는 볼 수 있지만 중간에서 분기할 수 없습니다.
- “충분히 다른 자손을 만들 수 없습니다”가 표시되면 유전자 풀이 너무 작다는 뜻입니다. 작가 풀에 작가를 더 추가합니다.
- 여러 블록을 “유전 대상”으로 설정할 수 있습니다(순서·무작위 모두 가능). 뽑힌 결과를 하나의 부모 문자열로 합칩니다.

> 부모를 직접 더 넣으려면 진화 시작 대화상자에서 “사용자 작가 문자열 추가”를 클릭합니다. 예: `0.8::artist:sample_alpha::, artist:sample_beta`.

## 3단계: 둘씩 비교(선택)

결정하기 어렵다면 “둘씩 비교해 순위”를 클릭합니다. 부모 이미지 두 장을 나란히 보고 원하는 쪽에 가까운 것을 선택합니다. 선호도가 높은 부모일수록 다음 세대를 키울 때 자주 선택됩니다. 결과는 수시로 저장되므로 중간에 닫아도 됩니다.

<img src="../../images/readme/en/explore-compare.webp" alt="둘씩 비교" width="100%">

## 4단계: 결과 저장

마음에 드는 화풍을 찾으면 “블록으로 저장”을 클릭합니다.

- **뽑힌 작가만**: 작가 블록으로 저장합니다. 여러 장을 선택하면 합친 뒤 중복을 제거합니다.
- **전체 포지티브**: 후보를 한 장만 선택했을 때 사용할 수 있습니다.

저장한 블록은 이미지 생성 페이지에서 바로 사용할 수 있습니다.

## 자주 묻는 질문

- **버튼이 비활성화되어 진화할 수 없습니다**: 프롬프트에 활성화된 순서·무작위 블록이 없거나 유전을 켜지 않은 상태입니다.
- **탐색을 삭제하면 이미지도 삭제됩니까**: 아닙니다. 탐색 작업의 후보 사본만 삭제하며 로컬 갤러리의 원본에는 영향을 주지 않습니다.
- **첫 세대가 전부 마음에 들지 않습니다**: 정상입니다. 몇 세대를 더 고른 뒤 판단합니다. 변이가 예상 밖의 결과를 만들기도 합니다.
- **이미지 생성 페이지의 초안을 바꿉니까**: 진화 라운드는 별도 데이터로 실행하며 현재 블록의 잠금 상태와 뽑기 결과는 바꾸지 않습니다.
