# 이미지 도구

## Vibe 트랜스퍼와 정밀 참조

- **Vibe 트랜스퍼(Vibe)**: 한 장 또는 여러 이미지의 화풍과 분위기를 참조합니다. 강도와 정보 추출량을 조정할 수 있으며 한 번 인코딩하면 재사용할 수 있어 Anlas가 추가로 들지 않습니다.
- **정밀 참조**: 캐릭터나 화풍을 참조하며 충실도를 조정할 수 있습니다. 이미지마다 과금합니다.
- 둘 다 설정하면 정밀 참조가 우선하며 Vibe 트랜스퍼는 전송하지 않습니다(화면에 안내합니다).

왼쪽 탐색 메뉴의 “Vibe 라이브러리”와 “정밀 참조 라이브러리”에서 두 종류의 참조 이미지를 각각 관리합니다. 검색, 그룹 분류, Vibe 전체 패키지 가져오기·내보내기를 지원합니다.

## 디렉터 도구

<img src="../../images/readme/en/tools-director.webp" alt="디렉터 도구" width="100%">

NovelAI의 일곱 가지 디렉터 도구를 제공합니다. 배경 제거, 불필요한 선 정리, 선화 추출, 스케치화, 채색, 표정 수정과 로컬에서 실행하는 픽셀 정렬입니다. Opus 구독은 1MP 이내에서 대부분 무료입니다(배경 제거는 항상 과금합니다). 결과를 복사·저장하거나 입력 대기열에 추가하고 바로 이미지 투 이미지로 사용할 수 있습니다.

## 인페인트와 편집

<img src="../../images/readme/en/tools-inpaint.webp" alt="인페인트 편집기" width="100%">

전체 화면 편집기에 브러시, 지우개, 채우기, 마술봉(스마트 객체 모드 선택 가능, 처음 사용할 때 약 133 MB 모델 다운로드), 선택 영역, 올가미, 복제 도장, 흐림, 레이어, 캔버스 크기, 색조·채도를 갖추고 있습니다.

마스크를 그린 뒤 “적용”하거나 바로 “적용 후 생성”할 수 있습니다. 캔버스의 생성 결과를 누르고 있으면 원본과 비교합니다.

## 업스케일

<img src="../../images/readme/en/tools-upscale.webp" alt="업스케일" width="100%">

| 방식 | 설명 | 요구 사항 |
| --- | --- | --- |
| NovelAI 업스케일 | 클라우드에서 2배 확대하며 이미지 크기에 따라 과금합니다 | 로그인 |
| 로컬 · Real-ESRGAN | 내장 엔진과 모델(애니 고화질, 애니 고속, 일반 사진)을 사용합니다. 1–4배 확대하며 투명도를 유지하고 Anlas를 쓰지 않습니다 | Vulkan 지원 그래픽카드 |
| 로컬 · RTX | NVIDIA RTX Video로 빠르게 확대합니다. 약 64 MB 구성요소 다운로드가 필요합니다 | NVIDIA RTX 그래픽카드 |
| 로컬 · SeedVR2 | 고품질 업스케일입니다. 3B / 7B / 7B Sharp 등 여러 모델(가중치 3.4–8.2 GB)이 있으며 색상 보정, VRAM 정책 등 고급 설정을 지원합니다 | NVIDIA 그래픽카드(INT8 버전은 Turing 이상) |

로컬 업스케일 구성요소와 모델은 “설정 → 로컬 업스케일”에서 필요에 따라 다운로드합니다. 생성 페이지의 “향상”에서 로컬 방식을 선택하면 이미지 생성 후 자동으로 PC에서 업스케일할 수도 있습니다.
