# 자주 묻는 질문

### 실행할 때 Windows에서 “Windows의 PC 보호”가 표시됩니다

설치 파일과 프로그램에는 아직 코드 서명이 없습니다. “추가 정보 → 실행”을 클릭합니다. 변조 여부를 확인하려면 Release 페이지의 SHA-256 체크섬과 비교합니다.

### 설치형과 포터블의 차이는 무엇입니까

기능은 완전히 같습니다. 설치형은 `%LOCALAPPDATA%\Programs\W.O.F NAI Studio`에 설치하며 시작 메뉴와 제거 항목을 만듭니다. 포터블은 원하는 위치에 압축을 풀어 실행합니다. 둘 다 앱 내 업데이트를 지원합니다.

### 데이터는 어디에 저장하며 어떻게 백업합니까

- 설정·갤러리 데이터베이스·블록 라이브러리: 프로그램 폴더의 `user-data/`입니다.
- NAI Agent: 프로그램 폴더의 `agent-data/`입니다.
- 이미지: 직접 설정한 이미지 폴더입니다.

이 세 곳을 복사하면 전체 백업이 됩니다. 업그레이드하거나 제거해도 `user-data/`와 `agent-data/`는 삭제하지 않습니다.

### 구버전(1.x)에서 업그레이드하기

새 버전을 바로 설치하면 됩니다. 구버전의 AppData 데이터는 처음 실행할 때 전체 백업과 검증을 거친 뒤 `user-data/`로 이전합니다. 이전 설치형도 앱 내 업데이트로 업그레이드할 수 있습니다.

### 한 번 생성할 때 Anlas는 얼마나 듭니까

생성 버튼에 이번 총소비량이 실시간으로 표시됩니다(장수 × 장당 가격이며 참조 이미지 인코딩 등을 포함합니다). 설정에서 “높은 Anlas 비용 경고”를 켜면 설정값을 넘을 때 먼저 확인합니다. NAI Agent와 외부 브리지로 이미지를 생성할 때도 가격 카드에서 직접 승인해야 합니다.

### 어떤 기능이 인터넷을 사용합니까

- NovelAI API(생성, 계정, 업스케일, 디렉터 도구)입니다.
- 직접 설정한 대규모 언어 모델 서비스(번역, 역추론, NAI Agent)입니다.
- 온라인 갤러리 소스(Danbooru, Safebooru, Gelbooru, AI TAG)입니다.
- 업데이트 확인(이 저장소의 GitHub Releases)입니다.
- 직접 다운로드를 선택한 선택 구성요소(시맨틱 검색 모델과 환경, 업스케일 모델, 마술봉 모델)입니다.

시맨틱 검색, 로컬 업스케일, 갤러리 정리는 모두 PC에서 처리합니다. Danbooru 온라인 관련 태그에는 관련 태그만 보내고 전체 프롬프트는 보내지 않습니다. “설정 → 사전과 캐시”에서 끌 수 있습니다.

### 계정과 키는 안전합니까

NovelAI Token, 비밀번호, 각 서비스의 API 키는 Windows 시스템 보안 저장소에 저장하며 이 PC에서만 사용합니다. MCP 구성은 암호화 저장소에 저장합니다.

### 어떤 그래픽카드가 필요합니까

이미지 생성은 NovelAI 클라우드에서 처리하므로 그래픽카드 요구 사항이 없습니다. 선택적인 로컬 기능에만 필요합니다. 로컬 업스케일은 Vulkan 지원 그래픽카드, RTX 업스케일은 NVIDIA RTX 그래픽카드, SeedVR2는 NVIDIA 그래픽카드가 필요합니다. 시맨틱 검색은 NVIDIA 그래픽카드가 있으면 빠르지만 없어도 CPU로 사용할 수 있습니다.

### 인터페이스 언어는 어떻게 바꿉니까

“설정 → 모양”에서 简体中文, 繁體中文, English, 日本語, 한국어를 선택할 수 있습니다. 밝게·어둡게·시스템에 맞춤도 선택합니다.

### 문제는 어떻게 제보합니까

이 저장소의 [Issues](https://github.com/z15087716457-stack/W.O.F_NAI_Launcher/issues)에 버전, 재현 단계, 화면 이미지를 첨부해 제출합니다. 화면 이미지에 Token이나 키가 노출되지 않도록 주의합니다.
