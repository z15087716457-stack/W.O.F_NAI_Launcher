# F44 · 撤销三个工具条强制深色

**已随 [r15 本机更新](cumulative-preview-r15-2026-10-16.md) 安装，最终观感待用户验收。**

r14 把用户给出的深色玻璃截图误解为所有主题都固定深色，在三条工具条外加入 `_CanvasFloatTheme`。这偏离了恢复玻璃效果并跟随明暗主题的需求；当时新增测试也验证了错误的固定深色行为。用户实机指出浅色页面仍为黑条后，明确撤销该做法。

改正现有动态图案测试：浅／深主题中三条实际材质和前景保持对应主题，同时蓝／红背景仍透过玻璃；直接读取像素区分浅、深底色。真实页面接线检查浅色工具条、高对比度回退。原型 PNG 不改，并撤销 r14 对两个底部工具条新增的视觉排除，让其再次参与原始像素比较。
