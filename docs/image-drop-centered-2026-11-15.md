# 全窗口居中图片拖入提示

2026-11-15，根据+104实测截图反馈实施。用户确认全窗口压暗、纵向居中卡片约400×180、图标40、主文字18、说明13、留白24；拖入与读取保持同一位置。已随本机**2.3.4+105**安装，程序未自动启动，真实拖图由用户实测。[交付核验](local-2.3.4-build105-2026-11-15.md)

## 实现

- 继续使用`UiImageDropOverlay`、`UiCard`、`UiGlyphs.image`、`UiSpinner`及现有五语言文案。遮罩为40%黑色，覆盖应用根Overlay；卡片宽400、最小高180，窄窗扣除两侧24留白，长译文自然增高。两套文案共用IndexedStack尺寸，切换状态不改变卡片边界。
- GlobalDropHandler使用OverlayPortal与rootOverlay位置，将视觉层投射到窗口；原生DropRegion仍在原位置，未扩大接收区域。导航／侧栏也会变暗，拖入时不截获底层命中；读取时窗口输入屏障生效。新弹出的用途选择对话框仍位于提示层之上，可正常操作。
- 原生回调返回前启动全部读取、后续逐张导入、防重入、排除区域与图库内部拖拽策略保持；Portal随处理器销毁自动撤掉，不保留异步悬浮层。
