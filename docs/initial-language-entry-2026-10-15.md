# F15 · 首次系统语言与登录页切换

## 行为

- 首次设置迁移完成后、创建应用首帧前，从系统偏好列表中选第一个支持的语言；支持简中、繁中、英、日、韩，全部不匹配时使用英文。中文优先按 Hans／Hant 脚本，再按地区判断。
- 只在 `locale` 尚无值时保存检测结果；现有值（包括历史 `zh` 和带地区的存储值）保留。自动选定后也会记住，后续改变系统语言不会覆盖应用选择。
- 登录和载入页主题按钮左侧增加地球图标，菜单用各语言自身名称并勾选当前语言；复用设置页的语言 provider 与持久化。切换时保留已输入文本、编辑器控制器、选择范围、当前表单、主题及载入进度。
- Windows 沉浸标题栏的可点击保留宽增加为 227px；语言菜单在标题栏下展开，工作区继续使用原窗口按钮布局。没有 Windows 自绘标题栏时，两个入口放在页面右上角。
