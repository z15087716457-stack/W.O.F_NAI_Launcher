# 外部 Agent · 画布底部通知

已按用户后续指定的位置补齐：提示位于画布底部中央、左下信息条与右下操作条之间。此位置覆盖原 HTML 样板中靠近小水滴的收起态示意；外部侧栏及卡片继续沿用原样板。本批仅源码更新，未安装桌面，当前桌面仍为 2.3.3+100。

## 行为

- 宽画布与两侧工具条保持同一底边，使用相同的玻璃材质与明暗主题。长标题省略，始终保留「查看」。中间空间不足时抬高一行；工具条已上下排列的极窄画布中，提示位于它们上方。
- 按工具条真实尺寸布局，原有尺寸／种子、固定、复制、保存和详情操作保留。空画布也可接收提示，不额外创建工具条；临时通知不触发相机重新构图。
- 新结果显示约五秒后淡出，后台状态刷新不重置计时。淡出后不拦截点击、不保留屏幕阅读器内容。小水滴角标继续保留；过期结果切回页面不重播。
- 「查看」绑定当前提示的实际外部会话，展开后清除该会话提示；保留已有内部输入草稿。侧栏已经展开时使用原有侧栏入口，不叠加画布提示。

## 同时整理的流程

1. 任务执行中收起侧栏，完成后重新计算可见状态并发布通知，修正仅在调用开始时设置未读而漏掉最终结果的问题。
2. 小水滴和侧栏「查看」统一选择最近的外部未读会话。原生提问／付费确认在实际进入等待状态后提示；已有等待项不会压住其他会话后来完成的新结果。
3. 区分更新成功、操作未完成和需要用户处理。复用原生结果中的错误、`ok:false` 与取消状态：显式取消不伪报更新，原生部分失败不伪报全部成功；不改传给外部宿主的原工具结果。
4. 只读调用保持安静。通知、未读时间和已读状态均为瞬时 UI 信息，不写入历史，不随恢复重放；关闭状态下仅绘制通知槽不会创建 Agent 控制器／宿主。

检查范围为本次外部调用、通知、侧栏与产物路径，没有开展全仓架构重写。工具定义、模型推理、既有权限和付费契约保持原有路径，原始接入说明见[外部会话](external-agent-session-2026-11-13.md)。

## 实现位置

- `external_session.dart`、工作区控制器及外部桥接：保存瞬时事件，按完成时状态设置未读，统一未读路由与原生结果解释。
- `AgentCanvasNoticeWiring`：只订阅已存在的控制器及实际待确认项；按事件选择文案和目标。
- `AgentCanvasNotice`：五秒计时、主题、长文省略、查看、淡出和无障碍语义。
- `GenSlots.canvasNotice`、`GenCanvas`：通知独立接入画布，统一布局父级先测量工具条，再放置通知，避免按猜测宽度挤压按钮。
