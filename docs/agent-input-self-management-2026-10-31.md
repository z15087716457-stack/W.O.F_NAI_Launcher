2026-10-31。九项源码实现与自动化验证完成，已随本机 **2.2.3+72** 安装；[交付核验](local-2.2.3-build72-2026-10-31.md)。尚未公开发布，未操作正式数据。

## 实现

| 范围 | 结果 |
|---|---|
| 多图拖入 | 原生回调返回前发起每个读取器的读取；后续解码、校验和导入仍逐张处理，单图失败不阻断其余图片 |
| 待发送图片 | 点击接入现有大图查看器，可缩放及切换同组附件；悬浮信息与删除保留 |
| 拖放范围 | 接收与高亮仅覆盖输入卡片；Agent 其余区域拒绝全局画布导入 |
| MCP 状态 | 修复设置先打开、Agent 后初始化时的空缓存；使用 Pi 状态展示连接、失败、登录、禁用与待应用，提供重连及失败详情，无新增轮询 |
| MCP 表单 | 名称、HTTP／本地命令、地址／参数、现有两行请求头控件；高级项含 OAuth、环境变量和 cwd。支持 JSON 往返编辑与未保存连接测试；修改字段后清除旧测试结果 |
| Skill | 创建、导入、启停、调用模式、删除及刷新共用现有存储、解析和删除恢复流程；包内 Skill 使用原路径，可独立禁用 |
| 扩展与包 | 本地扩展登记与解除引用；Pi 原生包管理器处理 npm、git、本地来源及版本替换，安装选择只持久化一次，包资源不复制到第二套目录 |
| MCP 自管理 | 与表单共用校验、加密存储和配置服务；可查询、增改删、启停、切换暴露、检测、重连及认证。连接检查／OAuth 直接复用 Pi 连接器，不创建 Agent 会话 |
| 自身设置与指令 | 读取可编辑值、默认值和版本；修改先备份并核对版本。工作区基础提示支持覆盖及恢复继承；全局设置保留。规则、模板及扩展正文继续使用原生文件工具 |

## 一个入口与现有机制

新增原生 deferred `agent_manage`，按资源／动作调用共用服务，保持默认七入口。关闭 Studio 业务 MCP 后仍可发现并重新启用它。详细参数放在 `nai-studio/references/self-management.md`，Pi 原生文档按需读取，不注入整份管理手册。

Skill、包及指令支持工作区／全局作用域；MCP、本地扩展登记与 Agent 设置沿用原有共享配置。原生包安装目录归 `.W.O.F/` 或全局 `agent-data/`，不重新在项目根散落启动器资料。

自管理修改在下次空闲发送时读取并恢复同一 Pi 会话，返回 `applies: next_turn`；当前管理调用先完成，不触发即时停机或回入当前会话的空闲命令。设置页原有即时操作保留。沿用现有权限钩子，只读模式阻止修改，完全权限不增加审批。

`manage-resources.mjs` 只是按需 SDK 实用程序，与已有 `list-skills` 同类；没有第二套 Agent 循环、包解析器、MCP 配置文件或后台连接管理器。取消时关闭其自有子进程。
