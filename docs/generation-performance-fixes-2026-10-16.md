# 生图页五项性能优化 · 2026-10-16

**已随 [r17 本机更新](cumulative-preview-r17-2026-10-16.md) 安装；下文保留实现阶段的基线和验证边界。**

用户在认可 r16 的两侧 65% 效果后，授权实施[调查报告](generation-performance-audit-2026-10-16.md)中的全部五项优化，要求保持现有视觉和交互。实现阶段仅修改有效源码，安装基线为 r16 / `2.0.0-preview+20`；当时未覆盖安装、启动、重启或热重载 Studio，未调用真实生成接口或模型。

## 实现

1. **批次边界索引**：`CanvasGroupBoundsIndex` 在布局改变后合并一次各组的实际图块矩形。角标、最近组选择与相机导航共用索引；矩形仍取原来的 union，空组返回 Rect.zero，不改变角标位置。
2. **收藏查询失效范围**：图片列表、ID／保存路径集合和图库内容版本分别投影。进度不再触发收藏读取，重复保存路径合并，未完成的查询复用；保存路径替换、删除及图库收藏版本变化仍刷新，迟到的旧结果不能恢复已移除的 ID。本批没有增加批量 SQL 接口，真正的收藏变更仍按唯一保存路径读取。
3. **输入刷新拆分**：历史批次、图片目录、焦点和参考数据独立投影；GenScope 使用分区订阅，画布图块只订阅焦点 ID／底纹。路由快捷键在执行时读取最新状态；操作与槽位复用稳定身份，菜单回调也不再因输入而通知全部图块。编辑器按本框文本和模型订阅，草稿仍即时同步。Token 先解析别名、预设、角色与跨正负面语义，再对各目标的有效 payload 比较；保留正向 NSFW 标签影响负面预设的现有规则。编码结果使用最多 256 项的内存缓存，共享统计小计／合计和并发贡献，失败可重试，模型上限与网页校准不变。
4. **流式内容与布局分离**：`canvasFeedGeometryProvider` 只监听图片、批次、尺寸和 Pins；`canvasFeedLayoutProvider` 给活动槽补最新进度、预览和重绘位置，保留历史条目身份与坐标。通道背景监听几何。新成图、尺寸变化、停止、删除及固定图变化仍布局，原相机锚点规则保持。嵌入图块按条目、焦点、固定状态与构建器复用；主题／文字环境或构建器替换会失效，回调不使用过期输入。
5. **预览解码尺寸**：历史封面、参考图及参考标题背景使用独立派生预览。布局 × DPR 后保留 1.5 倍滤波余量，向上取 32px 档位，按 cover 同时满足两轴，保持原始比例，小图不放大解码。侧栏宽度或 DPR 切换时保留上一帧；更换来源保持原来的 gapless 策略。画布放大、OLD、蒙版、拖拽、复制、保存和元数据继续使用原图，没有改写文件或截断历史。

## 同条件计数

基线是调查时的 r16；后测为真实 GenerationWiring 页面和隔离数据，证据在 `.dart_tool/generation-perf-fix-20261016/`。

| 场景 | r16 | 优化后 |
|---|---:|---:|
| 800 图／200 批，每步平移的批次边界条目读取 | 161,600 | 0（布局变化时建一次索引） |
| 800 张已保存图，10 次进度更新的收藏服务调用 | 8,000 | 0 |
| 同上，图库内容版本单次变化的收藏调用 | 800 | 800，保留必要刷新 |
| 20 次输入：GenCanvas／GenHistoryPanel 重建 | 各 59 | 各 0 |
| 20 次输入：可见 GenCanvasTile 重建 | 354 | 0 |
| 20 次输入：三个 ChannelBackdrop 重建合计 | 177 | 0 |
| 20 次输入：Token 编码器调用 | 120 | 40 |
| 其中未改动负向文本的编码器调用 | 40 | 0 |
| 历史不变，仅 progress 变更 10 次：feed 布局发布 | 10 | 0 |
| 100×150 预览，DPR=3，2048×3072 源图的解码尺寸 | 2048×3072 | 480×720 |
| 上述单份解码原始 RGBA 像素 | 24 MiB | 约 1.32 MiB |

20／200／800 张历史与 V4.5／V5 Full 的输入检查均满足相同失效边界；平移与缩放仍不触发 Token、历史布局或页面数据投影。页面的轻量总投影在 20 次输入中仍发布 59 次，已将无关重计算和重建分离，不能描述成“整页零更新”。稳定空闲探针仍为 60×16ms 无 Widget 重建，中央背景绘制计数 20，不代表原生 FPS。

实际流式更新由行为测试补充：800 张历史、10 帧活动槽，几何和通道对象保持身份，保留条目的世界坐标及对象保持，活动槽进度／图片立即变化；完成图尺寸变化会重新布局，已有历史锚点保持。该测试没有加载真实权重或向网络生图。

收藏与 Token 操作计数使用替身，未测真实 SQL／T5 编码延迟。解码像素不是进程内存或显存：放大画布可能同时持有原图与派生预览，不能据此宣称整体内存下降相同比例。原生 GPU／帧时间、长会话峰值和用户最终观感仍须实机验收。

## 视觉与回归

原型 PNG、既有排除区域和玻璃材质参数保持。截图测试只补充等待当前预览 provider 解码完成，不更新基准，也不扩大排除区域。三个工具条在真实浅／深主题中仍分别为浅／深玻璃，保留局部模糊、纹理、前景、阴影及高对比度回退；两侧仍为 65%。工具条实绘在审计目录 `captures/float-theme-light.png` 与 `float-theme-dark.png`，已查看。

缩略图另测 DPR 1／1.25／1.5／2／3、极宽／极高裁切、小图原像素、档位复用、原图完整尺寸及调整宽度时的帧保留。合成渐变／细结构图在显示尺寸的平均颜色差小于一个 8-bit 色阶；缩小解码存在重采样，不承诺所有原图逐像素相同。原图功能保持全尺寸。

验证结果见审计目录的 `regression-result.json`、`final-scope-tests.log`、`final-affected-tests.log`、`analyze-final.log`、`windows-build.log` 与 `protected-verification.json`。综合回归 973 项通过，随后新增构建器替换边界，受影响范围重新验证；最终不同检查合计 974 项，无跳过；最后一次分区调整后的受影响范围 308 项再次通过。全仓分析及最后 5 文件分析无诊断，Windows Release 构建通过，1516 项跟踪生产输入在最终构建前后保持哈希一致。完整结论见 `verification.json`；实现阶段该构建用于编译验证；后续 r17 已重新构建并完成本机交付。

修改未涉及依赖、数据库结构、国际化或生成输入，因此没有运行代码生成器。原有 DEVELOPMENT.md 与 .runs/ 保留；生成文件、原 PNG、共用玻璃组件与侧栏材质哈希核验通过。实现阶段的安装基线 AOT 为 `bea5ef593c1f4752048afee0a5be032a4390c71c6f7678bb89bea20041b60499`，当前安装状态以 r17 本机交付为准。
