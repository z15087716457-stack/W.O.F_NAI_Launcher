# 图库提示词搜索统一与旧文字索引修正

2026-11-17。用户确认[审查方案](gallery-prompt-search-audit-2026-11-17.md)后完成源码实施。当前工作树与已有未提交改动保留；本机仍2.4.1+117，本批未构建、安装、启动程序或发布。

## 当前搜索规则

- **普通输入固定做内容搜索**：查询文件名／路径、正向提示词、角色正向、现有可检索参数和手动标签。全局标签表不再决定某个词是否突然改用精确匹配；给其他图片添加标签可以增加新命中，不能删掉原有内容命中。
- **标签chip保持完整标签身份**：共用当前正向内容与显式手动标签，`blue eyes`不会因原文只有`blue eyes shadow`而被当成同一个标签。括号等名称标点保留。
- **空格保留短语，逗号／换行组合条件**：`blue eyes`是一个短语，`blue eyes, silver hair`要求两个内容条件同时满足。括号与引号内的逗号、引号内的换行保持字面短语，不拆成额外条件。
- **查询与派生索引共用归一化**：正／负数字权重、闭合符、权重括号、连续空白和空格／下划线表示统一处理。`::`闭合片段不再要求同一片段带数字开头；普通字面标点继续保留。检索缓存按规范化后的条件列表识别，逗号AND与连续短语仍然不同。

原始图片、提示词、角色JSON、负向词与生成参数不随检索归一化改写。RAG继续在现有图库范围内补充语义结果，基础搜索独立命中原图；本批没有修改Danbooru标签语义检索或向量格式。

## 收口与旧库升级

带逗号与不带逗号统一进入`advancedSearchResult`；目录路径匹配也不再由逗号有无决定。保留当前候选范围、属性筛选、排序、取消与过期结果保护；服务层移除分段前置查询及按ID重新读图片的重复流程。

删除`_knownSearchTags`、`searchByDelimitedTextSegments`及服务层四个分段／分流helper；精确标签查询仅由显式标签筛选使用。5个运行文件合计净减97行，没有增加第二套查询引擎。旧测试中“登记过标签后普通输入缩窄”的预期已按用户确认的新规则调整，同时继续断言标签chip的完整身份；导入测试改为验证实际精确标签入口。

`positive_search_text_v2`沿现有图库初始化拥有者升级派生文字索引：每页500行，从原始列及角色JSON复用新写入时的同一个文本构建器，再更新原FTS。完成标记写入后下次启动跳过；不删除图库或RAG索引，不重新编码向量。此升级代码已在隔离数据库验证，**正式图库尚未执行，安装新版后的首次初始化才会自动修正一次**。
