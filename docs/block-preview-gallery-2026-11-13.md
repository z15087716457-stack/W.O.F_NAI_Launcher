# 块多图预览与显示范围 · 2026-11-13

按用户确认的[多图样板](../../../mockups/block-crop-guide/README.md)实施。仅源码交付，桌面仍为 2.3.3+100；未安装、启动 Studio、调用模型／NAI 接口或提交 Git。

## 实际行为

- 编辑器支持一次添加多张图、替换当前图、移除当前图；下方方形缩略图点击直达，大图左右箭头循环切换。每张图独立保存位置与缩放，默认以第一张作为封面。
- 缩略图溢出时两端渐隐，普通滚轮在图条内横向浏览，不带动外层面板；当前项自动滚入可见范围。单图不显示浏览箭头。
- 箭头在悬停对应大图时显示，移出淡出；点击后留下的鼠标焦点不会让箭头滞留。键盘可聚焦／切图，触摸可唤出入口，减少动态效果偏好会关闭过渡。悬浮卡有离开缓冲，可跨越间隙进入操作。
- 显示范围默认开启，分别对应悬浮卡和详情预览。图内只绘制虚线与范围外遮罩；说明放在图外，避免挡住换图和操作提示。旧样板中的“网格卡显示范围”不再作为一个演示目标。
- 移除缩放滑杆和整行底部控制，图下右侧仅显示放大图标与百分比；滚轮／捏合调整，点击百分比回到 100%，保留位置。
- 悬浮卡词条由前 7 项改为按实际宽度展示最多五行（含剩余数量提示），随字体缩放重新排布；少量词条保持自然高度。侧栏、积木及块库共用。
- 横图在编辑区显示完整裁切范围，裁切框居中，拖动方向与画面移动一致。竖图保留原来的展示方式。偏移和缩放仍使用现有消费端的 Alignment 坐标，未改变提示词、生成参数或块的抽取行为。

## 数据与文件生命周期

`PromptBlock` 的旧 `thumbnail`、`thumbnailOffsetX/Y`、`thumbnailScale` 保持第一张封面；新增 `additionalThumbnails` 保存其余图的路径与独立裁切参数。旧 JSON 缺少该键时为空，不需要重写用户库。`thumbnails`／`withThumbnails` 统一枚举、首张接替和清空。

图片继续归一化为 PNG 并复制到托管目录，原文件不改动。保存先准备全部新图并核对既有编辑版本，失败清理本次临时副本；复制、跨文件夹复制、删除、删除撤销和文件夹删除覆盖整组图。仍被其他块或隐藏来源引用的图片不回收。缩略图按小尺寸的两倍采样解码，避免为每个小方块解码完整大图。

库 JSON 备份保留整组路径和裁切元数据，与原单图备份一致，不嵌入图片原件。删除撤销和 Agent 操作快照另保存受影响图的字节。Agent 旧接口继续操作封面及其裁切；替换封面保留其他图，`thumbnail: null` 清空整组，额外图写入由编辑器负责。

主块库编辑入口、生图／画风探索的映射、侧栏悬浮卡、详情栏和旧提示词预览均接入。卡片墙继续以首图作为封面。

## 原型对照与实绘边界

已从确认的 HTML 通过 CUA 获取 DOM 尺寸，并运行既有捕获／测量入口的多图模式：

```text
BLOCK_GALLERY_ONLY=1 BLOCK_GALLERY_IMAGE_DIR=<批准样图目录> BLOCK_GALLERY_WIDE_IMAGE=<横图> BLOCK_GALLERY_CAPTURES=<输出目录>
flutter test --no-pub tool/ui_shell/blocks_prototype_capture_test.dart
python tool/ui_shell/blocks_measure.py --gallery
```

| 项目 | 原型 | 原生 | 尺寸差 |
|---|---|---|---|
| 编辑图 | 294×210 | 293×210 | 宽 -1 |
| 编辑缩略图 | 44×44 | 44×44 | 0 |
| 悬浮图 | 300×150 | 298×150 | 宽 -2 |
| 浏览缩略图 | 38×38 | 38×38 | 0 |
| 缩放信息 | 42.83×16 | 42.81×15 | 约 -0.02、-1 |

图片框和新控件的尺寸残差最大 **2px**，来自现有边框。范围按真实内框 298×150／307×176 计算，未把外框宽度误当图片宽度。

有意保留：应用现有主题强调色与紧凑分段控件；左侧原有第二块预览及内部滚动。原生紧凑目标切换使图像起点比独立 HTML 样板略靠上，外部容器不按独立展示卡复刻。图片／图条／缩放信息的大小和相对关系另行核对。悬浮卡英文、日文、韩文底部提示允许换行，避免长文案横向溢出。

原有基准 PNG 保留，只将已批准重做的左侧预览面板及五行悬浮卡（含原有投影覆盖范围）列为例外；其余原生截图像素回归通过。新区域用专项行为、几何和部件实绘覆盖。图片为批准样图或既有演示素材，界面内容为合成数据，**不代表运行中用户窗口**。
