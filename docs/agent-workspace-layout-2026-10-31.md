## 当前目录契约

```text
项目根目录/                   ← Agent cwd，用户项目文件自由组织
├─ AGENTS.md                  ← 可选，用户项目规则
├─ 用户项目文件…
└─ .W.O.F/
   ├─ workspace.json
   ├─ instructions.md         ← Studio 补充规则
   ├─ sessions/               ← 原生 Pi JSONL
   ├─ ui/                     ← 聊天元数据、输入草稿和队列
   ├─ attachments/
   ├─ outputs/                ← 工具默认导出和图库操作备份
   ├─ notes/
   ├─ skills/
   ├─ prompts/
   ├─ snapshots/
   └─ 其他原 .agent/ 内容…     ← draft-backups、prompt-sets、search-images 等
```

`agentDir` 指向 `.W.O.F`；全局 `agent-data/skills`、`prompts`、settings 和删除池等仍归原全局数据根。用户项目产物可以按用户要求写到根目录或自定位置，不强制全部放进默认 outputs。

根目录 `AGENTS.md` 由 Dart 在既有提示词刷新点读取，和 `.W.O.F/instructions.md` 各加入一次；修改后在下次规则刷新时生效。Pi 的环境上下文发现继续关闭，不重复加载，也不自动收集父目录规则。Windows 下 `Agents.md` 等大小写写法沿用文件系统行为。
