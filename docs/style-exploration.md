# 画风探索 · 多池遗传使用教程

> [English](style-exploration.en-US.md) | 简体中文

画风探索是一套「选育式」的画风收敛工具：对着一个方向批量出候选图，你来打标筛选，把喜欢的串设为父本，遗传引擎再做变异 / 交叉 / 注入产出下一代——逐代收敛到你想要的画风，最后一键收编成 pill 块，回到生成页直接用。

入口：左侧导航栏「画风探索」图标。

## 三十秒看懂流程

1. **准备**：把画师池 / 画风串做成块，设为随机抽取并开启遗传（DNA 角标）。
2. **基础轮**：新建探索任务，批量出几十张候选。
3. **筛选**：全屏正式筛选，键盘 T / S / R 打标。
4. **深度轮**：多选喜欢的候选「建家族」→ 创建候选轮，子代自动变异。
5. **迭代**：多选优秀子代「建分支」，父本回交，进入下一代。
6. **收获**：最优串「收编为块」或「固化为模板」，回到 pill 系统参与生成。

## 界面总览

![画风探索三栏布局](../screenshots/style_explore_overview.png)

探索页是三栏布局，分区可拖拽调宽：

- **左栏 · 配方与参数**：就是生成页那套编辑区（提示词、角色框、模型、尺寸、采样器……）。「配方」是一份提示词 + 参数的命名快照，可新建 / 另存为 / 载入 / 复制；未保存时显示「未关联配方」。
- **中栏 · 块库**：与生成页共用的块库面板，点块即插入当前提示词。
- **右栏 · 探索任务 + 候选画廊**：任务（Run）列表和本任务的全部候选图。

**探索任务（Run）**会固化当时的提示词与参数快照，批量生成候选并记录每张图的 Roll 结果。任务状态机：草稿 → 生成中 → 已生成 → 筛选中 → 已完成；支持暂停、重试失败、取消（**取消不可逆**，剩余待生成候选标记为已取消）。

## 第 0 步：让块参与遗传

遗传以**块实例**为单位。想让某个块（比如画师池）的基因进入变异池，需要满足两个条件：

1. 实例已**启用**；
2. 实例模式为**随机抽取**或**顺序**（「固定」模式的块内容不变，没有可遗传的东西）。

满足后，pill 上会多出一个 **DNA 图标**，点它在「开启遗传 / 关闭遗传」之间切换：

![pill 上的遗传开关](../screenshots/style_explore_pill_genetics.png)

> 注意：遗传开关**只在画风探索页可用**，生成页的 pill 不显示这个图标——这是为了防止日常生成时误改遗传标定。

最常用做法：把「收藏艺术家池」「400精选画师池」这类画师池块设为随机抽取、开启遗传，它们就是变异引擎的基因池。

## 第 1 步：基础轮 —— 批量出候选

右栏「探索任务」点 **+** 新建任务，命名并设**出图数**，开始批量生成。

候选画廊支持：

- **网格 / 牌堆**双视图切换；
- **多选**（建家族、批量操作用）；
- 标签过滤：全部 / 心选 / 待审 / 珍宝 / 特殊 / 拒绝 / 失败；
- 每张候选卡下方有 **♡（心选）** 和 **T / S / R** 预标记按钮；
- 每张候选都带 **Roll 快照**：这张图上每个随机块实际抽到了什么串，逐张留档，可回溯、可复制正向 / 负向。

## 第 2 步：正式筛选

点画廊右上「**正式筛选**」进入全屏打标模式：

![全屏正式筛选](../screenshots/style_explore_screening.png)

- 键盘 **T = 珍宝**、**S = 特殊**、**R = 拒绝**，底部也有对应按钮；
- 打错可以「撤销上一张」；
- 顶部显示进度（已归类 x / 总数），**全部归类后才允许「完成筛选」**——保证每张候选都有明确去向；
- 已完成筛选的任务之后还可以再次进入**复筛**；
- 拒绝的图可批量删除：只删 Run 目录里的候选副本，**图库里的源图不受影响**。

## 第 3 步：深度迭代 —— 谱系与遗传

筛完后进入遗传环节，全部在「**谱系**」面板进行：

![谱系面板](../screenshots/style_explore_lineage.png)

### 建家族

在画廊**多选**喜欢的候选，点「**建家族**」：对话框里给家族命名、预览所选候选的父本串，还可以**追加自定义串**（手动输入一段提示词作为父本）。确认后创建家族 + **第 1 代父本集**（状态：活跃）。

### 创建候选轮（深度轮）

在活跃父本集上点「**创建候选轮**」，变异引擎对父本串做**变异 / 交叉 / 随机注入**，产出下一代候选：

- 出图数至少等于父本数（**每个父本保底一张**子代）；
- 前提：主提示词里至少有一个**已启用且开启遗传**的随机 / 顺序块，否则引擎没有变异载体，会提示无法进行深度轮；
- 同一代可以「**新增一轮**」追加更多候选；
- 深度轮在独立数据层跑，**不污染你当前编辑区的草稿**。

### 父本两两排序

点「**排序**」进入两两比较：每次展示两串，选「左边好 / 右边好 / 都不好 / 跳过」。胜方偏好 +1.0，「都不好」双方各 -0.25（下限 0.25），跳过只记录不计分。偏好值显示在谱系的父本条目上，帮你量化哪条串更贴近目标。

### 多选建分支（进入下一代）

从**最新一代候选堆**里多选优秀子代，点「**多选建分支**」：选中子代成为新父本，同时**第 1 代父本全部回交并入**（保留偏好值），组成下一代父本集；旧的活跃集标记为「已回交」。

三个限制（违反会被拒绝并提示原因）：

- 只能从**最新代**候选堆选子代；
- 当前代的候选轮必须**全部完成**（没有 pending 候选）；
- 子代串去重后不得与回交父本**完全重复**。

谱系面板完整保留每代的父本集、候选堆和分支关系，任意子代都能回溯完整祖先链。

## 附：随机抽取设置详解

遗传的多样性由块的随机抽取设置决定。点 pill 的齿轮打开「块实例设置」：

![块实例设置 - 随机抽取](../screenshots/style_explore_random_draw.png)

- **抽取数量**：每次生成从块里抽几条（范围如 1 ~ 1 即固定抽 1 条）；
- **输出顺序**：抽中多条时的排列方式；
- **触发概率**：该实例本次参与抽取的概率（100% = 必参与）；
- **随机权重**：给抽中的词加 `weight::词::` 权重，在「最小 ~ 最大」区间内按「平均」值为中心抽样（Split-Beta 分布）；
- **离散预设**：集中 / 均衡 / 发散，控制权重分布向均值收拢还是向两端摊开；「高级」里可用左 / 右离散分别微调均值两侧的形态；
- **软平衡 + 回拉强度**：把整串抽到的权重整体向「平均权重」回拉，只减弱共同偏高 / 偏低，不改变成员间的相对差距——多张连抽时画风强度更稳定。

搭配**实例级锁定**（锁住的实例不参与重抽）和**重抽**按钮，可以精确控制每一轮探索的变量。

## 收获成果

选到满意的串之后，在候选详情或多选菜单里：

- **收编为块**：把该候选的 Roll 串做成 pill 块（可命名、可合并收编），回到生成页 / 块库直接插入使用；
- **固化为模板**：把串灌入正向提示词，配合顶栏「另存为」存成配方；
- **Roll 快照**：载入快照到编辑器，完整还原那张图的实际提示词状态。

## 常见问题

- **提示「无法进行深度轮」**：主提示词里没有启用中的随机 / 顺序遗传块。去左栏给至少一个块设成随机抽取并点亮 DNA 图标。
- **建分支按钮拒绝操作**：确认选的是最新代候选堆、当前代轮次全部完成，且子代串与回交父本不完全重复。
- **取消任务**：不可恢复；只是暂停的话用「暂停」。
- **删候选图**：只删 Run 目录副本，图库源图与收藏记录都在。
- **生成页看不到 DNA 图标**：遗传开关是探索页专属，这是有意设计。
