## 图库浏览位置

主图库的全部、收藏、最近浏览、删除池、各收藏集与文件夹分别保存位置。记录只包含图片路径、相对位置、滚动值及筛选／排序条件，保留在现有时间线状态中，本次运行有效；不新增图片／页面缓存或持久化设置。

返回分类时按原图片恢复，前面的图片删掉后仍能定位；原图已不在结果中时使用原滚动值并限定在当前范围内。首次进入从顶部开始，搜索／排序变化不套用旧结果的位置，多选清理沿用原行为。

分类入口改为通过现有 `setBrowseScope` 一次提交范围及筛选，替代此前多个独立筛选调用，避免中间结果覆盖位置或重复查询。界面测试覆盖实际侧栏从全部到收藏、经过空最近浏览后返回的位置恢复。

## Agent 块预览图

现有 `block_manage(create/update)` 的 `changes.thumbnail` 接受 `{image_id:...}`、`{path:工作区相对路径}` 或 `null`。读取统一走 `NaiAgentStudioTools.loadImage`，复用已有图片来源和路径边界；图片归一化为 PNG 后存入既有 `prompt_block_thumbnails/`，源文件移动／删除不影响块。

`thumbnailOffsetX/Y` 为 -1..1，`thumbnailScale` 为 1..3，与手动块编辑器相同。更换图片默认居中、1 倍；省略 thumbnail 可只调整显示区域。完整块查询返回当前参数与版本。声明仍使用同一个工具，说明仅补入现有按需参考文档，无新工具或 UI。

写入沿用原快照和版本检查，旧预览字节进入备份；替换／移除只清理不再被块引用的托管图片。写入冲突时删除本次创建的文件，保留用户新草稿。没有额外权限系统、目录导入或图像生成。
