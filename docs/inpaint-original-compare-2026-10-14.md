# 画布 OLD 原图与局部重绘范围对比

有效源码：`.devin/wt/ui-integration`，分支 `codex/uiux-integration`。用户要求在新画布补回官网 OLD，并授权使用 Anlas 做必要的实际验证。本项承接已提交但尚未安装的 Vibe 编码卡片修复。

## 官网实测

通过 Codex 内置浏览器读取 `https://novelai.net/image` 的实际 DOM 和已加载官方脚本，部署标识 `45680b6-38476166330-1`。生成一张 V5 Full 测试原图，再对该图执行一次局部重绘，两次各 11 Anlas，共 22 Anlas。每次请求前均报告当时官网报价和余额；不涉及充值。

官方 `display.old-compare` 在有 `originalImage` 时出现，生成完成前禁用。`pointerdown` 开启原图显示，窗口 `pointerup` 关闭；不是点击后永久停留的开关。按住时在原图上显示该结果保存的 `mask`，透明度 0.3，采用像素式蒙版显示。实际按下后 DOM 出现 `pre-edit original` 和 `inpaint mask`，松开后这两层消失。脚本及按下 / 松开结果相互核验。

官网测试前保留可见草稿记录；测试中仅更改表情词并使用本次测试图及蒙版，核验后比对当前提示词再恢复，移除测试底图恢复原空底图状态。页面留下两个测试结果供查看；原数值生成参数、负面提示词和角色框未改写。测试时绘制蒙版的范围较预期更大，仍仅用一次重绘完成交互验证，没有追加生成。

私有页面状态、原始证据及截图仅在忽略目录 `.dart_tool/inpaint-old-compare-20261014/`，不提交账号资料或生成图片。

## Studio 实现

- 右下角工具条最左侧增加 OLD，使用现有官方图标、轻微平滑渲染和玻璃表面；有原图的完成结果才出现，失败快照及变体组的原始占位不显示。
- 按住主键查看当前图片原图，松开或取消恢复结果；指针移出后释放也恢复。空格 / Enter 支持同样的按住交互，键盘失焦与应用进入后台会恢复；右键不启动对比。
- 每次请求首次异步等待前复制源图和蒙版缓冲区。完成图记录请求原图及局部重绘蒙版，保存路径回填与批次归属副本继续保留，两次连续重绘各自使用本次请求输入。
- 对比只增加显示层，当前结果的身份、原始输出字节、相机、历史选择及保存 / 复制 / 详情等动作不变。原图采用 contain，蒙版使用同样的对齐；黑色和透明未选区域保持透明，选中区域为白色约 30%，无效蒙版省略。
- 原图预解码；所选图的蒙版在后台 isolate 转换并缓存，不在每次按住时重算。未获取蒙版时仍可查看原图。
- 画布不足 500px 时两条底部工具条分行，图片底部留白同步增加；360px 下仍保留完整十位种子和各按钮。普通图片及宽画布沿用现有位置。
- 五语言文案同步，繁体资源由既有生成链产出。没有原图数据的旧导入或重载结果不推断来源，不显示不可用的 OLD。
