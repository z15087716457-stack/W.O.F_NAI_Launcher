# 轻量翻译语义分段

源码已完成，尚未构建或安装；本机仍为2.4.0+109，公开Windows／Mac仍为2.4.0+108。本批不调用真实模型或NAI，不修改用户草稿、设置及索引。

## 当前行为

- 沿用现有翻译服务、模型路由、术语表、请求分组及快照核对。一次请求同时完成语义分段和翻译，不增加预分段模型调用、工具或设置。
- 逗号标签仍要求逐项翻译；散文、分号及字段允许模型按语义拆分或合并相邻短片段，不能跨字段、原生块、硬换行及XML分区。
- 输入保留原始结构与权重；本地干净标签仍供术语表查询。只读解析器可检查XML内容，格式化／生成等其他调用仍默认将XML视为不可改写文本。普通词库别名及引号文字保持原义。
- 轻量结果使用原文片段作定位依据，不接受模型给出的字符下标。片段必须在对应分组内按顺序精确匹配，不能漏掉实质内容、重排或跨结构；只有权重、结构标签及分隔符可留在片段之间。
- 展示直接使用已保存的语义范围，不再按逗号重新拆译文。长片段自动换行时译文放在最后一行下，只为末行预留译文空间。继续使用同一原生编辑框、光标、选区和输入法。
- 修改部分原文后保留小扳手与待更新；整段删除后移除对应译文。旧整篇XML错位记录会显示待更新，下次点现有翻译入口即可重译，不自动发起模型请求。原有逐项结果继续复用。

## 协议

保持现有`fields / groups / ids`与有序完整覆盖规则。块模式仍返回`zh`及可选`parts`；轻量组返回`readings`，其中每项是原文片段及对应译文。例如`<scene>soft lighting; warm colors</scene>`可以返回：

```json
{"fields":[{"id":"main","groups":[{"ids":["main:0"],"readings":[{"source":"soft lighting","zh":"柔和光线"},{"source":"warm colors","zh":"暖色调"}]}]}]}
```

校验后的结果继续写入既有`PromptReading`结构；不新增持久化版本或改写原文。内置提示词统一维护两种模式的必要格式规则；用户已保存的自定义提示词不改写。
