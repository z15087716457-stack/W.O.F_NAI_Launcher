# F13 · 主提示框最低高度与内部 TIP 恢复

2026-10-15。用户在只读调查后授权开工。已在现行共用编辑槽恢复最低高度与内部 TIP，继续随 F07–F12 积攒；未构建 Release 或安装，桌面仍为 r7。

## 原因与实现

原实现 `9b04197af` 将提示卡高度控制在宽度约 0.72 倍，并显示轮换小贴士。新编辑槽在 `3e9c1c358` 迁移时将非全屏最低行数设为 1，遗漏 TIP；后续 `ec50104d4` 只补探索主框。原布局、小贴士牌组及五语言资源仍在；只读证据见 `.dart_tool/prompt-height-tip-audit-20261015/`。

- 在现行 `GenerationEditorWiring` 按编辑槽宽度、当前字号及文字缩放计算最低 4–16 行。根据当前卡片的头尾及左右留白重新折算，使卡片仍接近原来的宽高比例；更长正文继续自动增高，留空后恢复最低高度。
- 主生图正向框接回 `TipSurface.prompt`，探索正向框继续使用 `TipSurface.explorePrompt`；复用现有牌组、五分钟轮换及五语言文案。TIP 作为 hint 显示，输入正文后隐藏，不进入药丸文档或生成参数。
- 主框正负面采用同一最低高度计算；角色编辑槽仍为最低一行，全屏编辑仍为最低八行。宽度变化不重建文档或移动光标。设置及 TIP 依赖在 Consumer 构建期读取，布局回调只计算行数。
- 两套整页接线测试对轮换时钟使用固定 Stream；应用中的原有轮换时钟保持原样。
