# macOS 空闲负载与后台工作量对照

2026-10-31 在同一台 Mac 上对照测量了基于 2.2.2 的 macOS 版本与加入空闲绘制和后台任务优化后的构建。以下数据仅反映这次对照，2.2.5 尚未按同一方法复测。测试窗口一直显示在屏幕上。CPU 100% 表示占满一个核心。记录指标包括 CPU、帧率、内存和处理耗时。电池续航与整机功耗未测量。

## 亮屏实测

| 场景 | 改前 | 改后 |
|---|---|---|
| 生图页静置，各自默认设置，空画布 / 6 张图 | 45% / 77% CPU，120 帧/秒 | 都约 0%，不再连续绘制 |
| 两边都开原本空闲微动，空画布 / 6 张图 | 45% / 77%，120 帧/秒 | 15% / 23%，30 帧/秒 |
| 新增防烧屏档，空画布 / 6 张图 | — | 0.70% / 0.94%，1 帧/秒 |
| 登录页静置 | 17%，120 帧/秒 | 8%，30 帧/秒 |
| 提示词框打字，两边都开微动 | 85%，120 帧/秒 | 39%，53 帧/秒 |
| 切页，两边都开微动 | 28% CPU | 21% CPU |
| 拖动和缩放画布 | 101%，120 帧/秒 | 90%，103 帧/秒 |
| 第二次及以后启动，出画面 / 能操作 | 5.0 / 6.2 秒 | 0.5 / 1.7 秒 |

默认设置的最大差异来自空闲微动改为关闭，已有用户升级后也会关闭。图库、积木库、设置页原本静置就约 0%，不把它们写成新节省。新装或刚升级的首次启动，两边都约 4.5 秒。

拖动测试每秒仅送入约 98–99 次事件：改前平均多画约 17.5 张重复画面，改后按变化绘制；有效跟手画面约 98 / 99 张每秒，两边都没有连续两次以上刷新缺画面。最慢 5% 的画面仍有 0.1–0.9ms 差异，原因未确定。没有测试真实触控板每秒至少 120 次输入、默认关闭微动时拖动，或松手后的惯性。

## 图库索引的隔离基准

以下使用假模型和 2 万张带长参数的图片，量的是索引管理开销，不代表真实模型推理速度。

| 场景 | 改前 | 改后 |
|---|---|---|
| 存一张图 | 约 12 CPU 秒，写盘 1.2 GB，ANN 存两次合计 706 MB | 约 0.85 CPU 秒，写盘 0.2 MB，安静后存一次 353 MB |
| 每 8 秒存一张，连续 20 张 | 37 CPU 秒，写盘 3.6 GB | 6.7 CPU 秒，写盘 2 MB |
| 新图可检索的等待中位数 | 98 秒 | 14 秒，最长 29 秒 |
| 崩溃后恢复 11 万向量 | 整份重建约 500 CPU 秒 | 重放约 0.6 CPU 秒 |

标签索引只根据相关标签行判定变化：以前存图会带来约 84 CPU 秒、2.6 GB 写盘的全量标签检查；现在该判定约 30ms。手动同步标签仍可能触发整份检查。图库更新仍需读取图片行计算签名，2 万行约 0.78 CPU 秒，约占存一张图开销的九成。

## 内存与范围

- 按各自默认设置，生图页静置时活动监视器内存少约 160–200 MB；隐藏满一分钟后示例从 937 MB 降到 663 MB。
- 生图页停止绘帧时显存比改前多约 17 MB，不计入 RSS；原因未查清，本次保留并公开说明。
- Windows 没有整窗遮挡检测，只有 Mac 能判断窗口被完全遮住或切到其他桌面；Windows 真机和 Intel Mac 尚未测量。
- 请求场景使用隔离数据和本地模拟服务。

这些结果支持减少闲置绘制、重复扫描和后台轮询；它们不保证不同硬件、图库或版本获得相同百分比。
