## 与材料的出入和审查重点

- active 的块色 16% 底适用于经典和图案样式；实心 / 翻译样式仍保留自己的底色，并使用同样的 2px / 30% active 外圈。实心底从 100% 降到 16% 会破坏原来的白字对比，翻译底按主题中性色规格保留。此项是对状态与样式重叠的解释，交检查点①审查确认。
- 积木翻译全文沿用多行 TextSpan、标签标注和语法强调，允许高度随正文增长；普通药丸没有此例外。
- scope 切换时关闭旧实例卡并清空 active marker，避免角色编辑 State 复用后保留旧标记；未修改实例卡内容、动作或业务模型。
- 模块卡片的整页套用、侧栏布局 / 键盘导航、管理页布局及实例卡重做属于后续任务，没有在本任务施工。
- 本任务没有模型选择或生成参数变化；V5 / V4.5 / V3 的整页样式差异仍需在生图页后续段验证。本段提供共用药丸及原有编辑器回归证据。
