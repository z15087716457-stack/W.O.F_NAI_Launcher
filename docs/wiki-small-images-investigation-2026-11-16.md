# 小百科图片窗调查 · 2026-11-16

本文记录调查和交互预览当时的结论。后续已获授权完成[原生实现与验证](wiki-image-panel-2026-11-16.md)，尚未构建、安装或发布；此前标签搜索重构和释义 UI 的未提交改动保持。

后续已完成[全库兼容性复核](wiki-image-compatibility-2026-11-16.md)：原生实施以该报告补充的动态章节、译文编号关联、正文搬运和分批读取边界为准，不能把 `solo` 固定两组预览直接作为全库通用方案。

## 结论

可以在 Ctrl 标签扩展右下方增加图片窗，复用现有图片请求、缓存和灯箱。主要工作是补齐图片引用解析、接入浮层布局，并在正文显示层搬走相应图片内容；不需要重写百科或引入模型识图／额外翻译请求。

## 已核实的事实

- `tag_expansion_wrapper.dart` 的小百科只创建 `WikiLinkedBody(compact: true)`，没有传完整百科使用的 `exampleCards`／`exampleTag`。因此 `!post #...` 留作文字，当前布局也只有搜索、关联、小百科三个面板，右下方尚无图片区域。
- 完整百科已经使用 `WikiExampleRepository`、`WikiExampleGallery` 与 `showWikiExampleViewer`。现有链路包括元数据批量请求、按可见性加载缩略图、图片缓存、失败重试，以及单击开启可缩放灯箱、左右切换和来源链接。
- 2026-11-16 只读核对本机当前生效的 Wiki 修订及官方 `solo` 原文，两者明确引用的图片 ID 相同：示例 `7251942 / 135361 / 8691735`；非示例 `5870555 / 9832301 / 7465226`。匿名元数据查询中六项均返回 360／720 图片变体地址，未下载图片字节。此结论是地址可取，不替代每张图的实际渲染验收。
- 现有 `WikiExampleReference.parse` 只识别 DText“Examples／示例”章节里的 `!post #ID`。用当前 `solo` 正文调用生产解析器，只得到前三张；“Non-examples／非示例”三张被漏掉。
- 当前生效 Wiki 还存在 `!asset #ID`，例如 `.52_gal_(splatoon)` 的 `22435242`。现有解析器和帖子接口未覆盖这种类型。已只读验证该公开素材的 JSON 接口返回可用的 360／720 变体；[官方控制器](https://github.com/danbooru/danbooru/blob/master/app/controllers/media_assets_controller.rb)提供媒体素材查询。[官方媒体模型](https://github.com/danbooru/danbooru/blob/master/app/models/media_asset.rb)定义图片变体。
- 随包旧 `assets/databases/tag_wiki.db` 是另一份扁平正文，`solo` 已丢失这六个嵌入标记，不能据此判断当前安装内容。核实用的是 `dictionary_updates` 当前提交指向的只读数据库；本轮没有重新同步词库。

## 建议的呈现和数据边界

1. 有明确图片引用时，在小百科右侧、关联列表下方增加同风格图片窗；没有引用不出现。宽度沿用现有约 240 的右栏，与小百科顶边对齐、限高并独立滚动。窄窗在小百科内部下方承接，不伸出窗口。
2. 每项保留缩略图、配图说明和来源编号。帖子通常没有可用的自然语言文件名，名称采用现成说明，例如“单人 + 1个男孩”，编号标成 `Post #7251942`；素材项使用 Asset 编号。说明沿用当前译文／标签译名，缺失时保留原说明，不另请模型命名。
3. 明确保留“示例／非示例”分组；正文其他位置的插图保留附近标题作为语境。不可把所有图片合并成没有语境的正例图集。
4. 单击复用现有灯箱；缩略图先加载，放大图在打开时读取。图片请求失败、被删除或不可访问时，保留说明和来源链接，可重试。
5. 从当前打开的原文提取引用，按相同 ID 在正在显示的原文／译文里移走图片引用及配图说明；只移除确定归属于图片的内容。保留定义、判断条件、警告、普通帖子文字链接和“见另”。无法准确对应的译文段落保留；完全搬空的示例标题一并隐藏。
6. 所有移除仅是显示投影，原始 Wiki、译文缓存和复制原文保持。图片列表也以当前正文为准，避免现有 `forTag` 重新读取线上新版后，图片与本地旧版正文错配。复用现有资料仓库和请求缓存，不另外建立数据库。

## 需要改动的现有位置

| 位置 | 最小必要调整 |
|---|---|
| `core/wiki/wiki_example_repository.dart` | 引用带类型与所属章节，覆盖正文、示例及非示例；接收当前正文提取出的引用，复用变体映射与缓存 |
| `data/datasources/remote/danbooru_api_service.dart` | 沿用帖子批量接口，补媒体素材元数据读取 |
| `widgets/common/wiki_example_gallery.dart` | 复用图片、说明、占位和灯箱入口，支持供小窗使用的已提取图片集合 |
| `widgets/tag_expansion/tag_expansion_wrapper.dart` | 按引用预留右下图片区域、正文显示投影、窄窗布局和现有切词条／关闭清理 |

不要直接给小百科打开完整百科的行内图片开关，否则图片仍插在左侧正文，且继续漏掉反例及媒体素材；这不满足用户指定的右下图片窗。
