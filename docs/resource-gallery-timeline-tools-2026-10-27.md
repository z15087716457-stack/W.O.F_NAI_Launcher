# 资源小窗时间线与提示词工具栏 · 2026-10-27

资源小窗图库改用本地画廊的 `GalleryTimelineScrubber`、日期分组／吸顶标题、`computeGalleryTimelineLayout` 和可见范围缓冲策略。时间线一次取得完整轻量索引，只为附近卡片分批读取记录，单批最多 60 项；滚动和大图切换不再继续请求分页，也不因追加条目反复排版。查看器使用完整当前筛选序列。

索引查询显式接受小窗排序，在独立过滤器及结果列表上完成，不更改主画廊的筛选和排序。分组按钮复用本地 UI 与保存设置；主窗口分组改变通过既有小窗消息同步。缩略图仍由主程序同一 `ThumbnailCacheService` 提供，已索引的合法路径免去逐张扫描全库；图库变化时失效这份路径索引。

主提示词头部在工具溢出时优先保留页签的自然宽度；未超出五项时沿用原布局。包含菜单在内超过五项时，工具区显示四个半按钮的宽度，内部横向滚动；边缘剩余内容用渐隐显示，滚轮只滚动工具区。窄栏按剩余空间约束，避免工具继续挤压基础提示词页签。翻译按钮沿用原有宽度。

回归包含 12,000 张合成图库的日期跳转、有限卡片构建、每批记录上限及滚动期间不查询分页；工具栏覆盖五种语言、明暗主题及 340／400／480px，检查真实字体页签、四个半按钮、渐隐像素和鼠标滚轮。沿用既有界面基线和掩码，不更新基线来掩盖差异。组件测试使用合成数据；用户运行实例由用户自行验收，不自动启动、热重载或操作。
