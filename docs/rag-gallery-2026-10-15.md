# RAG 第三批：本地图库多模态检索

2026-10-15。已完成开发与本地验证，按用户要求继续积攒；没有安装、启动／热重载 Studio、推送或发布。正式运行及收据仍为 r5。工作区向量索引和 Agent 检索工具／动态卡片暂放。

## 行为与入口

- 「设置 → RAG 向量系统」增加图库独立开关。默认关闭，每次首次建库先预览登记根目录、未删除图片数及 NAI 参数片段数，用户点击开始后才计算向量。支持增量、部分可用、暂停／继续、单独重建／清除；关闭保留索引。
- 本地图库搜索框尾部显示真实 RAG 状态。点击 RAG 菜单选择「综合检索／仅画面／仅 NAI 参数」，也可选择本地参考图片找相似，或在参考图上追加文字。图片图标可清除参考图；清除会话筛选也清除参考图，保留原有浏览范围。
- 文字查询的原有文件名／提示词命中先显示，语义结果按相关性补充。纯参考图查询只显示相似结果；参考图自身不返回。当前目录及子目录、收藏／收藏集、日期、NAI-only、模型及标签等筛选继续生效。语义补充时取消日期分组，避免把相关性顺序伪装成时间顺序。
- 普通结果先返回，模型查询不阻塞界面；输入变化、切换模式、清除参考图、关闭来源或退出时取消／丢弃旧结果。删除池内图片与已移除来源不参与召回，迟到结果不能复活用户已删除的图片。

## 模型与数据

Gemma 在首次图片任务时按需加载文字＋视觉编码器，音频关闭。复用一个进程与模型所有者，不再常驻第二份文字编码器；空闲／本地超分让出时一起卸载。权重原样保留，本次没有下载或裁剪权重。选择性加载与多模态输入按照 [Google 模型说明](https://huggingface.co/google/embeddinggemma-2) 实现，当前专用运行依赖与 [首版报告](rag-tag-context-2026-10-15.md) 相同。

两条索引分别保存于应用数据目录 `rag/v1/indices/gallery-v1/images-v1-<processor指纹>/<模型指纹>/` 和 `gallery-v1/nai-text-v1/<模型指纹>/`。SQLite 向量为恢复依据，ANN 为可重建派生数据；与标签、Wiki、块库索引隔离。登记来源的稳定派生文件为 `rag/v1/sources/gallery-roots.json`，不导出用户完整图库数据库。

- **画面**：只读原图，按显示方向在内存转 RGB、限制到 2048 边长，再由模型预处理。保留原图字节、颜色格式和元数据，不写缩略图或改原图。现有图库图片参加检索；动图参考按第一帧处理，不涉及音频／视频索引。缺失、损坏、过大或解码失败的图单独跳过，设置页显示跳过数。
- **NAI 参数**：只读现有图库数据库中通过现行 NAI 指纹判定的缓存参数。收录正负面提示词及型号、采样器、步数、CFG、seed、尺寸等；不重新解析图片参数，不索引其他软件的生成元数据，不把 raw JSON／Vibe 编码塞进向量文档。
- **排序**：画面只经 Gemma；NAI 参数采用 Gemma 召回＋Qwen 文字重排，绝不把图片交给 Qwen。综合检索用排名融合，不直接比较图片相似度与重排分数。文字查询独立限为 256 Gemma tokens，提示词推荐的双 120-token 窗口不变。
- **恢复与新鲜度**：视觉向量检查文件身份、大小、mtime 与实时来源；NAI 文字片段按实时摘要核验。暂停后来源变化会重新规划增量。图库范围经独立的只读服务查询取得，不改变正在显示的筛选、排序或 Agent 的资料查询状态。

查询图路径仅存于会话 provider，不写生成草稿、图库或设置。请求使用短期的范围路径清单，正常完成／取消后删除；查询文本与参考图字节不存入索引。交互查询优先于下一批建库，视觉每批最多 8 图、模型微批为 2；原有超分资源让出和 Windows Job 子进程回收继续生效。
