# 本地放大模型固定大小

2026-10-17。源码完成，待下次本机更新；桌面仍为 r24／`2.0.0-preview+28`。

用户反馈常规模型和未安装的 SeedVR2 显示 `0 B`。常规模型管理器此前没有填充大小；SeedVR2 只在有效安装收据存在时提供权重大小，设置接线又将下载总量、安装磁盘字节混作卡片大小。

现由管理器独立提供 `LocalUpscaleModel.modelBytes`：常规模型合计固定清单中对应的 `.param`／`.bin`（快速型号包含 2／3／4 倍三组文件），SeedVR2 只计所选权重，不重复计算共享 VAE、源码和 Python/CUDA 环境；自定义模型读取导入文件大小。安装、失败或删除不改变目录内置型号的固定大小，不修改清单、安装校验或既有 `diskBytes` 口径。

设置契约的 `bytes` 保持模型大小，新增 `total` 专用于传输进度。下载 ZIP 总量与解包后模型大小不再混用；未知大小显示破折号，避免将缺失数据写成 `0 B`。RTX 清单文件大小也进入数据模型，现有 RTX 独立组件行保持原样。

界面按现有格式显示：常规三种约 9／4／32 MB；SeedVR2 3B FP8／INT8 约 3.2 GB，7B FP8 约 7.7 GB、INT8 约 7.8 GB。大小由固定清单推导，不依赖联网查询；数字单位沿用既有格式。

验证证据位于 `.dart_tool/upscale-model-sizes-20261017/`：

- 68 项检查通过，4 项真实 GPU／原生可选审计按既有条件跳过；包括两张原有本地放大明暗视觉基准，未修改基准或比较范围。
- 隔离目录验证三种常规模型与六种 SeedVR2 在安装、删除前后大小一致；SeedVR2 安装使用微型合成权重与替身进程，自定义导入验证实际文件合计。真实固定清单可离线提供全部大小，不下载权重或运行安装进程。
- 接线验证安装／未安装、失败及未知／不同传输总量均不改模型大小。组件验证 ZIP 传输百分比使用独立总量；五种语言、900／1600px 窗口、浅深主题实绘检查九张模型卡片，安装前后无 `0 B` 或布局异常。已查看中文浅色安装前及深色安装后实绘。
- 11 个改动 Dart 文件范围分析无诊断。269 张原视觉 PNG、两个固定清单、未归属 `DEVELOPMENT.md`、桌面 AOT 和安装收据共 274 个文件哈希保持。

未构建新 Release、安装或自动启动／热重载应用；未写用户草稿、参数、索引或下载大型权重，未执行真实放大／生成。待更新时与 V5 胶囊范围、宽度修正一并累计。
