# 轻量翻译：原文就地编辑

2026-11-15，修正2.4.0候选中“点击原文后译文消失”的交互。原文始终由同一个原生编辑框显示并编辑；注释保持只读，按逗号逐项对齐。部分修改显示现有12px线性扳手与「待更新」，整段删除由既有readings重定位逻辑移除对应注释。

## 实现

- 移除离焦阅读层／聚焦编辑层的切换及另一套拖入坐标换算。原生输入、光标、选区、输入法、撤销和拖入共用一个RenderEditable。
- 保留原文所有字符、换行和UTF-16位置；语法高亮span只增加有注释段的排版空间，普通空白行保持原行高。原生strut约束光标与选区，首行不额外增加上部留白。注释根据实际原文行框定位，并跟随同一滚动偏移。
- 复用UiText、UiGlyph和现有待更新文案，不新增翻译入口、可编辑译文或操作按钮。模型、术语表、分组协议及块翻译链保持。
- 更新五种语言的轻量翻译说明：编辑时译文持续显示；复制和生成只使用原文。

## 验证与边界

- 提示词组件、翻译服务／provider、存储、分段与重定位回归396项通过。
- 最终光标／选区／语法及生成接线179项通过，包含29项轻量注释布局与交互检查：五语言、深浅主题、320/736px、150%缩放，Windows/macOS/Linux光标、复制及输入法、完整删除、局部待更新、Unicode原文、带权重选区。
- 使用真实字体检查合成数据部件实绘；上方原文可编辑，底部状态完整显示，权重背景和选区仍为原文行高。此证据不代表运行中用户窗口或Mac实机验收。
- 未请求真实模型或NAI生成，未操作用户草稿、启动或重启Studio。构建与公开分发状态另见[2.4.0发布核验](release-2.4.0-2026-11-15.md)。
