# 图生图精简与原图放入画布 · 2026-10-05

用户要求删除图生图标题栏的「更多」菜单，并将底图直接放入生图区域，从现有画布入口进行本地编辑，无需先调用 NAI 生成变体。空态的精准参考库导入与绘制草图保留。

## 实现

- 删除图生图标题栏的溢出按钮、菜单与仅由它使用的私有处理函数。增强、超分、导演工具等继续使用中央画布工具条的现有入口。
- 标题栏新增箭头按钮「放入画布」，五种语言同步；小于 360px 的侧栏隐藏重复缩略图与已启用徽标，保留操作按钮与标题。
- `ImageGenerationNotifier.registerSourceImage` 将源图登记到中央画布、当前预览和内存历史，复制并保留完整原字节、编码尺寸及已有元数据。不会重建提示词/种子，不虚构生成操作，也不自动保存到本地图库。
- 同一图片按完整字节匹配，复用既有图片；包括清空历史后仍留在经典预览中的图片。导入保留其他结果。每次点击发起新的显式对焦请求，已选中的原图也能再次飞回。
- 点击时读取最新底图，生成中禁用并由 provider 再次保护；空图、无法解码的数据拒绝导入，生成状态保持原样。点击不写入草稿、蒙版、角色或桥接参数。

## 验证

- 81 项相关测试通过：图像生成 provider、图生图面板、画布布局/交互、图像工作流与繁体资源。
- 零 API 调用与零余额刷新；带 NAI 元数据的 PNG 逐字节保留，提示词和种子不被当前草稿覆盖；验证去重、历史与预览保留、无效数据及运行中保护。
- 实际 `GenerationCanvasView` 联动验证：按钮插入原图、重复对焦、直接从工具条打开本地 `ImageEditorScreen`，8×8 样本保持 8×8 编辑画布。
- 五语言 × 深浅主题 × 320/400px × 折叠/展开，共 40 张真实字体截图；无布局溢出，逐语言标题栏总览已检查。
- 受影响源码与测试静态检查无问题。记录位于 `.dart_tool/img2img-canvas-20261005/`。
