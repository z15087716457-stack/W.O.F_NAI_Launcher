# 图片使用记录、种子切换与简洁查看器焦点

状态：2026-11-04 已随本机 **2.2.5+82** 安装；公开仍为 2.2.5+80，本批未推 Git，未自动启动。[交付与回退](local-2.2.5-build82-2026-11-04.md)。

## 最终行为

- **图片使用记录**：“使用图片”在角色处理右侧显示 Vibe、PR、局部重绘小标记；没有明确记录就不显示。参考素材可还原时，悬停提示可由参考图选项导入；只有使用记录时，说明未附带可导入素材。参考图卡片的启用与默认选择继续按实际素材决定。宽窗口仍为原行，窄窗口自然换行。
- **种子固定**：参数条与参数抽屉的锁按钮始终可切换。固定当前显示的图片种子；没有可用种子时，沿用已有逻辑产生一个值并固定。解除后可以再次固定。保留 `-1=随机、有值=固定` 的单一状态，不新增历史种子缓存。
- **简洁查看器跟随**：共享图片选择与批次焦点在新一轮生成开始时一起重置，分组两态均切到本轮占位／预览。取消查看器完成时强制清空选择的监听；期间主动选历史图时，后续帧与完成继续尊重手动选择。无限画布继续由现有引擎对焦，不增加第二套跟随系统。

## 数据与范围

`NaiImageMetadata` 在原解析边界记录三个布尔值，Hive 使用新增的 40–42 字段并为旧记录提供 false 默认值；JSON 同步生成。已有缓存通过 `upgradeFromRawJsonIfNeeded` 从原始 Comment 补齐，不扫描或迁移用户图库。

Vibe／PR 依据已有参考数据、有效的非空强度记录或原有明确 PR 开关；局部重绘只识别明确请求记录。`NativeInfillingRequest` 在本工作区保存的官网源码 `04_工具/开发计划/素材/nai5_chunks/5285-84437ecf40a2e4bf.js` 中核对，普通 `Img2ImgRequest` 的强度／噪声不推断为重绘。没有原图时，不能据用户的界面截图断言该图实际使用了哪种参考。

界面复用现有 Dialog、Wrap 和 Tooltip，仅增加三个小标记及悬停文案；五种语言同步。未新增工具、服务或设置，不修改实际图片字节、导入参数或 API 请求。
