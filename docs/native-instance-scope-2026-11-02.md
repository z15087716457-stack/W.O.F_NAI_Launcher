## 行为与实现

- 普通运行用 EXE 所在目录确定实例身份；不同安装目录可以分别启动，同一目录重复打开仍唤醒原窗口，改文件名或换工作目录不会绕过同目录单实例。
- 显式 `NAI_STUDIO_SANDBOX` 继续使用隔离数据根作为身份。共用同一个根的不同程序目录只使用一个实例；不同隔离根互不阻挡，沿用现有大小写／分隔符／尾斜线归一化及非法配置拒绝规则。
- 在现有 `studio_sandbox::Identity` 中补上普通运行目录，复用原有哈希与隔离根逻辑；互斥锁、唤醒消息和主窗口标记使用相同身份。
- 主窗口统一写入原有属性标记；窗口查找保留类名、标题及身份标记检查，删除重复的跨进程路径查询。`flutter_window.cpp` 的消息接收端直接复用现有 Identity 调用，未增加管理器、服务、开关或界面。
- 新身份不受旧版无目录后缀的全局锁阻挡；不会自动结束其他目录的进程。同目录程序更新仍沿用既有退出／覆盖流程。

生产仅改 `windows/runner/main.cpp` 与 `windows/runner/studio_sandbox.h`，合计增加 21 行、删除 73 行，净减少 **52 行**。
