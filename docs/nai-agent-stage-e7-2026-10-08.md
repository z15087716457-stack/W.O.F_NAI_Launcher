# NAI Agent E7 · 必需交互扩展与外部扩展

2026-10-08。锁定官方 Pi 1.0.4；只新增一个内置 `nai-interaction`，注册 `studio_context` 与 `ask_user`。提问为 `model-only`／顺序执行，禁止嵌套批量调用；其余业务工具继续沿用原生桥，下一阶段再迁入 NAI Studio MCP 组。当前实际工具数仍为 25，尚未启用 MCP／CodeMode。

## 实现

- NAI Agent 设置增加可展开的内置扩展说明和外部条目。添加本地扩展文件或包目录，可开关、移除并持久保存；移除不删除源文件。变更在当前任务结束后的下一次发送生效，各聊天在所属工作区独立加载。
- 使用公开 `DefaultResourceLoader`、`extensionFactories`、`bindExtensions` 和 `session_shutdown`。只加载用户明确选定的路径，不自动扫描目录；破损扩展与 Studio 工具名冲突显式报错。
- 标准 `select`／`confirm`／`input`／`editor` 转原生问题卡，通知／状态／字符串 widget 转面板；选择限制真实选项，确认布尔值，编辑保留空白。启动问题不阻塞初始化，停止取消等待及后续请求；外部斜杠命令由 Pi 执行。
- 外部扩展运行本地代码。支持标准 Pi 文件／包目录和上述 API；终端自定义组件及其他桌面产品专有插件协议不在支持范围。标签主题格式为纯文本，Flutter 管理样式。
- 修复资源加载器缓存造成自定义提示词更新未生效；动态 getter 继续使用 Pi 的公开资源接口，不增加 Agent loop。
- 实际配置切换闭环修复 Windows 短路径／完整用户名路径的会话恢复误判，先归一实际路径再保存引用，保留 sessions 越界检查和原有 Pi 历史。
- 所有新增文案同步中英日韩，繁体和 l10n 按仓库流程生成。没有新增依赖。
