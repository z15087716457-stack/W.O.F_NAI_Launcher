# 轻量翻译的行距、选区与译文位置修正

2026-11-15，针对桌面2.3.4+104的实测反馈修正。已与居中拖入提示一起安装到本机**2.3.4+105**，既有累计修改保持；程序未自动启动，实际效果由用户实测。[交付核验](local-2.3.4-build105-2026-11-15.md)

## 原因与实现

- 原实现把整段译文排在最后一行，并用其完整高度给所有原文行设置strut。模型保留原样的长画师名段落也被当作译文重复排版，导致每行约145px。现按实际原文行依次排布换行后的译文，复用原有同行避让；与原文完全相同的结果不重复展示，待更新提示仍保留。
- 原生选区默认包含扩大的行高，光标矩形也不等于字形底边。轻量译文显示时改用tight原文字形框，译文定位在真实字形底边下方2px，选区不覆盖译文预留空间。只在测量时忽略段首尾空白；原文、换行和翻译范围不被改写。
- UnifiedPromptInput统一使用实际输入框的字体样式计算行高与光标高度；ThemedInput只增加可选selectionHeightStyle透传，其他输入框保持默认值。仍使用同一个原生编辑器，没有改模型、提示词、术语表、协议或存储链路。

- 另1项临时实绘采集通过，全仓flutter analyze为0问题。复现使用本地假数据，不请求真实模型或NAI，不读取或修改用户当前草稿。
