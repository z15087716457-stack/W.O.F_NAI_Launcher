# NAI Agent E8 · 独立指令设置

2026-10-08。NAI Agent 设置增加「指令」区域：独立的全局指令 `globalInstructions` 与系统提示词前置内容 `systemPromptPrefix`，各有编辑器和保存按钮。既有全局／工作区基础提示词编辑折叠保留，生效文本预览保持可见。

## 行为

- 所有工作区组合顺序：前置内容 → 当前基础提示词 → 全局指令 → 工作区规则／手册说明。工作区自定义基础提示词保持；宿主工具地图和 Pi 动态部分仍沿现有接口组装。默认两项为空，留空停用该部分。
- 两个字段独立持久化在 Agent 专属设置，复用串行合并与原子保存；编辑旧值归档到 prompt-history。没有额外 AGENTS 文件镜像，也不写用户 Pi CLI 配置。
- 保存使用公开 setSystemPrompt 更新当前宿主；恢复会话取最新设置。现有消息保持，设置保存不发模型请求。离开设置同时处理新字段和基础提示词的未保存编辑，保存过程中继续输入的草稿保留。
- 设置搜索可找到两项；中英日韩同步文案，繁体与 l10n 按正常流程生成。参考 PiDesktop 的独立全局指令编辑与保存；本次 prefix 在基础提示词前，并非它的 APPEND_SYSTEM.md 语义。
