# 画布原生帧时间与针对性优化 · 2026-10-16

**源码已完成，待用户要求后更新本机。桌面仍为 r17 / 2.0.0-preview+21。** 本次不覆盖、启动或操作用户实例，不请求生成／模型接口。用户要求保留中央原图清晰度与三个工具条效果。

## 采样与结论

基线为 `370ce2153`。独立 Windows Profile 窗口使用生产页面、相机、图块、两侧背景及三个工具条；合成 1664×2432 PNG，200 张历史。视图 1584×961、DPR 1、144Hz，每帧预算约 6.94ms。引擎日志为 Impeller OpenGLESSDF；系统主显示适配器报告 RTX 4080、3440×1440@144Hz。

拖动／滚轮走生产指针入口，缩放调用生产平滑缩放操作；按时间定义相同路径，每段 6 秒。比较完整效果、仅停用两侧背景、通道关闭，三组都保留原图与工具条。完整效果前后各重复三轮，另测只有一张历史的场景。

原生 `FrameTiming` 的 build 包含界面构建／布局／绘制指令准备，raster 为引擎栅格阶段；它们不是实际呈现 FPS，也不能把 raster 全部归为 GPU shader 执行。滚轮事件为 24 次／秒，空闲间隔不直接当丢帧。独立宿主只注册窗口插件，不代表完整 Studio 的后台业务负载。

原始时间戳及 P50／P95／P99 在 `.dart_tool/canvas-frames-20261016/`。用户指出前次采样时外部向量任务仍在运行，因此此前 `paired-*` 数值仅作为历史记录保留，不再作为正式结论。用户确认向量建库／推理已暂停或结束后，使用相同新旧 AOT、相同窗口与场景重新交替三轮；以下采用 `idle-retest-*` 的全部六次运行，每侧三轮 P95 取中位数，不剔除较慢运行。旧版四个文件只在独立源码副本中还原，未回写有效源码。启用 CPU profiler 的诊断及早期测试壳退出异常试跑不纳入比较。

本次每 2 秒记录系统 CPU、进程 CPU 和 NVIDIA 负载。开测前 12 秒 CPU 总占用中位数 5.20%（4.46–6.56%）；GPU 占用中位数 14%（13–27%，当时图形频率 210MHz）。三个原有 Python 后台进程在开测前及六次运行的采样中均为 0% CPU；采样驱动自身另有少量开销。运行中各轮系统 CPU 中位数 9.03–10.06%，GPU 中位数 21–32%，最高采样 60%。没有观察到持续的向量推理负载；这些低频计数不等同于 GPU 调度器跟踪，也不能证明机器绝对无其他活动。源码、AOT、14 份负载文件及截图核验见 `idle-retest-verification.json`；原 `verification.json` 与旧数据未覆盖。

三轮 totalSpan P95 的范围分别为：拖动旧版 29.95–30.91ms、新版 16.75–17.05ms；滚轮旧版 27.05–27.39ms、新版 20.78–21.15ms；缩放旧版 32.46–34.38ms、新版 19.09–19.60ms。暂停向量任务后的复测仍重现 CPU 优化收益，前次后台任务并未改变主要结论。

totalSpan 是单帧从 vsync 到栅格结束的引擎延迟，包含排队与调度，不是屏幕呈现间隔。栅格耗时没有与 CPU 相同幅度的下降，不把 CPU 改善比例描述成 FPS 提升比例。此前只有一张历史的补测见 `before-one-*` / `after-one-*`，同样属于未记录外部负载的历史数据，此次未重跑，不用于无向量负载的性能结论。

CPU 采样定位到两处热点：时间刻度逐帧构造本地 DateTime，重复进入 Windows 时区换算；波纹圆弧和建筑虚线逐帧重复创建、测量与截取路径。此前单列诊断中，停用两侧背景没有消除中央热点，通道关闭模式的连续相机采样间隔接近 6.94ms；这两种模式此次未重测，只保留为定位线索，不作为暂停向量任务后的正式指标。本次完整效果对照已在保持原图及工具条材质的情况下复现 CPU 改善。

## 修改

- 同日判断直接比较日历年月日，避免两个新的本地 DateTime；批次标注及主题名称按批次、日期、语言和刻度开关缓存，相机变化复用。跨午夜、切语言、批次数量／加载状态更新及重新开刻度仍刷新。
- 虚线按端点／圆、比例和虚线参数保留原来 `computeMetrics/extractPath` 得出的精确路径。颜色与线宽即时生效，完全在裁剪区外的路径提前跳过。最多 512 项，按访问顺序淘汰。
- 波纹每行保留原有绝对坐标圆弧路径，键包含行号、可见列与已有 20 档透明度分桶结果；颜色、动画相位、种子、缩放和背景色的原语义保留。最多 1024 行状态，按访问顺序淘汰。没有引入背景位图缩放或降低装饰细节。

只有四个通道绘制／标注文件改变。中央 `MemoryImage`、原图解码、OLD／蒙版／复制／保存、三条工具条、共用玻璃组件、65% 侧栏材质、滚轮运动规则和相机物理均保持。

## 验证与边界

974 项既有综合回归、47 项通道行为／原 PNG 回归及 1 项批量 RGBA 对照均通过，合计 1022 项不同检查。RGBA 对照覆盖六主题、明暗、三种缩放、两种子、两个世界位置和动静相位，288 个场景在其他状态预热缓存后与原渲染器完全一致。原有黄金 PNG 及排除范围未改。

全仓分析无诊断，最终 Windows Release 构建通过；三组原生前后固定画面的完整页面 RGB 一致。1510 个其他生产文件（含原图路径、工具条、材质和原 PNG）及原有 DEVELOPMENT.md 保持哈希。原生采样只在构建／测试结束后进行。完整检查见 `verification.json`。本次仅重测及补充开发采样工具，四个生产文件与已验证提交 `4d01bb19e` 哈希完全一致，复用此前测试／分析／构建结果，没有重新声称运行 1022 项检查；新六次原生截图 RGB 全部一致，安装 AOT 和收据仍未变化，详见 `idle-retest-verification.json`。复现入口为 [原生探针](../tool/canvas_frame_benchmark/README.md)。

CPU 慢帧明显降低，栅格绘制 P95 仍超过 144Hz 的预算；不承诺全程 144fps。此次没有用降画质、移除玻璃或改变滚动手感掩盖剩余绘制成本。桌面安装、数据、RAG 环境和索引保持，未自动启动／重启／热重载，未推送 GitHub 或重打便携包。
