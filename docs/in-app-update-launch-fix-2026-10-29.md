## 修复

- `WindowsUpdateScript.launch` 用正常启动的短命 PowerShell 调 `Start-Process -WindowStyle Hidden` 创建独立更新进程，待启动器退出码成功后才进入统一应用退出流程。脚本路径经环境变量传递并按 Windows 文件参数加双引号，避免拼进 PowerShell 代码；兼容中文、空格、单引号、分号与美元符号。
- 启动器工作目录显式设为更新脚本所在的临时目录，子进程继承该目录，释放对旧应用目录的占用。
- 启动失败继续使用现有本地化错误，保留应用打开；下载包与待安装元数据不因启动失败删除。
- 生成的 `.ps1` 写为 UTF-8 BOM，避免 Windows PowerShell 5.1 按本地 ANSI 解释中文路径。
- 服务提供可替换的脚本启动边界，让服务层验证调用顺序、编码和失败时不退出，同时不触碰实际应用目录。独立 Windows 进程回归使用生产 `launch`，不替换 PowerShell 或 `Start-Process`。
