# 外部 Agent 的桥接依赖提示

2026-10-29，源码已验证，尚未编译／安装／发布；当前本机仍为 2.2.1+62。

设置页的外部 Agent 操作区跟随上方 Krita 桥接开关：关闭时使用现有行组件灰显、禁用复制接管说明和结束连接，并以 11px 小字提示“此功能需要开启上方的 Krita 桥接”。开启后隐藏提示、恢复可用操作；无 Agent 在线时结束连接仍禁用。其余布局保持。

依赖为共享服务的 `SettingKey.kritaBridge`，不是 `kritaConnected`。桥接可以只监听外部 Agent，无需启动 Krita 软件或连接插件。此次没有改变桥接协议或实际用户设置。

实现位于 `lib/presentation/ui/settings/settings_system.dart`，提示同步五种界面语言；繁中资源按既有工具生成。`SettingsViewData.copyWith` 补齐桥接数据可选参数，以验证实时状态切换。
