## 实现

- 每个 Pi 事件立即接收处理，仅把思考／正文／工具参数增量的 UI 通知合并到 100ms。工具状态、停止、错误和最终消息立即发布；计时器随控制器关闭清理。
- 已完成轮次按来源消息及展示上下文生成稳定 renderKey，保留原卡片组件。缓存纯提示词差异计算（128 组、每组总计最多 32768 字符），不冻结撤销、版本锁定、资源、工具或分支状态。提示词组卡保留原修订去重路径。
- AgentScope 按整体／操作状态／输入区区分依赖，稳定输入区不随思考重建。同一设置对象跳过布局广播，仍推进加载版本以保持原异步读取保护。
- 思考字数与展开正文共享局部显示游标，按完整字符推进到已接收内容；断流不虚增。文本仅随合并快照重新排版，高刷动画只更新计数行及正文裁剪绘制。重新展开、开始选择、完成和减少动画模式立即显示已收到内容。
