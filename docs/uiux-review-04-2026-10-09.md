## 复查修正

- **舞台顶栏在 1280 默认宽度下挤坏**：舞台只有 536，原实现给统计固定 30% / 12% 宽度并硬裁，出现“38 枚 · お気に入り 6 · 3 ラ”“38장 · 즐ㄱ”这类半个字；生成中名称被压成“柔…”，进度只剩“第 3 轮 · 9…”看不到分数。改为按优先级退让：统计整项隐藏 → 去掉进度条 → “第 N 轮 · a / b”收成“a / b” → 最后才截短探索名。测量与渲染用同一份文字样式，`TextPainter` 用完释放。1280 生成中现在是完整名称 + “9 / 12” + 暂停 / 停止。
- **窄窗手动打开检查器会把编辑列压到 60–208**：原规则是舞台保 480、编辑列裁切，1000 宽窗口手动打开后编辑列只剩 208。改为放不下“352 + 480 + 检查器”时，检查器像 U1 库检查器一样浮在舞台右缘（12 阴影，标题行窗口按钮左侧有关闭按钮），编辑列和舞台宽度不动。
- **编辑列 352–384 之间直接裁掉右侧**：原实现总按保存宽度排版再裁切，900 窗口下卡片贴到分隔线。改为先按实际宽度重排到 352 下限，更窄才裁切；胶囊行和生成条随实际宽度排版。
- **切换菜单“更多 → 重命名”弹出对话框**：同一菜单里已有行内改名，改为直接进入行内改名（Enter 保存、Esc 取消、空名提示），不再在浮层上叠对话框。`ExploreRunActions.rename` 和 `styleExplore_runNameLabel` 目前无人引用，留给探索10 清理（ARB 里混有另一会话的未提交改动，本次不动）。
- 测试文件多余的 import 一并删除。
